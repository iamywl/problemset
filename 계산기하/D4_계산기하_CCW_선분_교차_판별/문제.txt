[S/W 문제해결 심화] CCW를 활용한 선분 교차 판별 (D4)

[알고리즘 개념 및 원리 학습 - 계산 기하학: 선분 교차 판별 (CLRS 33.1)]

계산 기하학(Computational Geometry)에서 2차원 평면 위의 두 선분 L1, L2가 서로 교차하는지 판별하는 것은 컴퓨터 그래픽스, 로보틱스, GIS(지리정보시스템) 등의 기초가 되는 중요한 기법입니다.

1. 벡터의 2차원 외적과 CCW(Counter-Clockwise) 함수:
- 세 점 P1(x1, y1), P2(x2, y2), P3(x3, y3)에 대해 벡터 P1P2와 P1P3의 2차원 외적(Cross Product) 공식:
Cross = (x2 - x1) * (y3 - y1) - (y2 - y1) * (x3 - x1)
- 결과 부호에 따른 기하학적 의미:
* Cross > 0: 점 P1, P2, P3가 반시계 방향(Counter-Clockwise)을 이룸 (+1)
* Cross < 0: 점 P1, P2, P3가 시계 방향(Clockwise)을 이룸 (-1)
* Cross == 0: 세 점이 일직선상(Collinear)에 위치함 (0)

2. 두 선분 AB와 CD의 교차 판정 알고리즘:
- d1 = CCW(A, B, C), d2 = CCW(A, B, D)
- d3 = CCW(C, D, A), d4 = CCW(C, D, B)
- 두 선분이 서로를 교차하려면 선분 AB를 기준으로 점 C와 D가 서로 반대편에 위치해야 하고(d1 * d2 <= 0), 동시에 선분 CD를 기준으로 점 A와 B가 서로 반대편에 위치해야 합니다(d3 * d4 <= 0).

3. 일직선상(Collinear) 특수 케이스 처리:
- 네 점이 모두 한 직선 위에 있는 경우 (d1 == 0 && d2 == 0 && d3 == 0 && d4 == 0):
* 단순히 부호 곱만으로는 교차 여부를 판별할 수 없습니다.
* 두 선분의 축 정렬 경계 상자(Bounding Box)가 서로 겹치는지 검사해야 합니다:
min(Ax, Bx) <= max(Cx, Dx) && min(Cx, Dx) <= max(Ax, Bx) &&
min(Ay, By) <= max(Cy, Dy) && min(Cy, Dy) <= max(Ay, By)
* 위 조건을 만족하면 두 선분이 적어도 한 점(끝점 포함) 이상 겹치므로 교차(1)로 판정하고, 그렇지 않으면 일직선상에 있으나 떨어져 있으므로 교차하지 않음(0)으로 판정합니다.
- 그 외의 경우:
* (d1 * d2 <= 0) && (d3 * d4 <= 0) 이면 교차(1), 아니면 교차하지 않음(0)입니다.

4. 자료형 주의사항:
- 좌표의 최댓값이 1,000,000일 때 외적 연산 과정에서 최대 (2 * 10^6)^2 = 4 * 10^12의 수가 발생하므로 반드시 64비트 정수형(long)으로 연산해야 오버플로우를 방지할 수 있습니다.

[문제 설명]

2차원 평면 위에 두 개의 선분 L1, L2가 주어집니다.
선분 L1의 양 끝점 좌표는 A(x1, y1), B(x2, y2)이며, 선분 L2의 양 끝점 좌표는 C(x3, y3), D(x4, y4)입니다.
두 선분이 한 점에서 만나거나, 끝점이 다른 선분 위에 닿아 있거나, 일직선상에서 일부 또는 전부 겹치는 경우 모두 '교차함(1)'으로 판정합니다.
만나지 않는 경우는 '교차하지 않음(0)'으로 판정합니다.
두 선분의 교차 여부를 판별하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. 모든 점의 좌표 x1, y1, x2, y2, x3, y3, x4, y4는 -1,000,000 이상 1,000,000 이하의 정수이다.
2. 선분의 두 끝점은 서로 다름이 보장된다. (A != B, C != D)
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 선분 L1의 좌표 x1, y1, x2, y2가 공백으로 구분되어 주어진다.
둘째 줄에 선분 L2의 좌표 x3, y3, x4, y4가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 두 선분이 교차하면 1, 교차하지 않으면 0을 출력한다.
