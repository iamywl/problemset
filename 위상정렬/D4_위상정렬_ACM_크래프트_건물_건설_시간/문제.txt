[문제 설명]
전략 시뮬레이션 게임에서 건물 1번부터 N번까지 각각을 짓는 데 걸리는 건설 시간 time[i]가 주어집니다.
또한 건물 간의 선행 건설 조건 M개가 주어집니다.
어떤 건물을 짓기 위해서는 해당 건물의 모든 선행 건물이 완공되어야 하며, 선행 조건이 충족되면 여러 건물을 동시에 지을 수 있습니다.
따라서 건물 v를 짓기 시작할 수 있는 가장 빠른 시점은 모든 선행 건물 u의 완공 시점 중 최댓값입니다.
$$dp[v] = \max_{(u \to v)} (dp[u]) + time[v]$$
특정 목표 건물 W를 완공하기까지 걸리는 최소 총 소요 시간을 위상 정렬과 동적 계획법(DP)을 결합하여 계산하라.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 건물 수 N(1 <= N <= 1,000)과 건설 규칙 수 K(1 <= K <= 100,000)가 주어진다.
두 번째 줄에 건물 1번부터 N번까지의 건설 시간 N개가 공백으로 구분되어 주어진다. (0 <= time <= 100,000)
다음 K개의 줄에 걸쳐 선행 건물 u와 후행 건물 v가 주어진다.
마지막 줄에 승리하기 위해 건설해야 하는 목표 건물 번호 W(1 <= W <= N)가 주어진다.

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, 건물 W를 완성하는 데 드는 최소 시간을 정수로 출력한다.
