[S/W 문제해결 기본] 위상정렬에 대해서 (D2)

[문제 설명]
위상 정렬(Topological Sort) 알고리즘 개념 및 동작 원리 설명:
위상 정렬은 사이클이 없는 방향 그래프(DAG, Directed Acyclic Graph)의 모든 정점을 방향성에 거스르지 않도록 순서대로 나열하는 알고리즘입니다.
일반적으로 칸(Kahn) 알고리즘이 널리 쓰이며, 동작 원리는 다음과 같습니다:
1. 모든 정점의 진입 차수(Indegree, 정점으로 들어오는 간선의 수)를 계산합니다.
2. 진입 차수가 0인 모든 정점(선행 작업이 없는 작업)을 큐(Queue)에 삽입합니다.
3. 큐에서 정점을 하나씩 꺼내 위상 정렬 결과 리스트에 추가합니다.
4. 꺼낸 정점에서 나가는 모든 간선을 제거합니다. (연결된 인접 정점들의 진입 차수를 1씩 감소시킵니다.)
5. 새롭게 진입 차수가 0이 된 정점들을 큐에 삽입합니다.
6. 큐가 빌 때까지 3~5 과정을 반복합니다.

[동작 과정 Trace 예시]
정점 4개(1, 2, 3, 4), 선행 관계 간선: (1 -> 2), (1 -> 3), (2 -> 4), (3 -> 4)
초기 진입차수: [1:0, 2:1, 3:1, 4:2]
1단계: 진입차수 0인 1을 큐에 삽입 -> Queue: [1]
2단계: 1 꺼냄 (순서: [1]) -> 2, 3의 진입차수 1씩 감소 -> [2:0, 3:0] -> Queue: [2, 3]
3단계: 2 꺼냄 (순서: [1, 2]) -> 4의 진입차수 1 감소 -> 4의 진입차수 1
4단계: 3 꺼냄 (순서: [1, 2, 3]) -> 4의 진입차수 1 감소 -> 4의 진입차수 0 -> Queue: [4]
5단계: 4 꺼냄 (순서: [1, 2, 3, 4]) -> Queue 비어있음, 정렬 완료!

이것을 구현하라.
DAG 형태의 정점 수 V와 방향 간선 수 E가 주어질 때, 올바른 위상 정렬 순서를 구하라. (단, 복수의 순서가 가능할 경우 정점 번호가 작은 것을 먼저 선택하여 일관된 순서를 유지하라.)

[제약 사항 (Java 전용)]
1. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내 (테스트케이스당 0.2초 이내)
2. 메모리 제한: 힙(Heap) 메모리 256MB 이내 (자바 전용)
3. 정점의 수 V는 1 이상 10,000 이하의 자연수이다.
4. 간선의 수 E는 0 이상 100,000 이하의 정수이다.
5. 진입 차수(Indegree) 배열과 큐를 이용한 카안 알고리즘 표준 구조를 구현한다.

[입력]

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 정점 수 V(1 <= V <= 10,000)와 간선 수 E(0 <= E <= 100,000)가 주어진다.
다음 E개의 줄에 걸쳐 방향 간선 u, v가 주어진다. (u -> v, 1 <= u, v <= V)

[출력]

각 테스트 케이스마다 '#T'를 출력하고, 위상 정렬된 정점 번호들을 공백으로 구분하여 출력한다.
