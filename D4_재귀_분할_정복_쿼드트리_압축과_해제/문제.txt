[S/W 문제해결 심화] 분할 정복 쿼드트리 압축과 해제 (D4)

[문제 설명]
$N \times N$ ($N = 2^K$) 크기의 흑백 영상이 주어집니다. 각 픽셀은 흰색(0) 또는 검은색(1)입니다.
쿼드 트리(Quad Tree) 알고리즘을 사용하여 영상을 다음과 같이 재귀적으로 압축합니다:
1. 현재 영역의 모든 픽셀이 0이면 "0"으로 압축합니다.
2. 현재 영역의 모든 픽셀이 1이면 "1"으로 압축합니다.
3. 0과 1이 섞여 있다면 영역을 4개의 사분면(왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래)으로 나누어 재귀 압축하며, 괄호 `(`와 `)`로 묶습니다: `(왼쪽위오른쪽위왼쪽아래오른쪽아래)`

주어진 영상에 대해 쿼드 트리로 압축한 결과를 출력하십시오.

[제약 사항 (Java 전용)]
1. N은 2, 4, 8, 16, 32, 64 중 하나이다 ($N = 2^K$).
2. 각 픽셀은 0 또는 1이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 첫 줄에 영상의 크기 N이 주어진다.
이어지는 N개의 줄에 걸쳐 공백 없는 문자열 형태로 영상 데이터가 주어진다.

[출력]
각 테스트케이스마다 '#tc'와 공백을 출력한 후, 압축된 쿼드트리 문자열을 출력한다.
