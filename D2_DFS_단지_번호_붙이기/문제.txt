[S/W 문제해결 기본] 단지 번호 붙이기 (D2)

정사각형 모양의 N×N 지도에 아파트들이 1로 표시되어 있다. 0은 집이 없는 빈 곳이다.
상, 하, 좌, 우로 연결된 집들의 모임을 하나의 '단지'라고 정의한다.
지도를 보고 총 단지수와, 각 단지에 속하는 집의 수를 오름차순으로 정렬하여 출력하는 프로그램을 작성하라.

[제약 사항 (Java 전용)]
1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. N은 3 이상 15 이하의 정수이다.

[입력]
첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 지도의 크기 N이 주어진다.
다음 N개의 줄에 걸쳐 N자리 문자열(0 또는 1)이 주어진다.

[출력]
각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 총 단지수를 출력한다.
다음 줄에 각 단지내 집의 수를 오름차순으로 공백으로 구분하여 출력한다. (단지가 없을 경우 빈 줄 출력)
