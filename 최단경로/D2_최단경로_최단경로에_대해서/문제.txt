[S/W 문제해결 기초] 최단경로에 대해서 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 다익스트라(Dijkstra) 최단 경로]
다익스트라(Dijkstra) 알고리즘은 음의 가중치가 없는 그래프에서 한 출발 정점(Start)으로부터 다른 모든 정점까지의 '최단 경로(최단 거리)'를 구하는 가장 대표적인 알고리즘입니다.
매 순간 아직 방문하지 않은 정점들 중에서 출발점으로부터의 누적 거리가 가장 짧은 정점을 탐욕적으로(Greedy) 선택하여 거리를 확정짓는 원리로 동작합니다.

효율적인 구현을 위해 우선순위 큐(Min-Heap)를 사용하며, 시간복잡도는 O((V + E) log V)입니다:
1. 최단 거리 배열 `dist`를 모두 무한대(INF)로 초기화하고, 시작점은 `dist[start] = 0`으로 설정합니다.
2. 우선순위 큐에 `(거리 0, 시작 정점)`을 삽입합니다.
3. 큐가 빌 때까지 다음 과정을 반복합니다:
- 큐에서 가장 거리가 짧은 `(d, u)`를 꺼냅니다.
- 이미 기록된 최단 거리보다 현재 꺼낸 거리가 더 길다면(`dist[u] < d`) 이미 최적화된 정점이므로 건너뜁니다.
- u와 연결된 인접 정점 v와 가중치 w에 대해, u를 거쳐서 v로 가는 거리(`d + w`)가 기존 `dist[v]`보다 짧다면:
- `dist[v] = d + w`로 갱신하고, 우선순위 큐에 `(dist[v], v)`를 삽입합니다 (Relaxation 연산).

[동작 과정 Trace 예시]
정점 1~3 (간선: 1->2 (가중치 4), 1->3 (가중치 2), 3->2 (가중치 1))에서 1번 출발:
- 초기 상태: dist = [0, INF, INF], pq = [(0, 1)]
- (0, 1) 꺼냄:
- 1 -> 2: dist[2] = min(INF, 0 + 4) = 4, pq에 (4, 2) 삽입
- 1 -> 3: dist[3] = min(INF, 0 + 2) = 2, pq에 (2, 3) 삽입
- (2, 3) 꺼냄 (거리가 더 짧은 3번 우선):
- 3 -> 2: dist[2] = min(4, 2 + 1) = 3 (갱신!), pq에 (3, 2) 삽입
- (3, 2) 꺼냄: 인접 간선 없음
- (4, 2) 꺼냄: dist[2]=3 < 4 이므로 무시(스킵)
최종 최단 거리는 1번: 0, 2번: 3, 3번: 2가 됩니다. 이것을 구현하여 다익스트라 알고리즘의 원리를 완벽히 체득하십시오.

[문제 설명]

방향 그래프와 시작 정점 K가 주어질 때, K번 정점에서 출발하여 1번부터 V번까지 각 정점으로 가는 최단 거리를 출력하십시오 (도달할 수 없는 경우 "INF"를 출력).

[제약 사항 (Java 전용)]

1. 정점의 수 V는 1 이상 1,000 이하의 자연수이다.
2. 간선의 수 E는 1 이상 10,000 이하의 자연수이다.
3. 모든 간선의 가중치는 1 이상 1,000 이하의 자연수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 정점의 수 V와 간선의 수 E가 공백으로 구분되어 주어진다.
둘째 줄에 시작 정점 K가 주어진다.
이어지는 E개의 줄에 걸쳐 간선 정보 u, v, w (u에서 v로 가는 가중치 w)가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'를 출력하고, 다음 줄부터 1번부터 V번 정점까지의 최단 거리를 한 줄에 하나씩 출력한다 (도달할 수 없으면 INF).
