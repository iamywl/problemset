[S/W 문제해결 기초] 격자판 최소 비용 이동 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 2차원 격자 다익스트라]
N x N 크기의 격자 지도가 주어집니다. 각 칸 (r, c)에는 그 칸을 통과할 때 소모되는 비용(복구 시간 또는 에너지)이 0 이상 9 이하의 한 자리 숫자로 적혀 있습니다.
출발점 (0, 0)에서 목적지 (N-1, N-1)까지 상, 하, 좌, 우 4방향으로 이동할 때, 통과하는 칸들의 비용 합의 최솟값을 구하는 문제입니다 (출발지 칸의 비용은 0입니다).

가중치가 서로 다른 2차원 격자판에서의 최단 경로는 단순 BFS(가중치 1) 대신 다익스트라(Dijkstra) 알고리즘을 사용해야 합니다.
`dist[r][c]`를 무한대로 초기화하고 우선순위 큐에 `(비용, r, c)`를 넣어 4방향 델타 탐색으로 최단 거리를 갱신합니다.

[동작 과정 Trace 예시]
3 x 3 격자:
011
311
420
(0,0)에서 출발:
- dist[0][0] = 0
- (0,0) -> (0,1) 비용: 1, (0,0) -> (1,0) 비용: 3
- (0,1) -> (0,2) 비용: 1+1=2, (0,1) -> (1,1) 비용: 1+1=2
- ...
목적지 (2,2)에 도달하는 최소 비용을 계산합니다.
이것을 구현하여 2차원 다익스트라의 원리를 마스터하십시오.

[문제 설명]
N x N 격자에서 (0,0)에서 (N-1, N-1)까지 이동하는 최소 소모 비용을 구하십시오.

[제약 사항 (Java 전용)]
1. 격자의 크기 N은 2 이상 100 이하의 자연수이다.
2. 각 칸의 비용은 0 이상 9 이하의 정수이며, 출발점 (0,0)의 비용은 0이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 격자의 크기 N이 주어진다.
이어지는 N개의 줄에 격자의 정보가 공백 없이 한 줄에 N개씩 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 최소 이동 비용을 정수로 출력한다.
