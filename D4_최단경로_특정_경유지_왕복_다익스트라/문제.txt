[S/W 문제해결 심화] 특정 경유지 왕복 다익스트라 (D4)

[복합 제약 조건 설명]
1번부터 N번까지의 정점과 E개의 양방향 가중치 간선으로 이루어진 무방향 그래프가 있습니다.
1번 정점에서 출발하여 N번 정점으로 이동하는 최단 거리를 구하고자 합니다.
단, 다음과 같은 엄격한 복합 조건이 추가됩니다:
"주어진 두 개의 서로 다른 특정 정점 V_1과 V_2를 반드시 모두 방문해야 한다."

[복합 해결 조건]
1. 한 번 이동했던 정점이나 간선을 다시 이동하는 것은 허용됩니다.
2. 가능한 이동 경로는 다음 두 가지 경우뿐입니다:
   - Case 1: 1 -> V_1 -> V_2 -> N
     (거리 = dist(1, V_1) + dist(V_1, V_2) + dist(V_2, N))
   - Case 2: 1 -> V_2 -> V_1 -> N
     (거리 = dist(1, V_2) + dist(V_2, V_1) + dist(V_1, N))
3. 다익스트라 알고리즘을 시작점 1, V_1, V_2에 대해 각각 총 3번 수행하여 필요한 최단 거리들을 구한 뒤 두 경로 중 최솟값을 취합니다.
4. 만약 두 경우 모두 목적지 N에 도달할 수 없거나 경로가 존재하지 않는다면 -1을 출력해야 합니다.
5. 거리 합산 시 오버플로우 방지를 위해 INF 값 설정 및 64비트 정수형(long) 처리가 필수적입니다.

[제약 사항 (Java 전용)]
1. 정점의 수 N은 2 이상 1,000 이하의 자연수이다.
2. 간선의 수 E는 1 이상 100,000 이하의 자연수이다.
3. 간선의 가중치 w는 1 이상 10,000 이하의 자연수이다.
4. 특정 경유지 V_1과 V_2는 1 이상 N 이하이며 V_1 != V_2 이다.
5. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
6. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 E가 공백으로 구분되어 주어진다.
이어지는 E개의 줄에는 양방향 간선의 정보 u, v, w가 공백으로 구분되어 주어진다.
마지막 줄에 반드시 거쳐야 하는 두 정점 V_1과 V_2가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 두 경유지를 모두 거쳐 N에 도달하는 최단 거리를 출력한다. (경로가 없으면 -1 출력)
