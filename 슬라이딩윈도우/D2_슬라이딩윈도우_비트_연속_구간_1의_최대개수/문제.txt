[S/W 문제해결 기초] 비트 연속 구간 1의 최대개수 (D2)

[문제 설명 및 개념]
0과 1로만 구성된 길이 N인 이진 수열이 주어집니다.
크기가 정확히 K인 연속된 윈도우 안에 포함될 수 있는 1의 최대 개수를 구하는 문제입니다.
슬라이딩 윈도우를 이용하여 윈도우 내 1의 개수를 $O(1)$에 갱신하며 최댓값을 산출하십시오.

[동작 과정 Trace 예시]
이진 수열 [1, 0, 1, 1, 0, 1, 1, 1], K=4:
- 윈도우 [1, 0, 1, 1]: 1의 개수 = 3
- 윈도우 [0, 1, 1, 0]: 1의 개수 = 2
- 윈도우 [1, 1, 0, 1]: 1의 개수 = 3
- 윈도우 [1, 0, 1, 1]: 1의 개수 = 3
- 윈도우 [0, 1, 1, 1]: 1의 개수 = 3
최대 1의 개수: 3

[제약 사항 (Java 전용)]
1. 수열의 길이 N은 1 이상 10,000 이하의 자연수이다.
2. 윈도우의 크기 K는 1 이상 N 이하의 자연수이다.
3. 수열의 원소는 0 또는 1이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 첫 줄에 N과 K가 공백으로 주어진다.
둘째 줄에 N개의 숫자가 공백으로 구분되어 주어진다.

[출력]
각 테스트케이스마다 '#tc'와 공백을 출력한 후, 크기 K인 윈도우 내 1의 최대 개수를 출력한다.
