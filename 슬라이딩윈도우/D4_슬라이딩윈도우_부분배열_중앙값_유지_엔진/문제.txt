[S/W 문제해결 심화] 부분배열 중앙값 유지 엔진 (D4)

[문제 설명]

길이가 N인 수열 A와 윈도우 크기 K(홀수)가 주어집니다.
윈도우가 한 칸씩 이동할 때마다, 현재 윈도우 안에 포함된 K개 원소들의 '중앙값(Median)'을 구하여 순서대로 출력하는 문제입니다.
크기 K가 최대 500까지 주어질 때 매번 정렬하면 O(N x K log K)가 소요되므로,
원소들의 빈도수와 크기 분포를 관리하는 균형 트리(TreeSet 또는 카운팅 배열)를 활용하여 O(N x Scale)에 중앙값을 고속으로 산출하십시오.

[제약 사항 (Java 전용)]

1. 수열의 길이 N은 1 이상 5,000 이하의 자연수이다.
2. 윈도우 크기 K는 1 이상 N 이하의 홀수 자연수이다.
3. 원소의 값은 0 이상 5,000 이하의 정수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 첫 줄에 N과 K가 공백으로 주어진다.
둘째 줄에 N개의 정수가 공백으로 구분되어 주어진다.

[출력]

각 테스트케이스마다 '#tc'와 공백을 출력한 후, 각 윈도우의 중앙값들을 공백으로 구분하여 한 줄에 출력한다.
