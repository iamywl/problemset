[문제 설명]
이진 탐색(Binary Search) 알고리즘 개념 및 동작 원리 설명:
이진 탐색은 '오름차순으로 정렬된 배열'에서 특정 목표 값(Target)의 위치를 $O(\log N)$ 시간 복잡도로 빠르게 찾아내는 탐색 알고리즘입니다.
탐색 범위의 시작 인덱스(left)와 끝 인덱스(right)의 중간 위치(mid)를 계산한 뒤, mid 위치의 값과 Target을 비교하여 탐색 범위를 절반씩 좁혀나갑니다.

[동작 과정 Trace 예시]
정렬된 배열 [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]에서 Target = 23을 찾는 과정:
1단계: left = 0, right = 9, mid = (0 + 9) / 2 = 4 -> arr[4] = 16 < Target(23)
       오른쪽 절반으로 범위 축소: left = mid + 1 = 5
2단계: left = 5, right = 9, mid = (5 + 9) / 2 = 7 -> arr[7] = 56 > Target(23)
       왼쪽 절반으로 범위 축소: right = mid - 1 = 6
3단계: left = 5, right = 6, mid = (5 + 6) / 2 = 5 -> arr[5] = 23 == Target(23)
       Target 발견! 탐색 종료, 인덱스 5 반환.

이것을 구현하라.
주어지는 오름차순 정렬된 $N$개의 원소 중에서 $M$개의 질의(Target)에 대해 각각 배열 내에 존재하면 1-based 인덱스를, 존재하지 않으면 -1을 출력하라.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 번째 줄에 배열의 크기 N(1 <= N <= 100,000)과 질의의 개수 M(1 <= M <= 10)이 공백으로 구분되어 주어진다.
두 번째 줄에 오름차순으로 정렬된 N개의 정수가 공백으로 구분되어 주어진다. (원소의 절댓값 <= 1,000,000,000)
세 번째 줄에 찾고자 하는 M개의 질의 정수가 공백으로 구분되어 주어진다.

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, M개의 질의에 대해 찾은 1-based 인덱스(없으면 -1)를 공백으로 구분하여 출력한다.
