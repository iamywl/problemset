[S/W 문제해결 기초] 미로 탈출 최단거리 기초 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 2차원 격자 BFS 최단 거리]
N x M 크기의 직사각형 격자 미로에서 (0, 0) 위치에서 출발하여 (N-1, M-1) 위치로 탈출하는 최단 이동 칸 수를 구하는 문제입니다.
1은 이동할 수 있는 길을 의미하고, 0은 이동할 수 없는 벽을 의미합니다.
상, 하, 좌, 우 4방향으로 인접한 길로만 1칸씩 이동할 수 있습니다.

BFS는 모든 경로를 거리 순서(1칸, 2칸, 3칸...)대로 동시에 넓혀가며 탐색하므로,
목적지 (N-1, M-1)에 최초로 도달하는 순간의 이동 거리가 바로 최단 거리임이 수학적으로 증명됩니다.

[동작 과정 Trace 예시]
4 x 6 미로:
101111
101010
101011
111011
(0,0)에서 출발:
- dist[0][0] = 1, Queue = [(0,0)]
- (0,0) 방문 -> 아래 (1,0) 도달 가능: dist[1][0] = 2
- (1,0) 방문 -> 아래 (2,0) 도달 가능: dist[2][0] = 3
- (2,0) 방문 -> 아래 (3,0) 도달 가능: dist[3][0] = 4
- (3,0) 방문 -> 오른쪽 (3,1) 도달 가능: dist[3][1] = 5
... 차례대로 확장되어 (3, 5)에 도달하는 최단 칸 수를 구합니다.
이것을 구현하여 2차원 델타 탐색과 BFS 최단 경로의 원리를 마스터하십시오.

[문제 설명]

주어진 N x M 크기의 미로에서 (0,0)에서 (N-1, M-1)까지 지나야 하는 최소 칸 수를 구하십시오 (시작 칸과 끝 칸도 개수에 포함).

[제약 사항 (Java 전용)]

1. N과 M은 2 이상 100 이하의 자연수이다.
2. 미로는 항상 탈출 가능한 경로가 존재한다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 M이 공백으로 구분되어 주어진다.
이어지는 N개의 줄에 미로의 정보가 공백 없이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 지나야 하는 최소 칸 수를 정수로 출력한다.
