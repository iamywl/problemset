[S/W 문제해결 기초] BFS에 대해서 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 너비 우선 탐색(BFS)]
너비 우선 탐색(Breadth-First Search, BFS)은 그래프나 트리를 탐색할 때 시작 정점에서 가까운 정점부터 차례대로(Level 순서대로) 방문하는 대표적인 탐색 알고리즘입니다.
가중치가 동일(1)한 그래프에서 시작점으로부터 다른 모든 정점까지의 '최단 경로(최단 거리)'를 보장하는 결정적인 특성을 가집니다.

BFS의 핵심 동작 원리는 선입선출(FIFO) 자료구조인 큐(Queue)와 방문 여부를 기록하는 불리언 배열(visited)을 사용하는 것입니다:
1. 시작 정점을 큐에 삽입(Enqueue)하고 visited[start] = true로 표시합니다.
2. 큐가 빌 때까지 다음을 반복합니다:
- 큐의 맨 앞에서 정점 u를 꺼냅니다(Dequeue).
- u와 인접한 모든 정점 v에 대해, 아직 방문하지 않았다면(!visited[v]):
- visited[v] = true로 표시하고,
- 큐에 v를 삽입합니다(Enqueue).

[동작 과정 Trace 예시]
정점 1번부터 4번까지의 그래프(간선: 1-2, 1-3, 2-4, 3-4)에서 1번부터 BFS 탐색 과정:
- 초기 상태: Queue = [1], visited = {1: T}
- 1 꺼냄 -> 방문 순서: 1. 1과 연결된 미방문 정점 2, 3 큐에 삽입 -> Queue = [2, 3], visited = {1, 2, 3}
- 2 꺼냄 -> 방문 순서: 1, 2. 2와 연결된 미방문 정점 4 큐에 삽입 -> Queue = [3, 4], visited = {1, 2, 3, 4}
- 3 꺼냄 -> 방문 순서: 1, 2, 3. 3과 연결된 정점 중 미방문 정점 없음 -> Queue = [4]
- 4 꺼냄 -> 방문 순서: 1, 2, 3, 4. 미방문 정점 없음 -> Queue = []
탐색 종료 후 방문 순서는 1 2 3 4가 됩니다. 이것을 구현하여 BFS의 레벨별 큐 동작 원리를 완벽히 체득하십시오.

[문제 설명]

1번부터 N번까지의 정점과 M개의 양방향 간선이 주어질 때, 1번 정점에서 출발하여 BFS로 방문하는 정점들의 순서를 공백으로 구분하여 출력하십시오 (인접 정점이 여러 개일 경우 번호가 작은 정점부터 먼저 방문합니다).

[제약 사항 (Java 전용)]

1. 정점의 수 N은 1 이상 1,000 이하의 자연수이다.
2. 간선의 수 M은 1 이상 10,000 이하의 자연수이다.
3. 간선은 양방향 간선이며 두 정점 사이에 여러 간선이 주어질 수 있다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 정점의 수 N과 간선의 수 M이 공백으로 구분되어 주어진다.
이어지는 M개의 줄에 걸쳐 간선이 연결하는 두 정점 번호 u, v가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 1번 정점부터 BFS로 방문한 정점 번호들을 공백으로 구분하여 한 줄에 출력한다.
