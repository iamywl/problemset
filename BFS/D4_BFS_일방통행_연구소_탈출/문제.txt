[S/W 문제해결 응용] 일방통행 연구소 탈출 (D3)

16×16 크기의 연구소 미로가 있다.
연구소 바닥에는 보안 감지 장치가 설치되어 있어 연구원이 한 번 지나간 통로는 센서가 감지하여 폐쇄된다.
따라서 연구원은 한 번 지나온 길을 다시 되돌아갈 수 없으며(역주행 불가), 오직 아직 방문하지 않은 새로운 길로만 전진해야 한다.

연구소에는 비상 보안 시스템이 가동되어 반드시 '보안 카드키'를 먼저 획득한 후에만 잠긴 비상 탈출구(3)에 진입할 수 있다.
(※ 주의: 보안 카드키를 획득하기 전에는 탈출구 칸으로 이동하거나 통과할 수 없다.)

주어진 16×16 미로에서 시작점(2)에서 출발하여 역주행 없이 도중에 보안 카드키(4)를 획득하고, 최종적으로 잠긴 비상 탈출구(3)까지 도달할 수 있는지 판단하는 프로그램을 작성하라.

[제약 사항 (Java 전용)]
1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. 미로 크기는 16×16 고정이며, 가장 바깥 테두리(0행, 15행, 0열, 15열)는 항상 벽(1)이다.
6. 격자 구성:
   - 0: 통로 (이동 가능)
   - 1: 벽 (이동 불가)
   - 2: 연구원의 시작 위치 (출발점)
   - 3: 잠긴 비상 탈출구 (도착점)
   - 4: 보안 카드키 (1개)
7. 한 번 방문한 통로는 다시 방문할 수 없다.

[입력]
각 테스트 케이스의 첫 줄에는 테스트 케이스 번호가 주어지며,
바로 다음 줄부터 16줄에 걸쳐 각 줄마다 길이 16인 문자열 형태로 미로의 정보가 주어진다.
샘플 테스트 케이스는 총 2개, 평가용 테스트 케이스는 총 10개가 주어진다.

[출력]
각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 탈출 가능하면 1, 불가능하면 0을 출력한다.
