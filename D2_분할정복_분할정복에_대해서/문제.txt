[문제 설명]
분할 정복(Divide and Conquer) 알고리즘 개념 및 동작 원리 설명:
분할 정복은 해결하기 어려운 거대한 문제를 더 이상 나눌 수 없을 때까지 작은 하위 문제로 나눈(Divide) 뒤, 각각의 하위 문제를 해결(Conquer)하고, 해결된 결과를 합쳐서(Combine) 원래 문제의 해답을 구하는 알고리즘 설계 패러다임입니다.

가장 대표적인 예시는 빠른 거듭제곱 연산 $C^N \pmod M$ 입니다.
$C^N$을 구할 때 단순 반복문을 사용하면 $O(N)$의 시간이 걸리지만, 분할 정복을 적용하면 다음과 같이 $O(\log N)$으로 대폭 단축됩니다.
- $N$이 짝수일 때: $C^N = (C^{N/2}) \times (C^{N/2})$
- $N$이 홀수일 때: $C^N = (C^{(N-1)/2}) \times (C^{(N-1)/2}) \times C$

[동작 과정 Trace 예시]
$2^{10} \pmod{1000}$ 연산 과정 Trace:
1단계: $2^{10}$ 계산을 위해 $2^5$ 호출 (Divide)
2단계: $2^5$ 계산을 위해 $2^2$ 호출
3단계: $2^2$ 계산을 위해 $2^1$ 호출
4단계: $2^1 = 2$ 기저조건 반환
5단계: $2^2 = (2^1 \times 2^1) = 4$ (Combine)
6단계: $2^5 = (2^2 \times 2^2 \times 2) = (4 \times 4 \times 2) = 32$ (Combine)
7단계: $2^{10} = (2^5 \times 2^5) = (32 \times 32) = 1024 \pmod{1000} = 24$ (Combine)

이것을 구현하라.
밑 $C$, 지수 $N$, 나눌 수 $M$이 주어질 때, $C^N \pmod M$의 값을 분할 정복을 이용하여 효율적으로 계산하라.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스마다 한 줄에 세 자연수 C(1 <= C <= 2,000,000,000), N(1 <= N <= 2,000,000,000), M(2 <= M <= 2,000,000,000)이 공백으로 구분되어 주어진다.

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, C^N mod M의 계산 결과를 출력한다.
