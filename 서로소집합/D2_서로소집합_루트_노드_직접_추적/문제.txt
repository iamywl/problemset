[문제 설명]
서로소 집합(Disjoint Set)에서 어떤 노드가 속한 집합의 최종 대표자(루트 노드)를 찾기 위해서는 직속 부모 포인터를 따라 계속 상위 노드로 거슬러 올라가야 합니다.

루트 노드(Root Node)의 유일한 특징은 "자기 자신의 부모가 자기 자신인 노드(parent[curr] == curr)"라는 점입니다.
따라서 재귀 함수나 경로 압축 없이도, 다음과 같이 직관적인 while 반복문 하나만으로 루트 노드까지 도달할 수 있습니다:

    int curr = X;
    int hops = 0; // 거쳐간 부모 링크 수
    while (parent[curr] != curr) {
        curr = parent[curr];
        hops++;
    }
    // 최종 도달한 curr가 루트 노드, hops가 루트까지의 이동 거리(간선 수)

이 문제에서는 1번부터 N번 노드까지의 부모 배열 상태가 주어졌을 때, 특정 노드 X에서 시작하여 루트 노드까지 거슬러 올라가며 거쳐간 간선의 수(hops)와 최종 도달한 루트 노드의 번호를 구하여 출력합니다.

[동작 원리 및 Trace 예시]
N = 6, X = 4이고, 1번부터 6번 노드의 부모가 다음과 같을 때:
parent = [0, 1, 1, 2, 3, 5, 5] (1-based index)
- parent[1] = 1 (1번은 루트)
- parent[2] = 1
- parent[3] = 2
- parent[4] = 3
- parent[5] = 5 (5번은 루트)
- parent[6] = 5

X = 4의 루트 추적 단계 (Trace):
- 시작: curr = 4, hops = 0
  - parent[4] = 3 != 4 이므로 curr = 3, hops = 1
  - parent[3] = 2 != 3 이므로 curr = 2, hops = 2
  - parent[2] = 1 != 2 이므로 curr = 1, hops = 3
  - parent[1] = 1 == 1 (루트 발견! 반복 종료)
최종 루트는 1번 노드이고, 거쳐간 간선의 수(hops)는 3입니다.
출력: 1 3

[제약 사항]
1. 노드의 수 N은 1 이상 100 이하의 정수입니다 (1 <= N <= 100).
2. 조회할 노드 번호 X는 1 이상 N 이하의 정수입니다 (1 <= X <= N).
3. 부모 관계는 사이클이 없는 올바른 트리 구조를 만족합니다.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어집니다.
각 테스트 케이스의 첫 번째 줄에는 노드의 수 N과 대상 노드 X가 공백으로 구분되어 주어집니다.
두 번째 줄에는 1번부터 N번 노드까지의 직속 부모 번호를 나타내는 N개의 정수가 공백으로 구분되어 주어집니다.

[출력 형식]
각 테스트 케이스마다 '#tc'를 출력하고 한 칸 띄운 후, 최종 루트 노드의 번호와 거쳐간 간선 수(hops)를 공백으로 구분하여 출력합니다.
