[S/W 문제해결 기본] 서로소집합에 대해서 (D2)

[문제 설명]
서로소 집합(Disjoint Set, 또는 유니온 파인드 Union-Find) 자료구조 개념 및 동작 원리 설명:
서로소 집합은 공통 원소가 없는 여러 개의 상호 배타적인 집합들을 효율적으로 관리하는 트리 기반 자료구조입니다.
대표적인 연산은 두 가지입니다:
1. Find(x): 원소 x가 속한 집합의 대표자(Root)를 찾아 반환합니다. 경로 압축(Path Compression) 기법을 사용하면 트리의 높이가 거의 상수가 되어 O(알파(N)) 시간에 수행됩니다.
2. Union(a, b): 원소 a가 속한 집합과 원소 b가 속한 집합을 하나로 합칩니다. Root(a)와 Root(b)를 찾은 뒤 한쪽 루트의 부모를 다른 쪽 루트로 지정합니다.

[동작 과정 Trace 예시]
원소 {1, 2, 3, 4}에 대해 초기 상태: parent = [1, 2, 3, 4]
1단계: Union(1, 2) 수행 -> Find(1)=1, Find(2)=2 -> parent[2] = 1 -> 집합 {1, 2}, {3}, {4}
2단계: Union(3, 4) 수행 -> Find(3)=3, Find(4)=4 -> parent[4] = 3 -> 집합 {1, 2}, {3, 4}
3단계: Find(2) 호출 -> parent[2] = 1 반환 (동일 집합 확인)
4단계: Union(2, 4) 수행 -> Find(2)=1, Find(4)=3 -> parent[3] = 1 -> 집합 {1, 2, 3, 4}로 병합 완료

이것을 구현하라.
1부터 N까지 번호가 매겨진 N개의 원소가 있습니다. 초기에는 각 원소가 독립된 집합을 이룹니다.
M개의 연산이 주어질 때:
- 연산 0 a b: 원소 a가 속한 집합과 원소 b가 속한 집합을 합친다 (Union).
- 연산 1 a b: 원소 a와 b가 같은 집합에 속해 있는지 확인한다. 같으면 YES, 다르면 NO를 출력한다.

[제약 사항 (Java 전용)]
1. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내 (테스트케이스당 0.2초 이내)
2. 메모리 제한: 힙(Heap) 메모리 256MB 이내 (자바 전용)
3. 전체 원소의 수 N은 1 이상 100,000 이하의 자연수이다.
4. 연산의 수 M은 1 이상 100,000 이하의 자연수이다.
5. makeSet, findSet, unionSet의 표준 상호배타 집합 연산을 정확히 구현한다.

[입력]

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 원소의 개수 N(1 <= N <= 100,000)과 연산의 개수 M(1 <= M <= 100,000)이 주어진다.
다음 M개의 줄에 걸쳐 연산의 종류 op(0 또는 1), a, b가 주어진다.

[출력]

각 테스트 케이스마다 '#T'를 출력하고, 연산 1의 결과를 공백으로 구분하여 차례대로 출력한다.
