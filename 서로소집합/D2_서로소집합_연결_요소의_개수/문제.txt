[S/W 문제해결 기본] 연결 요소의 개수 (D2)

[문제 설명]
방향이 없는 무향 그래프가 주어졌을 때, 서로 연결되어 있는 정점들의 무리인 '연결 요소(Connected Component)'의 총 개수를 구하는 문제입니다.
서로소 집합(Disjoint Set)을 이용하면 그래프의 모든 간선 (u, v)에 대해 Union(u, v)를 수행한 뒤,
서로 다른 대표자(Root)의 총 개수를 세어 연결 요소의 개수를 O(M 알파(N))에 쉽게 계산할 수 있습니다.

정점의 개수 N과 간선의 개수 M이 주어질 때, 연결 요소의 개수를 구하라.

[제약 사항 (Java 전용)]
1. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내 (테스트케이스당 0.2초 이내)
2. 메모리 제한: 힙(Heap) 메모리 256MB 이내 (자바 전용)
3. 정점의 수 N은 1 이상 1,000 이하의 자연수이다.
4. 간선의 수 M은 0 이상 10,000 이하의 정수이다.
5. 서로소 집합을 이용하여 간선 정보를 합친 후 독립된 집합(루트 노드)의 총 개수를 센다.

[입력]

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 정점의 개수 N(1 <= N <= 10,000)과 간선의 개수 M(0 <= M <= 100,000)이 공백으로 주어진다.
다음 M개의 줄에 걸쳐 간선이 연결하는 두 정점 u, v가 주어진다. (1 <= u, v <= N)

[출력]

각 테스트 케이스마다 '#T'를 출력하고, 연결 요소의 개수를 정수로 출력한다.
