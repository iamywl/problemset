[문제 설명]

서로소 집합(Disjoint Set / Union-Find) 자료구조의 가장 밑바탕이 되는 데이터 모델은 바로 1차원 '부모 배열(parent[])'입니다.

1번부터 N번까지의 노드가 주어졌을 때, 처음에는 어떤 노드도 연결되어 있지 않으므로 각 노드는 자기 자신을 가리킵니다:
parent[i] = i (1 <= i <= N)

이 기초 단계에서는 복잡한 재귀 순회나 트리 경로 압축 없이, 부모 배열의 원소를 직접 대입하고 조회하는 기본 개념과 동작을 학습합니다:
- 연산 1: "1 a b"
- b 노드의 직속 부모를 a로 설정합니다. (단순 대입: parent[b] = a)
- 연산 2: "2 x"
- x 노드의 현재 직속 부모 값(parent[x])을 조회하여 출력 목록에 추가합니다.

주어진 M개의 연산을 순서대로 수행한 뒤, 2번 연산으로 조회된 값들을 공백으로 구분하여 출력하십시오.

[동작 원리 및 Trace 예시]
N = 5, M = 5 일 때 초기 상태:
parent = [0, 1, 2, 3, 4, 5] (1-based index)

1. 연산 "1 1 2": parent[2] = 1 (2번의 부모가 1로 변경됨)
parent = [0, 1, 1, 3, 4, 5]
2. 연산 "1 2 3": parent[3] = 2 (3번의 부모가 2로 변경됨)
parent = [0, 1, 1, 2, 4, 5]
3. 연산 "2 3": 3번 노드의 직속 부모 조회 -> parent[3] = 2 기록
4. 연산 "2 2": 2번 노드의 직속 부모 조회 -> parent[2] = 1 기록
5. 연산 "2 4": 4번 노드의 직속 부모 조회 -> parent[4] = 4 기록

최종 2번 연산의 결과들: 2 1 4
출력: 2 1 4

[제약 사항]

1. 노드의 수 N은 1 이상 100 이하의 정수입니다 (1 <= N <= 100).
2. 연산의 수 M은 1 이상 100 이하의 정수입니다 (1 <= M <= 100).
3. 2번 연산은 각 테스트 케이스마다 최소 1회 이상 주어집니다.

[입력 형식]

첫 번째 줄에 테스트 케이스의 수 T가 주어집니다.
각 테스트 케이스의 첫 번째 줄에는 노드의 수 N과 연산의 수 M이 공백으로 구분되어 주어집니다.
다음 M개의 줄에 걸쳐 각 연산("1 a b" 또는 "2 x")이 주어집니다.

[출력 형식]

각 테스트 케이스마다 '#tc'를 출력하고 한 칸 띄운 후, 2번 연산들의 조회 결과를 공백으로 구분하여 순서대로 출력합니다.
