[S/W 문제해결 기초] DFS에 대해서 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 깊이 우선 탐색(DFS)]
깊이 우선 탐색(Depth-First Search, DFS)은 그래프의 모든 정점을 탐색할 때, 한 갈림길을 선택하여 더 이상 갈 수 없을 때까지 최대한 깊이 들어간 후, 막히면 이전 갈림길로 되돌아와(Backtracking) 다른 경로를 탐색하는 방법입니다.
재귀 함수 호출(Recursion)의 시스템 콜 스택 또는 명시적 스택(Stack)을 기반으로 동작합니다.

DFS의 핵심 알고리즘 원리:
1. 현재 정점 u를 방문하고 visited[u] = true로 표시합니다.
2. u와 인접한 정점 v들을 순회하면서:
   - 만약 v를 아직 방문하지 않았다면(!visited[v]):
     - v를 시작점으로 하여 즉시 재귀적으로 DFS(v)를 호출합니다.
3. 더 이상 방문할 인접 정점이 없으면 재귀 호출이 반환되어 직전 정점으로 돌아옵니다.

[동작 과정 Trace 예시]
정점 1~4 (간선: 1-2, 1-3, 2-4)에서 1번부터 번호가 작은 순서대로 DFS 탐색:
- DFS(1) 시작: 1 방문 -> 인접 정점 2, 3 중 작은 2 선택 -> DFS(2) 호출
  - DFS(2) 시작: 2 방문 -> 인접 정점 4 선택 -> DFS(4) 호출
    - DFS(4) 시작: 4 방문 -> 미방문 인접 정점 없음 -> DFS(4) 종료 후 2로 복귀
  - DFS(2) 종료 후 1로 복귀
- 1의 다음 인접 정점 3 선택 -> DFS(3) 호출
  - DFS(3) 시작: 3 방문 -> 미방문 인접 정점 없음 -> DFS(3) 종료 후 1로 복귀
- DFS(1) 종료
최종 방문 순서는 1 2 4 3이 됩니다. 이것을 구현하여 DFS의 재귀 호출과 백트래킹 원리를 완벽히 체득하십시오.

[문제 설명]
1번부터 N번까지의 정점과 M개의 양방향 간선이 주어질 때, 1번 정점에서 출발하여 DFS로 방문하는 정점들의 순서를 공백으로 구분하여 출력하십시오 (인접 정점이 여러 개일 경우 번호가 작은 정점부터 먼저 방문합니다).

[제약 사항 (Java 전용)]
1. 정점의 수 N은 1 이상 1,000 이하의 자연수이다.
2. 간선의 수 M은 1 이상 10,000 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 정점의 수 N과 간선의 수 M이 공백으로 구분되어 주어진다.
이어지는 M개의 줄에 걸쳐 간선이 연결하는 두 정점 번호 u, v가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 1번 정점부터 DFS로 방문한 정점 번호들을 공백으로 구분하여 한 줄에 출력한다.
