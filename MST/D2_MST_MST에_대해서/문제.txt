[문제 설명]
최소 신장 트리(Minimum Spanning Tree, MST) 알고리즘 개념 및 동작 원리 설명:
신장 트리(Spanning Tree)는 무향 연결 그래프에서 모든 정점을 사이클 없이 연결하는 부분 그래프(Tree)입니다.
최소 신장 트리(MST)는 가능한 여러 신장 트리들 중 사용된 간선들의 가중치(Weight) 합이 최소가 되는 트리입니다.
MST를 구하는 대표적인 두 알고리즘:
1. 크루스칼(Kruskal) 알고리즘: 간선들을 가중치 오름차순으로 정렬한 뒤, 사이클을 형성하지 않는(서로소 집합 Find(u) != Find(v)) 간선들을 탐욕적으로 N-1개 선택합니다. 시간 복잡도: $O(M \log M)$.
2. 프림(Prim) 알고리즘: 임의의 한 정점에서 시작하여, 현재 트리에 연결된 간선 중 아직 방문하지 않은 정점으로 가는 최소 가중치 간선을 우선순위 큐로 선택해 나갑니다. 시간 복잡도: $O(M \log N)$.

[동작 과정 Trace 예시]
정점 4개(1, 2, 3, 4), 간선 5개:
(1, 2, w=1), (2, 3, w=2), (1, 3, w=3), (3, 4, w=4), (2, 4, w=5)
1단계: 간선 정렬 -> [(1, 2, 1), (2, 3, 2), (1, 3, 3), (3, 4, 4), (2, 4, 5)]
2단계: (1, 2, 1) 선택 -> 사이클 없음 -> 선택 (누적 가중치: 1, 선택 수: 1)
3단계: (2, 3, 2) 선택 -> 사이클 없음 -> 선택 (누적 가중치: 3, 선택 수: 2)
4단계: (1, 3, 3) 검사 -> Find(1) == Find(3) (이미 연결됨, 사이클 형성) -> 제외!
5단계: (3, 4, 4) 선택 -> 사이클 없음 -> 선택 (누적 가중치: 7, 선택 수: 3 = N-1) -> 탐색 종료!
최종 MST 가중치 합 = 7.

이것을 구현하라.
주어지는 무향 연결 그래프의 최소 신장 트리의 총 가중치 합을 구하라.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 정점 수 V(1 <= V <= 10,000)와 간선 수 E(1 <= E <= 100,000)가 공백으로 주어진다.
다음 E개의 줄에 걸쳐 간선의 정보 u, v, w(1 <= u, v <= V, 1 <= w <= 1,000,000)가 주어진다.

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, MST의 총 가중치 합을 정수로 출력한다.
