[S/W 문제해결 기초] 앞뒤 대칭 팰린드롬 검사 (D2)

[문제 설명 및 개념]
덱(Deque)은 양방향 입출력이 가능하여 앞과 뒤에서 동시에 원소를 꺼내어 대칭성을 검사하는 문제에 가장 최적화된 자료구조입니다.
문자열이 앞에서부터 읽으나 뒤에서부터 읽으나 동일한 경우를 '회문(Palindrome)'이라고 합니다.

문자열의 모든 문자를 덱에 순서대로 넣은 뒤, 덱의 길이가 2 이상인 동안 `pollFirst()`와 `pollLast()`로 양 끝 문자를 동시에 꺼내어 일치하는지 비교합니다.
만약 꺼낸 두 문자가 서로 다르면 회문이 아니므로 0을 출력하고, 덱이 빌 때까지 모든 쌍이 일치하면 1을 출력하십시오.

[동작 과정 Trace 예시]
문자열 "level" 검사:
- 덱 초기화: ['l', 'e', 'v', 'e', 'l']
- 1단계: pollFirst() -> 'l', pollLast() -> 'l' (일치) -> 덱 남은 상태: ['e', 'v', 'e']
- 2단계: pollFirst() -> 'e', pollLast() -> 'e' (일치) -> 덱 남은 상태: ['v']
- 3단계: 덱 길이 1 이하로 검사 종료 -> 회문 판정 (출력: 1)

[제약 사항 (Java 전용)]
1. 문자열의 길이 N은 1 이상 1,000 이하이다.
2. 문자열은 알파벳 소문자로만 구성된다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 테스트케이스의 개수 T가 주어진다.
각 테스트케이스는 두 줄로 구성되며, 첫 줄에 문자열의 길이 N, 둘째 줄에 문자열이 주어진다.

[출력]
각 테스트케이스마다 '#tc'와 공백을 출력한 후, 주어진 문자열이 회문이면 1, 아니면 0을 출력한다.
