[S/W 문제해결 기초] 카드 셔플과 뒤집기 (D2)

[문제 설명 및 원리]
덱(Deque)을 사용하면 앞과 뒤에서 원소를 조작할 수 있으므로, 카드를 위에서 뽑아 아래로 넣거나 전체 덱을 가상으로 뒤집는 연산을 효율적으로 구현할 수 있습니다.
1부터 N까지의 번호가 적힌 N장의 카드가 위에서부터 1, 2, ..., N 순서로 놓여 있습니다.
M개의 셔플 명령어가 차례로 주어질 때 최종적으로 맨 위에 있는 카드와 맨 아래에 있는 카드의 번호를 구하십시오.

명령어의 종류:
1. `TOP_TO_BOTTOM`: 맨 위의 카드를 1장 꺼내어 맨 아래로 넣습니다.
2. `BOTTOM_TO_TOP`: 맨 아래의 카드를 1장 꺼내어 맨 위로 넣습니다.
3. `REVERSE`: 카드 더미의 순서를 완전히 뒤집습니다. (맨 위가 맨 아래가 됨)

[동작 과정 Trace 예시]
N=5 (초기 카드: [1, 2, 3, 4, 5], 맨 위=1, 맨 아래=5):
- `TOP_TO_BOTTOM` -> 맨 위 1을 맨 아래로 -> [2, 3, 4, 5, 1]
- `REVERSE` -> 뒤집기 -> [1, 5, 4, 3, 2]
- `BOTTOM_TO_TOP` -> 맨 아래 2를 맨 위로 -> [2, 1, 5, 4, 3]
최종 맨 위 카드: 2, 맨 아래 카드: 3

[제약 사항 (Java 전용)]

1. 카드의 수 N은 2 이상 1,000 이하의 자연수이다.
2. 명령어의 수 M은 1 이상 1,000 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 첫 줄에 카드의 수 N과 명령어의 수 M이 주어진다.
이어지는 M개의 줄에 걸쳐 명령어가 한 줄에 하나씩 주어진다.

[출력]

각 테스트케이스마다 '#tc'와 공백을 출력한 후, 최종 맨 위에 있는 카드의 번호와 맨 아래에 있는 카드의 번호를 공백으로 구분하여 출력한다.
