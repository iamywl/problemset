[S/W 문제해결 기초] 재귀에 대해서 (D2)

[알고리즘 개념 및 동작 원리 학습 - 재귀 호출(Recursion)]
재귀(Recursion)란 어떤 함수가 자기 자신을 다시 호출하여 문제를 더 작은 하위 문제(Subproblem)로 쪼개어 해결하는 프로그래밍 기법입니다.
재귀 함수를 올바르게 작성하기 위해서는 반드시 두 가지 핵심 요소가 존재해야 합니다:
1. `Base Case (기저 조건 / 탈출 조건)`: 더 이상 재귀 호출을 진행하지 않고 즉시 값을 반환하여 무한 루프(스택 오버플로우)를 방지하는 종료 조건입니다.
2. `Recursive Step (유도 단계)`: 원래 문제를 더 작은 단위의 하위 문제로 축소시키며 자기 자신을 호출하는 단계입니다.

함수가 호출될 때마다 컴퓨터 시스템 메모리의 호출 스택(Call Stack)에 함수의 지역 변수와 복귀 주소가 차곡차곡 쌓이며, 기저 조건에 도달하면 스택의 상단부터 결과가 반환(Return)되며 원래 위치로 거슬러 올라옵니다.

[동작 과정 Trace 예시]
자연수 N에 대하여 N! (팩토리얼)을 계산하는 재귀 함수 factorial(N):
- factorial(4) 호출 -> 4 * factorial(3) 대기 (스택에 4 저장)
- factorial(3) 호출 -> 3 * factorial(2) 대기 (스택에 3 저장)
- factorial(2) 호출 -> 2 * factorial(1) 대기 (스택에 2 저장)
- factorial(1) 호출 -> Base Case 도달! 1 반환 (복귀 시작)
- factorial(2) 복귀 -> 2 * 1 = 2 반환
- factorial(3) 복귀 -> 3 * 2 = 6 반환
- factorial(4) 복귀 -> 4 * 6 = 24 최종 반환!

[문제 설명]
주어지는 자연수 N에 대하여, N부터 1까지 1씩 감소하며 재귀 호출을 수행하여 각 단계의 값을 공백으로 출력(하강 Trace)한 뒤, 기저 조건(1)에 도달한 후 1부터 N까지의 합계(Sum)와 N!(팩토리얼) 값을 순수 재귀 함수로 계산하여 출력하십시오!

[제약 사항 (Java 전용)]
1. 자연수 N은 1 이상 15 이하이다.
2. for문이나 while문 같은 반복문을 일절 사용하지 않고, 오직 재귀 함수만을 활용하여 구현해야 한다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 한 줄에 자연수 N이 주어진다.

[출력]
각 테스트케이스마다 '#tc'와 공백을 출력한 후, N부터 1까지의 재귀 호출 과정(공백 구분), 그리고 N까지의 합계와 팩토리얼 값을 공백으로 구분하여 출력한다.
형식: `#tc trace_values... sum factorial`
