[S/W 문제해결 응용] 이준이의 프랙탈 도형 블록 쌓기 (D3)

[문제 설명]

초등학생 이준이는 장난감 사각 블록을 가지고 프랙탈 카펫 패턴을 조립하고 있습니다.
3^K x 3^K 크기의 정사각형 판에서, 정중앙의 3^{K-1} x 3^{K-1} 영역은 블록을 비워두고, 나머지 8개의 영역은 다시 동일한 규칙의 프랙탈 패턴으로 채웁니다.
이준이는 임의의 좌표 (r, c) (0-indexed, 0 <= r, c < 3^K)에 블록이 채워져 있는지 알고 싶어합니다.

재귀적 영역 분할을 통해, (r, c) 위치에 블록이 채워져 있다면 1, 빈 공간이라면 0을 판별하는 함수를 구현하십시오.

[제약 사항 (Java 전용)]

1. 프랙탈의 차수 K는 1 이상 10 이하의 자연수이다.
2. 행 번호 r과 열 번호 c는 0 이상 3^K - 1 이하의 정수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 한 줄에 K, r, c가 공백으로 구분되어 주어진다.

[출력]

각 테스트케이스마다 '#tc'와 공백을 출력한 후, 해당 좌표에 블록이 있으면 1, 없으면 0을 출력한다.
