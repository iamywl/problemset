[S/W 문제해결 응용] KMP 알고리즘을 이용한 부분문자열 탐색 (D3)

[알고리즘 개념 및 원리 학습 - KMP 알고리즘(Knuth-Morris-Pratt Algorithm, CLRS 32.4)]
문자열 매칭(String Matching)은 길이가 N인 본문 텍스트 T 안에서 길이가 M인 패턴 P가 출현하는 위치를 찾는 고전적인 컴퓨터 과학 문제입니다.

1. 단순 비교(Naive Approach)의 한계:
- 본문의 모든 위치 i에 대해 패턴을 처음부터 대조하는 무차별 대입 방식은 최악의 경우(예: 'AAAA...A'에서 'AAAB'를 찾을 때) O(N * M)의 시간 복잡도를 가집니다.
- 본문의 길이가 100,000이고 패턴의 길이가 10,000일 때 10억 번의 연산이 발생하여 시간 초과(TLE)에 직면합니다.

2. KMP 알고리즘의 핵심 원리:
- KMP 알고리즘은 불일치가 발생했을 때, 지금까지 일치했던 앞부분의 정보를 버리지 않고 재활용하여 텍스트의 포인터를 뒤로 되돌리지 않고 전진만 시킵니다.
- 이를 위해 패턴 P의 실패 함수(Failure Function) 또는 pi(π) 배열을 미리 전처리합니다:
  pi[i]: 패턴의 0번부터 i번까지의 부분문자열 중 접두사(Prefix)이면서 동시에 접미사(Suffix)가 되는 가장 긴 부분문자열의 길이 (단, 전체 자기 자신은 제외)
- pi 배열 전처리 시간 복잡도: O(M)
- 텍스트 탐색 과정:
  * T[i]와 P[j]가 일치하면 i와 j를 1씩 증가시킵니다.
  * 불일치가 발생하면, j를 pi[j-1]로 점프시켜 일치할 가능성이 있는 가장 긴 접두사 위치로 이동합니다 (j == 0이 될 때까지 반복).
  * 패턴 전체가 매칭되면(j == M-1), 결과에 반영한 후 다음 중첩 매칭을 위해 j를 pi[j]로 갱신하여 탐색을 이어갑니다.
- 전체 탐색 시간 복잡도: O(N + M)으로 매우 빠릅니다.

[문제 설명]
SSAFY 검색 엔진 팀에서 텍스트 문서 T 내에서 검색 키워드 패턴 P가 총 몇 번 등장하는지, 그리고 가장 먼저 등장하는 시작 위치(1-based 인덱스)가 어디인지 빠르게 확인하는 기능을 구현하고자 합니다.
패턴이 중첩되어 등장하는 경우(예: "AAAA"에서 "AA"는 1, 2, 3번 위치에 총 3회 등장)도 모두 카운트합니다.
본문 T와 패턴 P가 주어질 때, 패턴의 총 등장 횟수와 첫 등장 위치를 구하는 프로그램을 작성하십시오.
(만약 본문에서 패턴이 한 번도 나타나지 않는다면 총 등장 횟수는 0, 첫 등장 위치는 -1을 출력합니다.)

[제약 사항 (Java 전용)]
1. 본문 텍스트 T의 길이는 1 이상 100,000 이하이다. (1 <= |T| <= 100,000)
2. 패턴 P의 길이는 1 이상 10,000 이하이며, |P| <= |T| 이다. (1 <= |P| <= 10,000)
3. 본문 텍스트 T와 패턴 P는 알파벳 대소문자(A-Z, a-z)로만 구성되며 공백은 포함되지 않는다. 대소문자를 구분한다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 본문 텍스트 T가 주어진다.
둘째 줄에 패턴 문자열 P가 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 패턴의 총 등장 횟수(cnt)와 첫 번째 등장 위치(pos, 1-based)를 공백으로 구분하여 한 줄에 출력한다. (패턴이 미발견될 경우 '0 -1' 출력)
