[S/W 문제해결 응용] 음식물 피하기 (D3)

통로의 크기가 N×M인 건물이 있다.
통로의 곳곳에 음식물 쓰레기가 떨어져 있다.
음식물 쓰레기들이 상, 하, 좌, 우로 인접해 있으면 서로 뭉쳐서 하나의 큰 음식물 쓰레기 덩어리를 만든다.
음식물 쓰레기 덩어리들 중 가장 큰 덩어리의 크기(속한 칸의 수)를 구하는 프로그램을 작성하라.
음식물 쓰레기가 전혀 없다면 0을 출력한다.

[제약 사항 (Java 전용)]
1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. N과 M은 2 이상 20 이하의 정수이다.

[입력]
첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N, M, 그리고 음식물 쓰레기의 개수 K가 주어진다.
다음 K개의 줄에 걸쳐 음식물 쓰레기가 떨어진 좌표 (r, c)가 주어진다. (1 <= r <= N, 1 <= c <= M)

[출력]
각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 가장 큰 음식물 덩어리의 크기를 출력한다.
