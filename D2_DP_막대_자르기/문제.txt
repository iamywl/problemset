[S/W 문제해결 기초] 막대 자르기 (D2)

[알고리즘 개념 및 원리 학습 - 막대 자르기(Rod Cutting, CLRS 15.1)]
길이가 N인 하나의 긴 쇠막대가 있습니다. 이 막대를 정수 길이의 조각들로 자유롭게 잘라서 시장에 판매할 수 있습니다.
길이가 i인 막대 조각의 판매 가격이 p_i로 정해져 있을 때, 막대를 적절히 잘라서 얻을 수 있는 '최대 판매 금액'을 구하는 문제입니다.

[최적 부분 구조 및 점화식 도출]
길이 n의 막대를 자를 때 첫 번째 조각의 길이를 i (1 <= i <= n)로 정한다면, 남은 부분의 길이는 (n - i)가 됩니다.
따라서 길이 n에서 얻을 수 있는 최대 수익 r_n은 가능한 모든 첫 조각 길이 i에 대해:
r_n = max_{1 <= i <= n} (p_i + r_{n-i})  (단, r_0 = 0)
이 점화식을 상향식(Bottom-up)으로 작은 길이부터 차례대로 DP 테이블을 채워나가면 O(N^2) 시간에 최적해를 구할 수 있습니다.

예를 들어, 길이 4 막대이고 p = [0, 1, 5, 8, 9] 일 때:
- r_1 = max(p_1 + r_0) = 1
- r_2 = max(p_1 + r_1, p_2 + r_0) = max(1+1, 5+0) = 5
- r_3 = max(p_1 + r_2, p_2 + r_1, p_3 + r_0) = max(1+5, 5+1, 8+0) = 8
- r_4 = max(p_1 + r_3, p_2 + r_2, p_3 + r_1, p_4 + r_0) = max(1+8, 5+5, 8+1, 9+0) = 10 (길이 2짜리 2개로 자름)

[문제 설명]
막대의 길이 N과 각 길이 1부터 N까지의 판매 가격 p_1, p_2, ..., p_N이 주어질 때, 막대를 잘라 얻을 수 있는 최대 수익을 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. 막대의 길이 N은 1 이상 1,000 이하의 자연수이다.
2. 각 가격 p_i는 1 이상 10,000 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 막대의 길이 N이 주어진다.
둘째 줄에 길이 1부터 N까지의 가격 p_1, ..., p_N이 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 최대 판매 수익을 출력한다.
