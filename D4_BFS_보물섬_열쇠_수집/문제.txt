[S/W 문제해결 심화] 보물섬 열쇠 수집 (D4)

N×M 크기의 보물섬 지도가 있다.
지도에서 0은 빈 통로, 1은 벽, 2는 출발점, 3은 보물상자(도착점)이다.
또한 섬 안에는 3개의 비밀 열쇠가 숨겨져 있다:
  - 4: 열쇠 A
  - 5: 열쇠 B
  - 6: 열쇠 C
보물상자를 열기 위해서는 순서에 상관없이 3개의 열쇠(A, B, C)를 모두 획득한 후에만 보물상자(3)에 들어갈 수 있다.
(열쇠 3개를 모두 획득하기 전에는 보물상자(3) 칸으로 이동하거나 지나갈 수 없다.)
출발점에서 출발하여 3개의 열쇠를 모두 수집하고 보물상자에 도착하는 최소 이동 칸수를 구하라.
도달할 수 없는 경우에는 -1을 출력한다.

[제약 사항 (Java 전용)]
1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. N과 M은 4 이상 12 이하의 자연수이다.

[입력]
첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 M이 주어진다.
다음 N개의 줄에 걸쳐 각 줄마다 M자리 문자열(0, 1, 2, 3, 4, 5, 6)이 주어진다.

[출력]
각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 최소 이동 칸수를 출력한다. 불가능 시 -1.
