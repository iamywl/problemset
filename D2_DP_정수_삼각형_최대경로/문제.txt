[S/W 문제해결 기초] 정수 삼각형 최대경로 (D2)

[알고리즘 개념 및 원리 학습 - 2차원 DP 테이블 채우기]
정수들이 삼각형 모양으로 배치되어 있습니다. 꼭대기(1층)에서 시작하여 아래층으로 한 칸씩 내려올 때, 대각선 왼쪽 아래 또는 대각선 오른쪽 아래로만 이동할 수 있습니다.
바닥 층까지 도달했을 때 지나온 수들의 합의 최댓값을 구하는 문제입니다.

[점화식 및 원리]
삼각형의 i행 j열에 위치한 원소를 `tri[i][j]`라고 하고, 해당 위치까지 도달하는 경로 합의 최댓값을 `dp[i][j]`라고 합시다.
(i, j) 칸으로 올 수 있는 직전 위치는 위층의 (i-1, j-1) 또는 (i-1, j) 뿐입니다.
따라서 점화식은 다음과 같습니다:
- 맨 왼쪽 열(j=0): dp[i][0] = dp[i-1][0] + tri[i][0]
- 맨 오른쪽 열(j=i): dp[i][i] = dp[i-1][i-1] + tri[i][i]
- 내부 칸(0 < j < i): dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + tri[i][j]

바닥 층(N-1행)에 도달한 후, dp[N-1] 행의 값들 중 최댓값을 취하면 전체 최적해가 됩니다.

[문제 설명]
삼각형의 높이 N과 삼각형을 이루는 정수들이 주어질 때, 꼭대기부터 바닥까지 이어지는 경로 중 수들의 합이 최대가 되는 값을 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. 삼각형의 높이 N은 1 이상 500 이하의 자연수이다.
2. 각 정수는 0 이상 9,999 이하의 정수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 삼각형의 크기 N이 주어진다.
둘째 줄부터 N개의 줄에 걸쳐 각 층의 정수들이 공백으로 구분되어 주어진다. (i번째 줄에는 i개의 정수)

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 경로 합의 최댓값을 출력한다.
