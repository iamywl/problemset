[S/W 문제해결 기초] 연결리스트에 대해서 (D2)

[자료구조 개념 및 동작 원리 학습 - 연결 리스트(Linked List)]
연결 리스트(Linked List)는 데이터 원소들이 메모리상에 물리적으로 연속해 저장되지 않고, 각 노드(Node)가 자신의 데이터(Data)와 다음 노드를 가리키는 포인터(Next Pointer)를 함께 보관하며 사슬처럼 연결된 선형 자료구조입니다.
배열(Array)과 달리 중간에 원소를 삽입하거나 삭제할 때 뒤쪽의 모든 원소를 밀거나 당길 필요가 없으므로, 삽입/삭제할 위치의 포인터만 갱신하면 O(1) 시간에 효율적으로 구조를 변경할 수 있는 장점이 있습니다.

단일 연결 리스트(Singly Linked List)에서 제공하는 6가지 핵심 연산은 다음과 같습니다:
1. `insert_front X`: 정수 X를 리스트의 맨 앞(Head)에 삽입합니다.
2. `insert_back X`: 정수 X를 리스트의 맨 뒤(Tail)에 삽입합니다.
3. `insert_at K X`: 인덱스 K(0-indexed) 위치에 정수 X를 삽입합니다. (K가 리스트 크기보다 크면 맨 뒤에 삽입)
4. `delete_at K`: 인덱스 K 위치의 노드를 삭제하고 그 노드의 값을 출력합니다. (인덱스가 유효하지 않으면 -1 출력)
5. `get_at K`: 인덱스 K 위치의 노드 값을 출력합니다. (인덱스가 유효하지 않으면 -1 출력)
6. `size`: 현재 리스트에 존재하는 노드의 총 개수를 출력합니다.

[동작 과정 Trace 예시]
이 자료구조를 구현하면 다음과 같은 단계별 과정을 거치게 됩니다:
- 초기 상태: List = [] (size = 0)
- insert_back 10 수행 -> List = [10]
- insert_front 20 수행 -> List = [20, 10]
- insert_at 1 30 수행 -> List = [20, 30, 10] (인덱스 1 자리에 30 삽입)
- get_at 1 수행 -> 인덱스 1의 값 30 확인 및 출력
- size 수행 -> 현재 노드 수 3 출력
- delete_at 1 수행 -> 인덱스 1의 30 노드 삭제 및 30 출력 -> List = [20, 10]
- delete_at 5 수행 -> 유효하지 않은 인덱스이므로 -1 출력
- get_at 0 수행 -> 인덱스 0의 값 20 출력

[문제 설명]

주어지는 N개의 명령어를 순서대로 처리하여 그 결과를 출력하는 단일 연결 리스트 프로그램을 직접 구현하십시오!

[제약 사항 (Java 전용)]

1. 주어지는 명령의 수 N은 1 이상 1,000 이하의 자연수이다.
2. 삽입되는 정수 X는 1 이상 100,000 이하의 자연수이다.
3. 인덱스 K는 0 이상 10,000 이하의 정수이다.
4. 출력을 요구하는 연산(delete_at, get_at, size)의 결과를 공백으로 구분하여 한 줄에 출력한다.
5. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
6. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 첫 줄에 명령의 수 N이 주어진다.
이어지는 N개의 줄에 걸쳐 명령어가 한 줄에 하나씩 주어진다.

[출력]

각 테스트케이스마다 '#tc'와 공백을 출력한 후, 출력을 요구하는 연산들의 결과를 공백으로 구분하여 한 줄에 출력한다. (출력 결과가 없다면 빈 줄)
