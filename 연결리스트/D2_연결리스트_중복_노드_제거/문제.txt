[S/W 문제해결 기초] 중복 노드 제거 (D2)

[문제 설명 및 원리]
오름차순으로 정렬된 정수 단일 연결 리스트가 주어집니다.
리스트를 순회하면서 연속하여 나타나는 동일한 값의 중복 노드를 하나만 남기고 모두 삭제하십시오.
연결 리스트에서는 `cur.val == cur.next.val`인 경우, `cur.next = cur.next.next`로 링크를 건너뜀으로써 노드를 간결하게 제거할 수 있습니다.

중복이 제거된 최종 연결 리스트의 원소들을 순서대로 출력하십시오.

[동작 과정 Trace 예시]
입력 리스트: 1 -> 1 -> 2 -> 3 -> 3
- cur=1: cur.next.val == 1 이므로 중복 -> cur.next = cur.next.next (링크 2로 연결) -> 1 -> 2 -> 3 -> 3
- cur=1: cur.next.val == 2 이므로 서로 다름 -> cur = cur.next (cur=2로 이동)
- cur=2: cur.next.val == 3 이므로 서로 다름 -> cur = cur.next (cur=3으로 이동)
- cur=3: cur.next.val == 3 이므로 중복 -> cur.next = null -> 1 -> 2 -> 3
최종 결과: 1 2 3

[제약 사항 (Java 전용)]

1. 노드의 개수 N은 1 이상 1,000 이하의 자연수이다.
2. 입력되는 노드 값들은 오름차순으로 정렬되어 있으며, 1 이상 10,000 이하의 정수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 첫 줄에 노드의 개수 N이 주어진다.
둘째 줄에 정렬된 N개의 정수가 공백으로 구분되어 주어진다.

[출력]

각 테스트케이스마다 '#tc'와 공백을 출력한 후, 중복이 제거된 연결 리스트의 값들을 공백으로 구분하여 출력한다.
