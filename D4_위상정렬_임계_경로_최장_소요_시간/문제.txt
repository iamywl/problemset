[문제 설명]
임계 경로(Critical Path) 기법은 대규모 건설 및 소프트웨어 프로젝트에서 전체 작업이 완료되는 최단 완료 시간(즉, 선행 제약으로 인한 최장 경로의 길이)을 계산하는 핵심 알고리즘입니다.
프로젝트의 각 작업 단계 간에 소요 시간 w를 갖는 방향 간선 u -> v 가 주어집니다.
시작 작업(Start)에서 목표 작업(End)까지 도달하는 데 걸리는 '가장 긴 소요 시간'을 위상 정렬 DAG 최장 경로 알고리즘으로 구하라.
$$dist[v] = \max_{(u \to v)} (dist[u] + w)$$

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 작업 노드 수 N(2 <= N <= 10,000)과 작업 관계 수 M(1 <= M <= 50,000)이 주어진다.
다음 M개의 줄에 출발 작업 u, 도착 작업 v, 소요 시간 w(1 <= w <= 1,000)가 주어진다.
마지막 줄에 시작 작업 Start와 목표 작업 End가 주어진다.

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, 시작 작업부터 목표 작업까지의 최장 소요 시간을 정수로 출력한다.
