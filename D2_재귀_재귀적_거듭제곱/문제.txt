[S/W 문제해결 기초] 재귀적 거듭제곱 (D2)

[문제 설명 및 원리]
자연수 C와 N이 주어질 때, $C^N$을 재귀 호출을 이용하여 계산하는 문제입니다.
기저 조건: $N = 0$일 때 결과는 1입니다.
유도 단계: $C^N = C \times C^{N-1}$ 형태로 자기 자신을 재귀 호출하여 곱해 나갑니다.
반복문 없이 순수 재귀 함수로 구현하십시오.

결과가 매우 커질 수 있으므로 $1,000,000,007$로 나눈 나머지를 출력합니다.

[동작 과정 Trace 예시]
C=2, N=4 계산:
- power(2, 4) -> 2 * power(2, 3)
- power(2, 3) -> 2 * power(2, 2)
- power(2, 2) -> 2 * power(2, 1)
- power(2, 1) -> 2 * power(2, 0)
- power(2, 0) -> Base Case: 1 반환
- 역순으로 2, 4, 8, 16이 계산되어 최종 16 반환.

[제약 사항 (Java 전용)]
1. 밑 C는 1 이상 1,000 이하의 자연수이다.
2. 지수 N은 0 이상 1,000 이하의 정수이다.
3. 모든 연산은 모듈러 $1,000,000,007$을 취한다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 한 줄에 밑 C와 지수 N이 공백으로 주어진다.

[출력]
각 테스트케이스마다 '#tc'와 공백을 출력한 후, $C^N \pmod{1,000,000,007}$ 값을 출력한다.
