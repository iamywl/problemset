[S/W 문제해결 응용] 포함배제의 원리 상한 제한 중복조합 (D4)

[복합 제약조건 및 알고리즘 최적화]
방정식 x_1 + x_2 + ... + x_N = S 에 대하여, 각 변수 x_i가 상한선 조건 `0 <= x_i <= M`을 만족하는 음이 아닌 정수해의 개수를 구해야 합니다.

일반 중복조합(nH S)은 상한선이 없지만, 여기서는 어떤 변수가 M을 초과하는(x_i >= M + 1) 조건을 배제해야 합니다.
변수의 개수 N이 최대 10 이하일 때, 다음 조합론적 최적화를 적용합니다:
1. 2^N가지의 부분집합 비트마스크(mask)를 순회합니다.
2. mask에서 k개의 변수가 각각 M+1 이상인 사건을 나타낼 때:
   - 잔여 합 `S' = S - k * (M + 1)`을 계산합니다.
   - 만약 S' >= 0 이라면 그 경우의 수는 `nH S' = (N + S' - 1) C S'`가 됩니다.
3. 포함-배제의 원리(Inclusion-Exclusion Principle)에 의해, k가 홀수이면 빼고(-), 짝수이면 더하여(+) 정확한 해의 개수를 mod 1,000,000,007로 산출합니다.

[문제 설명]
N, S, M이 주어질 때 0 <= x_i <= M 을 만족하는 정수해 x_1 + ... + x_N = S의 개수를 1,000,000,007로 나눈 나머지를 구하십시오.

[제약 사항 (Java 전용)]
1. 변수의 개수 N은 1 이상 10 이하의 자연수이다.
2. 합 S는 1 이상 2,000 이하의 자연수이다.
3. 상한선 M은 1 이상 S 이하의 자연수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N, S, M이 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 조건을 만족하는 정수해 개수 mod 1,000,000,007을 정수로 출력한다.
