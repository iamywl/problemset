[S/W 문제해결 기초] 중복조합에 대해서 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 중복조합(Combination with Repetition)]
중복조합(Combination with repetition)이란 서로 다른 N개의 원소 중에서 '중복을 허용하여' R개를 택할 때, 순서를 고려하지 않고 선택하는 것을 말합니다.
기호로는 nHr로 표기하며, 칸막이(Divider) 모델을 통해 다음과 같이 일반 조합으로 변환하여 계산합니다:
nHr = (n + r - 1)Cr

중복조합을 재귀 호출(Backtracking)로 구현할 때는, 오름차순(비내림차순)을 유지하기 위해 다음 단계로 넘어갈 때 시작 인덱스(start)를 `i + 1`이 아닌 `i`로 그대로 넘겨주어 현재 선택한 원소를 다시 선택할 수 있도록 허용합니다:
1. 현재 depth가 R에 도달하면 중복조합 하나가 완성된 것이므로 결과를 출력합니다.
2. start 위치부터 N까지의 숫자를 순회하며 숫자를 선택합니다.
3. 다음 재귀 호출(depth + 1)을 할 때, 시작 인덱스를 `i`로 유지하여 동일한 원소의 중복 선택을 허용합니다.

[동작 과정 Trace 예시]
N=3, R=2인 경우, 1부터 3까지의 숫자 중 중복을 허용하여 2개를 고르는 과정:
- depth 0, start 1:
- 1 선택 -> depth 1, start 1: [1, 1], [1, 2], [1, 3] 완성
- depth 0, start 2:
- 2 선택 -> depth 1, start 2: [2, 2], [2, 3] 완성
- depth 0, start 3:
- 3 선택 -> depth 1, start 3: [3, 3] 완성
총 3H2 = (3+2-1)C2 = 4C2 = 6가지 중복조합이 사전순으로 생성됩니다. 이것을 구현하여 중복조합의 원리를 완벽히 체득하십시오.

[문제 설명]

1부터 N까지의 자연수 중에서 중복을 허용하여 R개를 고른 모든 중복조합을 사전 순으로 출력하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. N과 R은 자연수이며, 1 <= R <= N <= 8 이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N과 R이 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 첫 줄에 '#tc'를 출력하고, 다음 줄부터 생성된 중복조합을 한 줄에 하나씩 공백으로 구분하여 사전 순으로 출력한다.
