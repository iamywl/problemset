[S/W 문제해결 기초] 큐에 대해서 (D2)

[자료구조 개념 및 동작 원리 학습 - 큐(Queue)]
큐(Queue)는 은행이나 놀이공원의 '대기 줄'처럼 가장 먼저 들어온 데이터가 가장 먼저 나가는 선입선출(FIFO: First In First Out) 구조의 대표적인 선형 자료구조입니다.
한쪽 끝인 뒤쪽(Rear)에서는 새로운 데이터의 삽입(Offer/Push)만 발생하고, 반대쪽 끝인 앞쪽(Front)에서는 데이터의 삭제(Poll/Pop)만 일어납니다.
프린터의 출력 대기열, 키보드 입력 버퍼, 너비 우선 탐색(BFS)의 방문 노드 관리 등이 모두 큐의 대표적인 사례입니다.

큐에서 제공하는 6가지 핵심 연산은 다음과 같습니다:
1. `offer X`: 정수 X를 큐의 맨 뒤(Rear)에 삽입합니다.
2. `poll`: 큐의 맨 앞(Front)에 있는 정수를 꺼내어 반환합니다. 만약 큐가 비어있다면 -1을 반환합니다.
3. `size`: 현재 큐에 들어있는 정수의 총 개수를 반환합니다.
4. `empty`: 큐가 비어있으면 1, 비어있지 않으면 0을 반환합니다.
5. `front`: 큐의 맨 앞(Front)에 있는 정수를 꺼내지 않고 확인만 합니다. 만약 큐가 비어있다면 -1을 반환합니다.
6. `back`: 큐의 맨 뒤(Rear)에 있는 정수를 꺼내지 않고 확인만 합니다. 만약 큐가 비어있다면 -1을 반환합니다.

[동작 과정 Trace 예시]
이 자료구조를 구현하면 다음과 같은 단계별 과정을 거치게 됩니다:
- 초기 상태: Queue = []
- offer 10 수행 -> Queue = [10] (Front=10, Back=10)
- offer 20 수행 -> Queue = [10, 20] (Front=10, Back=20)
- front 수행 -> 맨 앞의 10 확인 및 출력
- back 수행 -> 맨 뒤의 20 확인 및 출력
- poll 수행 -> 맨 앞의 10을 꺼내어 출력 (Queue = [20])
- size 수행 -> 현재 원소 개수인 1 출력
- empty 수행 -> 큐가 비어있지 않으므로 0 출력
- poll 수행 -> 맨 앞의 20을 꺼내어 출력 (Queue = [])
- poll 수행 -> 큐가 비어있으므로 -1 출력

[문제 설명]
주어지는 N개의 명령어를 순서대로 처리하여 그 결과를 출력하는 큐 프로그램을 직접 구현하십시오!

[제약 사항 (Java 전용)]
1. 주어지는 명령의 수 N은 1 이상 1,000 이하의 자연수이다.
2. offer 연산으로 주어지는 정수 X는 1 이상 100,000 이하의 자연수이다.
3. 출력해야 하는 연산(poll, size, empty, front, back)의 결과들을 공백으로 구분하여 한 줄로 출력한다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 명령의 수 N이 주어진다.
이어지는 N개의 줄에 걸쳐 명령어가 한 줄에 하나씩 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 출력을 요구하는 각 연산(poll, size, empty, front, back)의 결과를 공백으로 구분하여 한 줄에 출력한다.
