[문제 설명]
시아는 R x C 크기의 지도에서 바다(0)와 육지(1)를 관리하는 국토 개발 프로젝트를 진행하고 있습니다.
상하좌우로 인접한 육지(1)들은 하나의 섬을 형성합니다.
초기에 지도 상의 모든 육지(1)들에 대해, 인접한 육지끼리 Union-Find를 적용하여 전체 섬의 개수를 구하고자 합니다.
2차원 좌표 (r, c)를 1차원 인덱스 $r \times C + c$로 변환하여 서로소 집합을 구성하고,
독립된 섬의 총 개수를 구하라.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 R과 C(1 <= R, C <= 50)가 공백으로 주어진다.
이어서 R개의 줄에 걸쳐 각 줄마다 C개의 숫자(0 또는 1)가 공백으로 주어진다.

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, 섬의 총 개수를 정수로 출력한다.
