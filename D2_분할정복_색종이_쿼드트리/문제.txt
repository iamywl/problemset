[S/W 문제해결 기초] 색종이 쿼드트리 (D2)

[알고리즘 개념 및 원리 학습 - 쿼드트리(Quad Tree) 분할 정복]
쿼드트리(Quad Tree)는 2차원 공간을 4개의 사분면(Quadrant)으로 재귀적으로 분할하여 표현하거나 탐색하는 분할 정복 기법입니다.
이미지 압축, 지형 렌더링, 충돌 감지 등 컴퓨터 공학 전반에서 널리 활용됩니다.

[동작 원리 및 예시]
1. 현재 탐색 중인 N x N 크기의 종이 전체가 모두 같은 색(0 또는 1)인지 검사합니다.
2. 만약 전체가 동일한 색이라면, 더 이상 자를 필요가 없으므로 해당 색의 색종이 개수를 1 증가시키고 탐색을 종료합니다.
3. 만약 다른 색이 섞여 있다면, 가로와 세로를 각각 절반으로 나누어 동일한 크기의 4개의 작은 사분면((N/2) x (N/2))으로 분할합니다:
   - 제1사분면: 좌상단 (r, c)
   - 제2사분면: 우상단 (r, c + N/2)
   - 제3사분면: 좌하단 (r + N/2, c)
   - 제4사분면: 우하단 (r + N/2, c + N/2)
4. 각 사분면에 대해 1~3번 과정을 재귀적으로 반복합니다.

[문제 설명]
N x N 크기의 정사각형 색종이가 주어집니다. 각 칸은 흰색(0) 또는 파란색(1)으로 칠해져 있습니다.
전체가 모두 같은 색이 아니면 4개의 동일한 정사각형으로 자르는 과정을 반복할 때, 최종적으로 잘라진 '파란색(1)' 색종이의 총 개수를 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. N은 2, 4, 8, 16, 32, 64 중 하나이다. (N = 2^k, 1 <= k <= 6)
2. 각 칸의 색은 0(흰색) 또는 1(파란색)이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 한 변의 길이 N이 주어진다.
다음 N개의 줄에는 색종이의 각 행에 해당하는 N개의 숫자가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 최종 잘라진 파란색(1) 색종이의 개수를 출력한다.
