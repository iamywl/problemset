[S/W 문제해결 기본] 바이러스 감염 컴퓨터 (D3)

신종 바이러스인 웜 바이러스는 네트워크를 통해 전파된다.
어느 날 1번 컴퓨터가 웜 바이러스에 걸렸다.
컴퓨터의 수와 네트워크 상에서 서로 직접 연결되어 있는 컴퓨터의 쌍이 주어질 때,
1번 컴퓨터를 통해 바이러스에 걸리게 되는 컴퓨터의 수를 구하는 프로그램을 작성하라. (1번 컴퓨터는 카운트에서 제외한다.)

[제약 사항 (Java 전용)]
1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. 컴퓨터의 수 N은 1 이상 100 이하인 양의 정수이다. 컴퓨터 번호는 1번부터 N번까지이다.

[입력]
첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에는 컴퓨터의 수 N이 주어진다.
둘째 줄에는 네트워크 상에서 직접 연결되어 있는 컴퓨터 쌍의 수 M이 주어진다.
이어서 M개의 줄에는 네트워크 상에서 직접 연결되어 있는 두 컴퓨터의 번호가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 1번 컴퓨터를 통해 감염되는 컴퓨터의 수를 출력한다.
