[S/W 문제해결 기초] 덱에 대해서 (D2)

[자료구조 개념 및 동작 원리 학습 - 덱(Deque)]
덱(Deque, Double-Ended Queue)은 '양쪽 끝에서 삽입과 삭제가 모두 가능한' 유연한 선형 자료구조입니다.
스택(Stack)의 후입선출(LIFO) 특성과 큐(Queue)의 선입선출(FIFO) 특성을 모두 포괄하며, 상황에 따라 스택처럼 쓰거나 큐처럼 쓸 수 있는 매우 강력한 추상 자료형입니다.

덱에서 제공하는 8가지 핵심 연산은 다음과 같습니다:
1. `push_front X`: 정수 X를 덱의 맨 앞(Front)에 삽입합니다.
2. `push_back X`: 정수 X를 덱의 맨 뒤(Back/Rear)에 삽입합니다.
3. `pop_front`: 덱의 맨 앞 원소를 꺼내어 출력합니다. 만약 덱이 비어있다면 -1을 출력합니다.
4. `pop_back`: 덱의 맨 뒤 원소를 꺼내어 출력합니다. 만약 덱이 비어있다면 -1을 출력합니다.
5. `size`: 현재 덱에 들어있는 정수의 총 개수를 출력합니다.
6. `empty`: 덱이 비어있으면 1, 비어있지 않으면 0을 출력합니다.
7. `front`: 덱의 맨 앞 원소를 꺼내지 않고 확인만 합니다. 비어있다면 -1을 출력합니다.
8. `back`: 덱의 맨 뒤 원소를 꺼내지 않고 확인만 합니다. 비어있다면 -1을 출력합니다.

[동작 과정 Trace 예시]
이 자료구조를 구현하면 다음과 같은 단계별 과정을 거치게 됩니다:
- 초기 상태: Deque = []
- push_back 1 수행 -> Deque = [1]
- push_front 2 수행 -> Deque = [2, 1] (앞에 2 삽입)
- push_back 3 수행 -> Deque = [2, 1, 3] (뒤에 3 삽입)
- front 수행 -> 맨 앞의 2 확인 및 출력 (Deque 변동 없음)
- back 수행 -> 맨 뒤의 3 확인 및 출력 (Deque 변동 없음)
- size 수행 -> 현재 원소 개수인 3 출력
- pop_front 수행 -> 맨 앞의 2를 꺼내어 출력 (Deque = [1, 3])
- pop_back 수행 -> 맨 뒤의 3을 꺼내어 출력 (Deque = [1])
- empty 수행 -> 비어있지 않으므로 0 출력
- pop_front 수행 -> 맨 앞의 1을 꺼내어 출력 (Deque = [])
- pop_back 수행 -> 비어있으므로 -1 출력

[문제 설명]
주어지는 N개의 명령어를 순서대로 처리하여 그 결과를 출력하는 덱 프로그램을 직접 구현하십시오!

[제약 사항 (Java 전용)]
1. 주어지는 명령의 수 N은 1 이상 1,000 이하의 자연수이다.
2. push_front, push_back 연산으로 주어지는 정수 X는 1 이상 100,000 이하의 자연수이다.
3. 출력을 요구하는 연산(pop_front, pop_back, size, empty, front, back)의 결과를 공백으로 구분하여 한 줄에 출력한다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 명령의 수 N이 주어진다.
이어지는 N개의 줄에 걸쳐 명령어가 한 줄에 하나씩 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 출력을 요구하는 각 연산의 결과를 공백으로 구분하여 한 줄에 출력한다. 만약 출력할 결과가 없다면 빈 줄로 남긴다.
