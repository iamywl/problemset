[S/W 문제해결 기초] 다음 순열 사전순 찾기 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - Next Permutation 알고리즘]
1부터 N까지의 숫자로 이루어진 순열이 주어졌을 때, 사전 순으로 다음에 오는 순열을 찾는 알고리즘을 Next Permutation이라고 합니다.
전체 순열을 재귀로 일일이 다 생성하지 않고도, 현재 수열에서 단 O(N) 시간 만에 다음 순열을 유도해내는 원리는 다음과 같습니다:
1. 뒤에서부터 탐색하여 A[i-1] < A[i]를 만족하는 가장 큰 인덱스 i를 찾습니다 (꺾이는 지점). 만약 그런 i가 없다면 현재 순열이 이미 마지막(내림차순)입니다.
2. 다시 뒤에서부터 탐색하여 A[j] > A[i-1]을 만족하는 가장 큰 인덱스 j를 찾습니다.
3. A[i-1]과 A[j]의 자리를 맞바꿉니다(Swap).
4. A[i]부터 배열의 끝까지의 구간을 뒤집어(Reverse) 오름차순으로 정렬합니다.

[동작 과정 Trace 예시]
수열 [1, 3, 5, 4, 2]의 다음 순열을 찾는 과정:
1. 뒤에서부터 보면 2 -> 4 -> 5 증가하다가 3에서 꺾임: i=2 (A[i-1]=3, A[i]=5)
2. 뒤에서부터 3보다 큰 최초의 수 찾기: j=3 (A[j]=4)
3. 3과 4 교환(Swap) -> [1, 4, 5, 3, 2]
4. i=2 위치부터 끝([5, 3, 2])을 뒤집기 -> [1, 4, 2, 3, 5]
이 결과 [1, 4, 2, 3, 5]가 바로 사전순 다음 순열입니다. 이것을 구현하여 순열 조작의 원리를 마스터하십시오.

[문제 설명]

주어진 순열의 사전 순 다음 순열을 구하는 프로그램을 작성하십시오. 만약 이미 사전 순으로 가장 마지막 순열인 경우 -1을 출력합니다.

[제약 사항 (Java 전용)]

1. N은 2 이상 10,000 이하의 자연수이다.
2. 수열은 1부터 N까지의 자연수가 중복 없이 한 번씩 등장한다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N이 주어진다.
둘째 줄에 N개의 자연수가 공백으로 구분되어 순서대로 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 다음 순열을 공백으로 구분하여 출력한다. 마지막 순열인 경우 -1을 출력한다.
