[S/W 문제해결 기초] 순열에 대해서 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 순열(Permutation)]
순열(Permutation)이란 서로 다른 N개의 원소 중에서 R개를 택하여 '순서를 고려하여' 나열하는 것을 말합니다.
순서가 다르면 서로 다른 경우로 취급하며, 기호로는 nPr로 표기하고 그 경우의 수는 다음과 같습니다:
nPr = n! / (n-r)! = n * (n-1) * ... * (n-r+1)

순열을 구현하는 가장 표준적인 방법은 재귀 호출(Recursion)과 방문 여부를 기록하는 불리언 배열(visited)을 사용하는 것입니다:
1. 현재 위치(depth)가 R에 도달하면 순열 하나가 완성된 것이므로 결과를 저장/출력합니다.
2. 1부터 N까지의 숫자 중 아직 방문하지 않은(!visited[i]) 숫자를 찾습니다.
3. visited[i] = true로 설정하고 결과 배열에 숫자를 담은 후, 다음 단계(depth + 1)로 재귀 호출합니다.
4. 재귀 호출이 반환되면 visited[i] = false로 원상복구(Backtracking)하여 다른 순열을 탐색할 수 있도록 합니다.

[동작 과정 Trace 예시]
N=3, R=2인 경우, 1부터 3까지의 숫자로 만들 수 있는 순열의 탐색 단계:
- depth 0: 1 선택 (visited[1]=T) -> depth 1 이동
- depth 1: 2 선택 (visited[2]=T) -> depth 2 도달! 순열 [1, 2] 완성 및 기록
- backtrack (visited[2]=F)
- depth 1: 3 선택 (visited[3]=T) -> depth 2 도달! 순열 [1, 3] 완성 및 기록
- backtrack (visited[3]=F)
- backtrack (visited[1]=F)
- depth 0: 2 선택 -> [2, 1], [2, 3] 완성
- depth 0: 3 선택 -> [3, 1], [3, 2] 완성
총 6가지(3P2 = 6)의 순열이 사전순으로 생성됩니다. 이것을 구현하여 순열의 원리를 완벽히 체득하십시오.

[문제 설명]

1부터 N까지의 자연수 중에서 중복 없이 R개를 고른 모든 순열을 사전 순으로 출력하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. N과 R은 자연수이며, 1 <= R <= N <= 8 이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N과 R이 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 첫 줄에 '#tc'를 출력하고, 다음 줄부터 생성된 순열을 한 줄에 하나씩 공백으로 구분하여 사전 순으로 출력한다.
