[S/W 문제해결 기초] 정렬배열 탐색기 (D2)

[알고리즘 개념 및 원리 학습 - 이진 탐색(Binary Search)]
이진 탐색(Binary Search)은 '이미 오름차순으로 정렬되어 있는 배열'에서 특정 값을 찾을 때 사용하는 매우 효율적인 탐색 알고리즘입니다.
처음부터 끝까지 순차적으로 확인하는 순차 탐색은 최악의 경우 O(N)의 시간이 걸리지만, 이진 탐색은 탐색 범위를 절반씩 좁혀나가기 때문에 O(log N)이라는 매우 빠른 속도로 동작합니다.

[동작 원리 및 예시]
1. 탐색 범위의 시작점(low)을 배열의 시작 인덱스, 끝점(high)을 배열의 마지막 인덱스로 지정합니다.
2. 중간 위치인 mid = (low + high) / 2를 계산합니다.
3. 찾고자 하는 목표값(Target)과 배열의 중간값 arr[mid]를 비교합니다:
   - Target == arr[mid]: 탐색 성공! 해당 인덱스를 반환합니다.
   - Target < arr[mid]: 목표값이 중간값보다 작으므로, 오른쪽 절반은 볼 필요가 없습니다. high = mid - 1로 좁힙니다.
   - Target > arr[mid]: 목표값이 중간값보다 크므로, 왼쪽 절반은 볼 필요가 없습니다. low = mid + 1로 좁힙니다.
4. low > high가 될 때까지 2~3 과정을 반복하며, 만약 찾지 못하면 배열에 목표값이 존재하지 않는 것입니다.

예를 들어, [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]에서 23을 찾는 경우:
- 1단계: low=0, high=9, mid=4 (arr[4]=16). 23 > 16 이므로 low = 5로 변경.
- 2단계: low=5, high=9, mid=7 (arr[7]=56). 23 < 56 이므로 high = 6으로 변경.
- 3단계: low=5, high=6, mid=5 (arr[5]=23). 23 == 23 탐색 성공! (위치 6번째)

[문제 설명]
오름차순으로 정렬된 N개의 정수가 주어집니다. 이 배열에서 정수 K가 존재하는지 이진 탐색으로 확인하고, 존재한다면 1번째부터 시작하는 위치(1-based index)를, 존재하지 않는다면 -1을 출력하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. 배열의 원소 개수 N은 1 이상 100,000 이하의 정수이다. (1 <= N <= 100,000)
2. 각 정수 및 찾고자 하는 값 K는 -1,000,000,000 이상 1,000,000,000 이하이다.
3. 배열은 항상 오름차순으로 정렬되어 주어지며, 중복된 값은 존재하지 않는다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내 (케이스당 0.2초 이내)
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 N과 K가 공백으로 구분되어 주어진다.
두 번째 줄에는 오름차순으로 정렬된 N개의 정수가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 값 K의 1-based 인덱스를 출력한다. 존재하지 않으면 -1을 출력한다.
