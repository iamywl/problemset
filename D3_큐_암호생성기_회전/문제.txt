[S/W 문제해결 응용] 암호생성기 회전 (D3) - SWEA 1225 기반

[문제 스토리]
정보보안 동아리의 도윤이는 회의실 도어락에 등록할 8자리의 보안 암호를 동적으로 생성하는 프로그램을 구현하고 있습니다.
도윤이의 암호 생성기는 8개의 정수를 큐(Queue)에 넣고 다음과 같은 사이클 규칙을 반복합니다:
1. 맨 앞(Front)의 숫자를 꺼내 첫 번째 단계에는 1을 감소시킨 뒤 맨 뒤(Rear)로 보냅니다.
2. 다음 숫자를 꺼내 2를 감소시킨 뒤 맨 뒤로 보냅니다.
3. 이처럼 1부터 5까지 차례대로 감소시키며 뒤로 보내는 과정을 하나의 '사이클'이라고 합니다.
4. 숫자를 감소시켰을 때 그 값이 0 이하가 되면, 0으로 고정하여 맨 뒤로 보내고 전체 암호 생성 사이클을 즉시 종료합니다.

사이클이 종료되었을 때, 큐에 남아있는 8개의 숫자가 바로 완성된 보안 암호입니다.
도윤이를 도와 초기 8개의 정수가 주어졌을 때 최종 8자리 암호를 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. 입력으로 주어지는 8개의 정수는 1 이상 100,000 이하의 자연수이다.
2. 암호 생성이 종료될 때 마지막으로 들어간 숫자는 항상 0이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 8개의 정수가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 완성된 8자리 암호를 공백으로 구분하여 한 줄에 출력한다.
