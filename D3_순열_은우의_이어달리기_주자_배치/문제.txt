[S/W 문제해결 기본] 은우의 이어달리기 주자 배치 (D3)

[스토리텔링]
체육대회 반 대표 육상 코치를 맡은 은우는 이어달리기 종목에 출전할 N명의 주자 배치 순서를 결정하고 있습니다.
이어달리기에서는 앞 주자로부터 다음 주자로 배턴(Baton)을 전달할 때 두 사람 간의 호흡과 시너지가 경기 결과에 매우 큰 영향을 미칩니다.
주자 i번이 주자 j번에게 배턴을 넘겨줄 때 발생하는 시너지 점수를 S[i][j]라고 합니다.

N명의 주자 순서를 1번부터 N번까지 어떤 순열 [P_1, P_2, ..., P_N]으로 배치할 때,
전체 배턴 터치 시너지의 총합은 다음과 같습니다:
총 시너지 = S[P_1][P_2] + S[P_2][P_3] + ... + S[P_{N-1}][P_N]

은우를 도와 N명의 주자 순열 배치를 최적화하여 얻을 수 있는 시너지 총합의 최댓값을 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. 주자의 수 N은 3 이상 8 이하의 자연수이다.
2. 각 주자 간의 시너지 점수 S[i][j]는 0 이상 100 이하의 정수이다 (단, i=j일 때 S[i][i]는 0이다).
3. 주자 번호는 0번부터 N-1번까지이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 주자의 수 N이 주어진다.
이어지는 N개의 줄에 걸쳐 N x N 시너지 행렬 S의 원소들이 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 얻을 수 있는 최대 시너지 총합을 정수로 출력한다.
