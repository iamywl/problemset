[S/W 문제해결 기초] 스택에 대해서 (D2)

[자료구조 개념 및 동작 원리 학습 - 스택(Stack)]
스택(Stack)은 '차곡차곡 쌓아 올린 더미'라는 뜻으로, 데이터를 오직 한쪽 끝(Top)에서만 넣고(Push) 뺄 수 있는(Pop) 대표적인 선형 자료구조입니다.
가장 나중에 들어온 데이터가 가장 먼저 나가는 특성을 가지며, 이를 '후입선출(LIFO: Last In First Out)'이라고 부릅니다.
뷔페 식당에 쌓여 있는 접시 더미, 웹 브라우저의 '뒤로 가기' 방문 기록, 텍스트 편집기의 '실행 취소(Undo)' 기능 등이 모두 스택의 대표적인 실생활 사례입니다.

스택에서 제공하는 5가지 핵심 연산은 다음과 같습니다:
1. `push X`: 정수 X를 스택의 맨 위(Top)에 삽입합니다.
2. `pop`: 스택의 맨 위(Top)에 있는 정수를 꺼내어 반환합니다. 만약 스택에 들어있는 정수가 없다면 -1을 반환합니다.
3. `size`: 현재 스택에 들어있는 정수의 총 개수를 반환합니다.
4. `empty`: 스택이 비어있으면 1, 비어있지 않으면 0을 반환합니다.
5. `top`: 스택의 맨 위(Top)에 있는 정수를 꺼내지 않고 확인만 합니다. 만약 스택이 비어있다면 -1을 반환합니다.

[동작 과정 Trace 예시]
이 자료구조를 구현하면 다음과 같은 단계별 과정을 거치게 됩니다:
- 초기 상태: Stack = []
- push 10 수행 -> Stack = [10] (Top은 10)
- push 20 수행 -> Stack = [10, 20] (Top은 20)
- top 수행 -> 맨 위의 20 확인 및 출력 (Stack 변동 없음)
- pop 수행 -> 맨 위의 20을 꺼내어 출력 (Stack = [10])
- size 수행 -> 현재 원소 개수인 1 출력
- empty 수행 -> 스택이 비어있지 않으므로 0 출력
- pop 수행 -> 맨 위의 10을 꺼내어 출력 (Stack = [])
- pop 수행 -> 스택이 비어있으므로 -1 출력

[문제 설명]
주어지는 N개의 명령어를 순서대로 처리하여 그 결과를 출력하는 스택 프로그램을 직접 구현하십시오!

[제약 사항 (Java 전용)]
1. 주어지는 명령의 수 N은 1 이상 1,000 이하의 자연수이다.
2. push 연산으로 주어지는 정수 X는 1 이상 100,000 이하의 자연수이다.
3. 출력해야 하는 연산(pop, size, empty, top)의 결과들을 공백으로 구분하여 한 줄로 출력한다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 명령의 수 N이 주어진다.
이어지는 N개의 줄에 걸쳐 명령어가 한 줄에 하나씩 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 출력을 요구하는 각 연산(pop, size, empty, top)의 결과를 공백으로 구분하여 한 줄에 출력한다. 만약 출력할 결과가 없다면 빈 줄로 남긴다.
