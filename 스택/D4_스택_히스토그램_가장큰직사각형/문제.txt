[S/W 문제해결 심화] 히스토그램 가장큰직사각형 (D4) - 백준 6549 기반

[복합 제약 조건 설명 - 모노톤 스택을 이용한 O(N) 최대 직사각형 탐색]
히스토그램은 너비가 1인 N개의 직사각형 막대가 수평으로 이어붙여진 형태입니다. 각 막대의 높이가 주어집니다.
이 히스토그램 내부에 완전히 포함되는 직사각형 중 '가장 넓이가 큰 직사각형'의 면적을 구해야 합니다.

[복합 해결 조건]
1. N이 최대 100,000에 달하므로, 모든 구간의 최솟값을 구하는 분할정복 O(N log N) 또는 O(N^2) 알고리즘 대신, '모노톤 증가 스택'을 활용하여 완벽한 O(N) 단일 패스에 해결해야 합니다.
2. 스택에는 높이가 오름차순을 유지하도록 막대의 인덱스를 저장합니다.
3. 현재 막대의 높이가 스택 top 막대의 높이보다 낮아지면:
- 스택 top을 꺼내고 그 막대를 높이 h로 하는 직사각형의 최대 너비를 계산합니다:
width = 스택이 비어있다면 현재 인덱스 i, 아니라면 (i - 1 - stack.peek())
면적 = h * width
- 최대 면적을 갱신합니다.
4. 모든 막대를 확인한 후 스택에 남은 막대들에 대해서도 동일하게 처리합니다.
5. 계산되는 면적이 32비트 정수를 초과할 수 있으므로 64비트 정수(long) 연산을 필수로 적용해야 합니다.

[제약 사항 (Java 전용)]

1. 막대의 개수 N은 1 이상 100,000 이하의 자연수이다.
2. 각 막대의 높이는 0 이상 1,000,000,000 이하의 정수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N이 주어진다.
둘째 줄에 N개의 막대 높이가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 히스토그램에서 가장 큰 직사각형의 넓이를 출력한다.
