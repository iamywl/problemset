[S/W 문제해결 기초] 숫자 되돌리기 제로 (D2)

[자료구조 개념 및 원리 학습 - 스택의 실행 취소(Undo) 원리]
스택의 가장 직관적인 응용 분야 중 하나는 '최근 작업 되돌리기(Undo)'입니다.
재무 장부를 기입할 때 숫자를 잘못 불렀을 경우, '0'을 외치면 가장 최근에 썼던 숫자를 지우는 규칙이 있습니다.
- 0이 아닌 자연수가 들어오면 스택에 차례대로 push합니다.
- 0이 들어오면 가장 최근에 들어간 숫자가 잘못된 것이므로 스택에서 pop하여 지웁니다.
모든 수를 처리한 후 스택에 최종적으로 남아있는 모든 수의 합을 구합니다.

[동작 과정 Trace 예시]
입력 수열: [3, 0, 4, 0]
1) 3 입력 -> 스택: [3]
2) 0 입력 -> pop -> 스택: [] (3 취소)
3) 4 입력 -> 스택: [4]
4) 0 입력 -> pop -> 스택: [] (4 취소)
최종 합 = 0

입력 수열: [1, 3, 5, 4, 0, 0, 7, 0, 0, 6]
1) 1, 3, 5, 4 -> 스택: [1, 3, 5, 4]
2) 0 -> 4 pop -> 스택: [1, 3, 5]
3) 0 -> 5 pop -> 스택: [1, 3]
4) 7 -> 스택: [1, 3, 7]
5) 0 -> 7 pop -> 스택: [1, 3]
6) 0 -> 3 pop -> 스택: [1]
7) 6 -> 스택: [1, 6]
최종 합 = 1 + 6 = 7

[문제 설명]

주어진 K개의 정수를 순서대로 처리한 후 스택에 남은 모든 정수의 합을 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. 정수의 개수 K는 1 이상 100,000 이하의 자연수이다.
2. 입력되는 정수는 0 이상 100,000 이하의 정수이다.
3. 정수가 0일 경우에 지울 수 있는 수가 항상 존재함이 보장된다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 정수 K가 주어진다.
둘째 줄에 K개의 정수가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 최종적으로 남은 수들의 총합을 출력한다.
