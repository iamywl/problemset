[S/W 문제해결 심화] 오큰수 수열 탐색 (D4) - 백준 17298 기반

[복합 제약 조건 설명 - 모노톤 스택(Monotone Stack)]
크기가 N인 수열 A = [A_1, A_2, ..., A_N]이 주어집니다.
수열의 각 원소 A_i에 대해, '오른쪽에 있으면서 A_i보다 큰 수 중에서 가장 왼쪽에 있는 수'를 A_i의 오큰수(NGE: Next Greater Element)라고 부릅니다.
만약 그러한 수가 존재하지 않는다면 오큰수는 -1입니다.

[복합 해결 조건]
1. N이 최대 200,000에 달하므로, 각 원소마다 오른쪽 원소들을 선형 탐색하는 이중 반복문 O(N^2) 알고리즘은 400억 번의 연산으로 시간 초과가 발생합니다.
2. 따라서 '인덱스를 저장하는 모노톤 감소 스택'을 사용하여 O(N) 선형 시간에 해결해야 합니다:
- 스택에는 아직 오큰수를 찾지 못한 원소들의 인덱스를 저장합니다.
- 새 원소 A[i]를 만났을 때, 스택의 top 인덱스 j에 대해 A[j] < A[i]라면, A[j]의 오큰수는 바로 A[i]가 됩니다!
- 조건을 만족하는 동안 스택에서 pop하며 오큰수를 기록하고, 현재 인덱스 i를 스택에 push합니다.
- 모든 탐색이 끝난 후 스택에 남아있는 인덱스들의 오큰수는 -1로 채웁니다.

[제약 사항 (Java 전용)]

1. 수열의 크기 N은 1 이상 200,000 이하의 자연수이다.
2. 수열의 각 원소 A_i는 1 이상 1,000,000 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N이 주어진다.
둘째 줄에 N개의 자연수가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, A_1부터 A_N까지 각 원소의 오큰수를 공백으로 구분하여 한 줄에 출력한다.
