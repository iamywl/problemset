[S/W 문제해결 기초] 후위표기식 연산 기초 (D2)

[자료구조 개념 및 동작 원리 설명 - 스택 기반 후위표기식]
후위 표기식(Postfix notation)은 연산자가 피연산자 뒤에 위치하는 표기법으로, 괄호 없이도 연산의 우선순위가 명확하게 정해지는 특징이 있습니다.
컴퓨터가 수식을 계산할 때 가장 많이 사용하는 방식이며, 스택(Stack)을 사용하면 O(N) 시간에 간단히 계산할 수 있습니다.

[동작 과정 Trace 예시]
수식 "35+2*"의 동작 원리는 다음과 같습니다:
1. '3' 탐색: 피연산자이므로 스택에 push -> [3]
2. '5' 탐색: 피연산자이므로 스택에 push -> [3, 5]
3. '+' 탐색: 연산자이므로 스택에서 pop 2회 (b=5, a=3). a+b=8 계산 후 결과 push -> [8]
4. '2' 탐색: 피연산자이므로 스택에 push -> [8, 2]
5. '*' 탐색: 연산자이므로 스택에서 pop 2회 (b=2, a=8). a*b=16 계산 후 결과 push -> [16]
수식 탐색이 종료되면 스택에 남은 최종 결과값 16을 출력합니다.

[문제 설명]

주어진 길이 N의 후위 표기식을 스택을 활용하여 계산하고, 최종 결과값을 출력하는 프로그램을 작성하십시오.
이것을 구현하여 스택의 LIFO 원리와 연산자 처리 원리를 완벽히 체득하십시오.

[제약 사항 (Java 전용)]

1. 수식의 길이 N은 3 이상 101 이하의 홀수이다.
2. 피연산자는 0 이상 9 이하의 한 자리 정수이다.
3. 연산자는 '+', '-', '*' 세 가지만 사용된다.
4. 나눗셈은 없으며, 모든 연산 중간값 및 최종값은 정수 범위 내이다.
5. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
6. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 수식의 길이 N이 주어지고, 둘째 줄에 후위 표기식 문자열이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 최종 계산 결과 정수를 출력한다.
