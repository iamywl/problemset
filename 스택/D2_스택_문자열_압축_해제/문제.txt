[S/W 문제해결 기초] 스택 문자열 압축 해제 (D2)

[자료구조 개념 및 동작 원리 설명 - 스택 기반 괄호 압축 해제]
반복되는 패턴을 `k[문자열]` 형태로 표현한 압축 문자열은 중첩(Nested) 구조를 가질 수 있습니다.
이러한 중첩 구조를 처리하는 가장 완벽한 자료구조는 스택(Stack)입니다.
여는 괄호 '['를 만날 때마다 지금까지 누적된 문자열과 반복 횟수 k를 스택에 저장하고,
닫는 괄호 ']'를 만날 때 스택에서 이전 문자열과 k를 꺼내어 현재 문자열을 k번 복제한 뒤 이전 문자열 뒤에 이어 붙입니다.

[동작 과정 Trace 예시]
입력 "3[a]2[bc]"의 동작 과정:
1. 숫자 3 파싱 -> '[' 만나면 반복횟수 3, 이전 문자열 "" 스택에 push
2. 'a' 누적 -> 현재 문자열 "a"
3. ']' 만나면 스택에서 (3, "") 꺼내어 "" + "a"*3 = "aaa" 생성
4. 숫자 2 파싱 -> '[' 만나면 반복횟수 2, 이전 문자열 "aaa" 스택에 push
5. "bc" 누적 -> 현재 문자열 "bc"
6. ']' 만나면 스택에서 (2, "aaa") 꺼내어 "aaa" + "bc"*2 = "aaabcbc" 생성
최종 결과는 "aaabcbc"가 됩니다. 이것을 구현하여 중첩 스택 구조의 원리를 익히십시오.

[문제 설명]

주어진 압축 문자열을 스택을 이용하여 완전히 압축 해제한 원본 문자열을 출력하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. 압축 문자열의 길이는 1 이상 100 이하이다.
2. 반복 횟수 k는 1 이상 9 이하의 한 자리 정수이다.
3. 괄호 안의 문자는 알파벳 소문자('a'-'z')로만 구성된다.
4. 중첩 깊이는 최대 3단계 이하이다.
5. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
6. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 압축 문자열이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 압축 해제된 문자열을 출력한다.
