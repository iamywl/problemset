[S/W 문제해결 응용] 서준이의 쇠막대기 자르기 (D3)

[문제 스토리]

창의공작 동아리의 서준이는 기다란 쇠막대기들을 아래에서부터 위로 겹쳐 쌓아 올린 뒤, 수직 레이저를 발사하여 쇠막대기들을 여러 조각으로 절단하는 실험을 진행하고 있습니다.
서준이가 쌓은 쇠막대기와 레이저의 위치는 괄호 문자열로 완벽히 표현됩니다:
1. 쇠막대기는 자신보다 긴 쇠막대기 위에만 놓일 수 있으며, 끝점이 겹치지 않습니다.
2. 레이저는 인접한 괄호쌍 '()'로 표현됩니다.
3. 쇠막대기의 왼쪽 끝은 여는 괄호 '(', 오른쪽 끝은 닫는 괄호 ')'로 표현됩니다.

[스택을 활용한 절단 규칙]
- 여는 괄호 '('를 만나면: 새 쇠막대기가 시작되거나 레이저의 시작이므로 스택에 push합니다.
- 닫는 괄호 ')'를 만났을 때 직전 문자가 '('라면: 이것은 '레이저'입니다!
-> 스택에서 방금 넣은 '('를 pop한 후, 현재 스택에 쌓여있는 쇠막대기의 개수(stack.size())만큼 조각이 추가로 생성됩니다!
- 직전 문자가 ')'라면: 이것은 '쇠막대기의 끝'입니다!
-> 스택에서 해당 쇠막대기의 '('를 pop하고, 쇠막대기의 마지막 꼬리 조각(+1)이 완성됩니다!

서준이를 도와 절단 후 생성된 쇠막대기 조각의 총 개수를 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. 괄호 문자의 길이는 2 이상 100,000 이하의 짝수이다.
2. 쇠막대기와 레이저의 배치는 항상 문법적으로 유효하다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 쇠막대기와 레이저의 배치를 나타내는 괄호 문자열이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 잘려진 쇠막대기 조각의 총 개수를 출력한다.
