[S/W 문제해결 심화] 두배열 합의 K번째수 (D4)

[복합 제약 조건 설명]
크기가 N인 정수 배열 A와 크기가 M인 정수 배열 B가 주어집니다.
배열 A에서 원소 하나 a와 배열 B에서 원소 하나 b를 각각 선택하여 더하면 총 N x M개의 합(a + b)을 만들 수 있습니다.
이 N x M개의 모든 합들을 오름차순으로 정렬했을 때, K번째(1-based)로 위치하는 합의 값을 구해야 합니다.

[복합 해결 조건]
1. N과 M이 각각 최대 50,000에 달하므로, N x M = 2,500,000,000개의 모든 합을 직접 배열에 생성하거나 정렬하는 것은 메모리와 시간상 불가능합니다.
2. 따라서 '합이 X 이하인 쌍의 개수가 K개 이상인가?'라는 결정 문제(Decision Problem)로 변환하여 이진 탐색(Parametric Search)을 수행해야 합니다.
3. 배열 B를 정렬한 후, 배열 A의 각 원소 A[i]에 대해 B에서 (X - A[i]) 이하인 원소의 개수를 이진 탐색(Upper Bound) 또는 투 포인터로 빠르게 합산해야 합니다.

[제약 사항 (Java 전용)]
1. 배열 A의 크기 N과 배열 B의 크기 M은 1 이상 50,000 이하의 자연수이다.
2. 찾고자 하는 순위 K는 1 이상 N x M 이하의 자연수이다.
3. 각 원소 A[i], B[j]는 1 이상 1,000,000,000 이하의 자연수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N, M, K가 공백으로 구분되어 주어진다.
둘째 줄에 배열 A의 N개 정수가 공백으로 구분되어 주어진다.
셋째 줄에 배열 B의 M개 정수가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, N x M개의 합 중 K번째로 작은 값을 출력한다.
