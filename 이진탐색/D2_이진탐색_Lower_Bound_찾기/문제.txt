[S/W 문제해결 기본] Lower Bound 찾기 (D2)

[문제 설명]
정렬된 배열에서 특정 값 이상의 원소가 처음으로 등장하는 위치를 찾는 알고리즘을 하한선(Lower Bound) 탐색이라고 합니다.
동작 원리는 다음과 같습니다.
1. 탐색 범위 [left, right]를 0부터 N까지로 설정합니다.
2. 중간 위치 mid에 대해 arr[mid] >= Target이면, 더 앞쪽에도 조건을 만족하는 원소가 있을 수 있으므로 right = mid로 설정합니다.
3. arr[mid] < Target이면, mid 이하의 위치는 조건을 만족할 수 없으므로 left = mid + 1로 설정합니다.
4. left == right가 될 때의 위치가 바로 Target 이상인 첫 번째 원소의 1-based 인덱스입니다. (모든 원소가 Target보다 작으면 N + 1을 반환합니다.)

오름차순 정렬된 N개의 정수 배열과 M개의 질의가 주어질 때, 각 질의값 이상의 원소가 처음 나타나는 1-based 인덱스를 구하라.

[제약 사항 (Java 전용)]
1. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내 (테스트케이스당 0.2초 이내)
2. 메모리 제한: 힙(Heap) 메모리 256MB 이내 (자바 전용)
3. 배열의 크기 N은 1 이상 100,000 이하의 자연수이다.
4. 질의의 수 M은 1 이상 10 이하의 자연수이다.
5. 배열의 원소는 오름차순으로 정렬되어 주어지며 절댓값은 1,000,000,000 이하이다.

[입력]

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 배열의 크기 N(1 <= N <= 100,000)과 질의 수 M(1 <= M <= 10)이 주어진다.
두 번째 줄에 정렬된 N개의 정수가 공백으로 주어진다.
세 번째 줄에 M개의 질의 정수가 공백으로 주어진다.

[출력]

각 테스트 케이스마다 '#T'를 출력하고, M개의 질의에 대한 하한선 인덱스를 공백으로 구분하여 출력한다.
