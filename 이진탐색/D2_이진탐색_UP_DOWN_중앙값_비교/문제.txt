[문제 설명]

이진 탐색(Binary Search) 알고리즘의 핵심 개념은 "정렬된 데이터에서 중앙 원소(mid)를 선택하여 목표값(target)과 단 한 번 비교함으로써, 다음으로 탐색해야 할 범위를 즉시 절반으로 축소하는 것"입니다.

배열의 탐색 구간이 시작 인덱스 L부터 끝 인덱스 R까지로 주어졌을 때, 중앙 인덱스 mid는 다음과 같이 계산합니다:
mid = (L + R) / 2

이 문제에서는 복잡한 반복문을 사용하기 전에, 주어진 정렬 배열과 목표값 K에 대해 '단 1회의 중앙값 비교 판정'을 수행하는 기본 원리를 학습합니다.
초기 탐색 구간은 전체 배열(L = 0, R = N - 1)입니다.
배열의 중앙 원소 arr[mid]와 목표값 K를 비교하여 다음 세 가지 동작 중 하나를 수행하십시오:

1. K == arr[mid]:
목표값을 중앙에서 바로 찾았습니다!
출력: "EQUAL mid" (예: EQUAL 4)

2. K < arr[mid]:
목표값은 중앙값보다 작으므로 반드시 왼쪽 절반 구간에 존재해야 합니다.
다음 탐색 구간은 [L, mid - 1]로 축소됩니다.
출력: "LEFT L mid-1" (예: LEFT 0 3)

3. K > arr[mid]:
목표값은 중앙값보다 크므로 반드시 오른쪽 절반 구간에 존재해야 합니다.
다음 탐색 구간은 [mid + 1, R]로 축소됩니다.
출력: "RIGHT mid+1 R" (예: RIGHT 5 8)

[동작 원리 및 Trace 예시]
길이가 9인 정렬 배열 arr = [10, 25, 33, 47, 52, 68, 79, 88, 91] 이 주어졌을 때:
- L = 0, R = 8
- mid = (0 + 8) / 2 = 4, arr[4] = 52

Case 1: 목표값 K = 33
- 33 < 52 (K < arr[mid]) 이므로 왼쪽 구간으로 이동.
- 새로운 탐색 범위: L = 0, R = 3
- 출력: LEFT 0 3

Case 2: 목표값 K = 52
- 52 == 52 (K == arr[mid]) 이므로 중앙값과 일치.
- 출력: EQUAL 4

Case 3: 목표값 K = 79
- 79 > 52 (K > arr[mid]) 이므로 오른쪽 구간으로 이동.
- 새로운 탐색 범위: L = 5, R = 8
- 출력: RIGHT 5 8

[제약 사항]

1. 정렬된 배열의 크기 N은 1 이상 100 이하의 정수입니다 (1 <= N <= 100).
2. 배열의 각 원소 및 목표값 K는 -10,000 이상 10,000 이하의 정수입니다.
3. 배열은 엄격한 오름차순으로 정렬되어 있습니다.

[입력 형식]

첫 번째 줄에 테스트 케이스의 수 T가 주어집니다.
각 테스트 케이스의 첫 번째 줄에는 배열의 크기 N과 목표값 K가 공백으로 구분되어 주어집니다.
두 번째 줄에는 오름차순으로 정렬된 N개의 정수가 공백으로 구분되어 주어집니다.

[출력 형식]

각 테스트 케이스마다 '#tc'를 출력하고 한 칸 띄운 후, 판정 결과와 인덱스를 공백으로 구분하여 출력합니다.
- 중앙값과 같을 때: #tc EQUAL mid
- 중앙값보다 작을 때: #tc LEFT L (mid-1)
- 중앙값보다 클 때: #tc RIGHT (mid+1) R
