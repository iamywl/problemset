[S/W 문제해결 심화] K번째 수 구구단 배열 (D4)

[문제 설명]

N x N 크기의 2차원 배열 A의 각 원소는 A[i][j] = i * j 입니다. 이 수들을 1차원 배열 B에 넣고 오름차순 정렬했을 때, B[K]번째에 위치하는 수를 구하는 문제입니다. N이 최대 10^5로 N^2=10^10이므로 배열을 직접 만들 수 없으며, mid 값 이하의 원소 개수(sum(min(N, mid / i)))를 이진 탐색하여 O(N log K)에 해결합니다.

[알고리즘 개념 및 문제 해결 핵심 아이디어]

• 핵심 알고리즘: 이진 탐색 / 매개변수 탐색 - 2차원 배열 가상 순회 및 카운팅 (백준 1300 K번째 수)
• 접근 전략: 문제에서 요구하는 핵심 제약과 시간 복잡도를 분석하여, 비효율적인 완전 탐색 대신 최적화된 자료구조와 알고리즘 기법을 적용합니다.

[제약 사항 (Java 전용)]

1. 배열의 크기 N은 1 이상 100,000 이하의 자연수이다.
2. 구하고자 하는 순번 K는 1 이상 min(10^9, N^2) 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스마다 첫 줄에 N, 둘째 줄에 K가 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, B[K]의 값을 출력한다.
