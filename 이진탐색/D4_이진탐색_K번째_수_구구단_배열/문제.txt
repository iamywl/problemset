[문제 설명]
크기가 N x N인 2차원 배열 A가 있습니다. 배열의 각 행과 열은 1부터 시작하며, A[i][j] = i * j 입니다.
이 수를 1차원 배열 B에 모두 넣으면 크기가 N^2인 배열이 됩니다.
배열 B를 오름차순 정렬했을 때, B[K]에 위치하는 K번째 수를 구하고자 합니다. (배열 B의 인덱스는 1부터 시작합니다.)

N이 최대 100,000으로 주어지므로 N^2개의 수를 실제로 생성하거나 정렬하는 것은 메모리와 시간 복잡도상 불가능합니다.
어떤 수 X 이하인 원소의 개수는 각 i번째 행(1 <= i <= N)에서 min(N, X / i)개임을 이용할 수 있습니다.
이진 탐색(Parametric Search)을 통해 X 이하의 수의 개수가 적어도 K개 이상이 되는 최소의 정수 X를 구하라.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스마다 한 줄에 N(1 <= N <= 100,000)과 K(1 <= K <= min(10^9, N^2))가 공백으로 구분되어 주어진다.

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, K번째 수를 출력한다.
