[S/W 문제해결 기초] 피보나치 수 호출 카운터 (D2)

[문제 설명 및 원리]
피보나치 수열을 다음과 같은 전형적인 재귀 함수로 구현할 수 있습니다:
```java
int fib(int n) {
    if (n == 0) { count0++; return 0; }
    if (n == 1) { count1++; return 1; }
    return fib(n - 1) + fib(n - 2);
}
```
정수 N이 주어졌을 때, 재귀 함수 `fib(N)`을 실행하는 동안 `fib(0)`과 `fib(1)`이 각각 몇 번 호출되는지 구하는 문제입니다.
트리 형태의 재귀 호출 구조와 중복 연산의 발생 과정을 명확히 이해할 수 있습니다.

[동작 과정 Trace 예시]
N=3 호출:
- fib(3) = fib(2) + fib(1)
  - fib(2) = fib(1) + fib(0)
    - fib(1) 호출 (count1 + 1)
    - fib(0) 호출 (count0 + 1)
  - fib(1) 호출 (count1 + 1)
총 호출 횟수: fib(0)은 1번, fib(1)은 2번 호출됨.

[제약 사항 (Java 전용)]
1. N은 0 이상 30 이하의 정수이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트케이스의 개수 T가 주어진다.
각 테스트케이스의 한 줄에 정수 N이 주어진다.

[출력]
각 테스트케이스마다 '#tc'와 공백을 출력한 후, 0이 호출된 횟수와 1이 호출된 횟수를 공백으로 구분하여 출력한다.
