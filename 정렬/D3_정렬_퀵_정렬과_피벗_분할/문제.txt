[S/W 문제해결 응용] 퀵 정렬과 피벗 분할 (D3)

[문제 스토리]

SSAFY 알고리즘 전공 과정의 지아는 분할 정복(Divide-and-Conquer) 기법의 핵심인 '퀵 정렬(Quicksort)'의 내부 동작 과정을 정밀하게 분석하고 있습니다.
퀵 정렬은 평균적으로 O(N log N)의 뛰어난 성능을 보이며, 현업에서도 널리 사용되는 정렬 알고리즘입니다.
지아는 CLRS(Introduction to Algorithms) 7장에 수록된 표준 **로무토 분할(Lomuto Partition)** 기반 퀵 정렬 알고리즘을 직접 구현하고 실행 과정을 검증하고자 합니다.

[알고리즘 개념 학습 - CLRS Ch 7 Quicksort]

CLRS 교재의 로무토 분할 및 퀵 정렬 슈도코드는 다음과 같습니다:

```
PARTITION(A, p, r):
x = A[r] // 피벗은 항상 부분 배열의 마지막 원소
i = p - 1
for j = p to r - 1:
if A[j] <= x:
i = i + 1
exchange A[i] with A[j] // 원소 교환 (i == j 이어도 문장 실행 카운트)
exchange A[i + 1] with A[r] // 피벗을 최종 위치로 이동
return i + 1

QUICKSORT(A, p, r):
if p < r:
q = PARTITION(A, p, r)
QUICKSORT(A, p, q - 1)
QUICKSORT(A, q + 1, r)
```

[검증 요구사항]
크기 N의 1차원 정수 배열 A[1..N] (0-based 기준 A[0..N-1])이 주어집니다.
지아의 퀵 정렬 알고리즘을 0번 인덱스부터 N-1번 인덱스까지 전체 배열에 대해 실행했을 때:
1. 정렬 과정 중 `exchange` (원소 교환) 문장이 실행된 총 횟수를 계산하십시오.
(주의: i와 j의 인덱스가 동일한 경우라도 교환 문장이 호출되면 횟수로 정확히 1회 카운트합니다.)
2. 정렬이 완료된 배열에서 1번째 원소(A[0]), 중앙 원소인 floor((N+1)/2)번째 원소(0-based 인덱스 (N-1)/2), 그리고 마지막 N번째 원소(A[N-1])의 값을 구하십시오.

[제약 사항 (Java 전용)]

1. 배열의 크기 N은 1 이상 2,000 이하의 자연수이다.
2. 각 원소의 값은 1 이상 1,000,000 이하의 자연수이다.
3. 총 교환 횟수는 큰 값이 될 수 있으므로 64비트 정수(long)로 관리하는 것을 권장한다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N이 주어진다.
둘째 줄에 N개의 자연수가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 총 교환 횟수, 1번째 원소(최솟값), 중앙 원소(floor((N+1)/2)번째), N번째 원소(최댓값)를 공백으로 구분하여 출력한다.
형식: `#tc [총 교환 횟수] [Min] [Mid] [Max]`
