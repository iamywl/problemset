[S/W 문제해결 기초] 조합에 대해서 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 조합(Combination)]
조합(Combination)이란 서로 다른 N개의 원소 중에서 R개를 택할 때, '순서를 고려하지 않고' 단순히 선택만 하는 것을 말합니다.
순서가 달라도 구성 원소가 같으면 동일한 경우로 취급하며, 기호로는 nCr로 표기하고 그 경우의 수는 다음과 같습니다:
nCr = n! / (r! * (n-r)!)

조합을 구현하는 가장 대표적인 방법은 재귀 호출(Recursion)에서 직전에 선택한 원소의 다음 인덱스부터 탐색하도록 시작 위치(start) 변수를 전달하는 것입니다:
1. 현재 선택한 개수(depth)가 R에 도달하면 조합 하나가 완성된 것이므로 결과를 출력합니다.
2. start 위치부터 N까지의 숫자를 순회하며 숫자를 선택합니다.
3. 다음 단계(depth + 1)로 재귀 호출할 때, 시작 위치를 방금 선택한 숫자보다 1 큰 값(i + 1)으로 넘겨주어 중복 선택을 방지하고 항상 오름차순을 유지합니다.
4. 재귀 호출이 반환되면 Backtracking을 통해 다음 원소를 선택합니다.

[동작 과정 Trace 예시]
N=4, R=2인 경우, 1부터 4까지의 숫자 중 2개를 고르는 조합의 탐색 단계:
- depth 0, start 1:
  - 1 선택 -> depth 1, start 2 이동
    - 2 선택 -> depth 2 도달! 조합 [1, 2] 완성
    - 3 선택 -> depth 2 도달! 조합 [1, 3] 완성
    - 4 선택 -> depth 2 도달! 조합 [1, 4] 완성
  - 2 선택 -> depth 1, start 3 이동
    - 3 선택 -> depth 2 도달! 조합 [2, 3] 완성
    - 4 선택 -> depth 2 도달! 조합 [2, 4] 완성
  - 3 선택 -> depth 1, start 4 이동
    - 4 선택 -> depth 2 도달! 조합 [3, 4] 완성
총 6가지(4C2 = 6)의 조합이 사전순으로 생성됩니다. 이것을 구현하여 조합의 원리를 완벽히 체득하십시오.

[문제 설명]
1부터 N까지의 자연수 중에서 중복 없이 R개를 고른 모든 조합을 사전 순으로 출력하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. N과 R은 자연수이며, 1 <= R <= N <= 8 이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N과 R이 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 첫 줄에 '#tc'를 출력하고, 다음 줄부터 생성된 조합을 한 줄에 하나씩 공백으로 구분하여 사전 순으로 출력한다.
