[S/W 문제해결 응용] 디저트 선물세트 궁합 (D3)

[알고리즘 개념 및 원리 학습 - 조합과 백트래킹(Backtracking)]
단순한 조합 생성에서 특정 제약 조건(예: 상극인 두 원소는 동시 선택 불가)이 추가되면, 매 선택 단계마다 조건을 검사하여 유망하지 않은 분기를 사전에 차단하는 가지치기(Pruning) 기법이 필요합니다.

[문제 설명]
과일 명품관에서 N가지 과일(1번부터 N번) 중 서로 다른 R개를 골라 고급 선물 바구니를 구성하려고 합니다 (순서 무관).
그런데 과일 전문가들의 연구에 따르면, 함께 담았을 때 숙성 가스나 향의 충돌로 맛을 해치는 상극 과일 쌍이 M개 존재합니다.
선물 바구니 안에 어떠한 상극 과일 쌍도 동시에 포함되지 않도록 하면서 서로 다른 R개의 과일을 선택하는 유효한 선물 바구니의 총 가짓수를 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. 테스트 케이스 개수 T = 10 (샘플 2)
2. 과일의 종류 수 N은 3 이상 16 이하의 자연수이다.
3. 선택할 과일 수 R은 2 이상 min(N, 8) 이하의 자연수이다.
4. 상극 과일 쌍의 개수 M은 0 이상 20 이하의 정수이다.
5. 상극 쌍 (u, v)는 1 <= u < v <= N 이다.
6. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
7. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N, R, M이 공백으로 구분되어 주어진다.
다음 M개의 줄에 걸쳐 상극인 두 과일의 번호 u, v가 공백으로 구분되어 주어진다. (M=0인 경우 생략)

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 상극 충돌이 없는 유효한 선물 바구니의 총 가짓수를 출력한다.
