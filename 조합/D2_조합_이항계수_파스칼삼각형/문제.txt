[S/W 문제해결 기초] 이항계수 파스칼삼각형 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 이항계수와 파스칼의 삼각형]
이항계수(Binomial Coefficient) nCr은 N개의 서로 다른 대상에서 R개를 순서 없이 고르는 조합의 수를 의미합니다.
이항계수는 다음과 같은 매우 아름다운 점화식(파스칼의 항등식)을 만족합니다:
nCr = (n-1)C(r-1) + (n-1)Cr (단, nC0 = nCn = 1)

이 원리는 파스칼의 삼각형(Pascal's Triangle)으로 시각화되며, 2차원 DP 테이블을 채워나가는 방식으로 O(N*R) 시간에 매우 빠르고 오버플로우 없이 계산할 수 있습니다:
1. dp[i][0] = 1, dp[i][i] = 1로 초기화합니다.
2. i행의 j번째 값은 바로 윗 행의 두 값의 합으로 구해집니다: dp[i][j] = dp[i-1][j-1] + dp[i-1][j].

[동작 과정 Trace 예시]
N=4, R=2를 구하는 과정:
- 0행: 1
- 1행: 1 1
- 2행: 1 2 1
- 3행: 1 3 3 1
- 4행: 1 4 6 4 1
4행 2열의 값은 6이 되며, 이는 4C2 = 6과 완벽히 일치합니다! 이것을 구현하여 조합과 DP 테이블 구성의 원리를 익히십시오.

[문제 설명]

주어지는 자연수 N과 R에 대해 이항계수 nCr의 값을 1,000,000,007로 나눈 나머지를 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. N은 1 이상 1,000 이하의 자연수이다.
2. R은 0 이상 N 이하의 정수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N과 R이 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, nCr mod 1,000,000,007의 값을 정수로 출력한다.
