[S/W 문제해결 기본] 서아의 암호 만들기 모음 자음 (D3)

[스토리텔링]
보안 동아리에서 활동하는 서아는 동아리실 금고의 보안 비밀번호를 설정하고 있습니다.
암호는 서로 다른 L개의 알파벳 소문자들로 구성되며, 알파벳이 항상 오름차순으로 정렬되어 있어야 한다는 규칙이 있습니다.
또한 강력한 보안 규칙에 따라 암호는 '최소 1개의 모음(a, e, i, o, u)'과 '최소 2개의 자음'을 반드시 포함해야 합니다.

서아에게 C개의 후보 알파벳 문자들이 주어졌을 때,
위 조건을 모두 만족하는 가능한 모든 L글자 암호 조합을 사전 순으로 출력하십시오.

[제약 사항 (Java 전용)]
1. 암호의 길이 L과 후보 문자의 개수 C는 자연수이며, 3 <= L <= C <= 15 이다.
2. 주어지는 C개의 문자는 알파벳 소문자이며 중복되지 않는다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 L과 C가 공백으로 구분되어 주어진다.
둘째 줄에 C개의 알파벳 소문자가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 첫 줄에 '#tc'를 출력하고, 다음 줄부터 조건을 만족하는 암호를 한 줄에 하나씩 사전 순으로 출력한다.
