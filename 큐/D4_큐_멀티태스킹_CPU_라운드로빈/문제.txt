[S/W 문제해결 심화] 멀티태스킹 CPU 라운드로빈 (D4)

[복합 제약 조건 설명 - 라운드 로빈 스케줄러 시뮬레이션]
운영체제에서 여러 프로세스가 하나의 CPU를 공평하게 공유하기 위해 타임 퀀텀(Time Quantum) Q를 사용하는 라운드 로빈(Round Robin) 스케줄링을 수행합니다.
N개의 프로세스가 각각 도착 시간 A_i와 실행 필요 시간 B_i를 가집니다:
1. 프로세스는 도착 시각에 맞춰 준비 큐(Ready Queue)의 맨 뒤에 진입합니다.
2. CPU는 큐 맨 앞의 프로세스를 꺼내어 최대 Q시간 동안 실행합니다:
   - 만약 프로세스의 남은 실행 시간이 Q 이하라면, 해당 프로세스는 완전히 종료됩니다.
     (종료 시간 = 현재 시각 + 남은 시간, 반환 시간 = 종료 시간 - 도착 시간 A_i)
   - 만약 남은 실행 시간이 Q보다 크다면, Q시간만큼 실행한 후 큐의 맨 뒤로 다시 보냅니다.
3. 동일한 시각에 새로 도착한 프로세스가 있다면, 방금 타임 퀀텀이 만료되어 재진입하는 프로세스보다 '새로 도착한 프로세스'가 큐에 먼저 진입합니다.
4. 모든 프로세스가 종료될 때까지 각 프로세스의 반환 시간(Turnaround Time: 완료시각 - 도착시각)의 총합을 구하십시오.

[제약 사항 (Java 전용)]
1. 프로세스의 수 N은 1 이상 1,000 이하의 자연수이다.
2. 타임 퀀텀 Q는 1 이상 10 이하의 자연수이다.
3. 도착 시각 A_i는 0 이상 10,000 이하의 정수이며, 실행 필요 시간 B_i는 1 이상 100 이하의 자연수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 Q가 공백으로 구분되어 주어진다.
이어지는 N개의 줄에 각 프로세스의 도착 시간 A_i와 실행 시간 B_i가 공백으로 구분되어 주어진다. (입력은 A_i 기준 오름차순)

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 모든 프로세스의 반환 시간 총합을 출력한다.
