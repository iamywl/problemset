[S/W 문제해결 기초] 원형 순번 추출 요세푸스 (D2) - 백준 1158 기반

[자료구조 개념 및 원리 학습 - 큐를 활용한 요세푸스 순열]
1번부터 N번까지 N명의 사람이 원형으로 둘러앉아 있고, 양의 정수 K가 주어집니다.
이제 순서대로 K번째 사람을 제거하는 과정을 N명의 사람이 모두 제거될 때까지 반복합니다.
원이 제거되고 남은 사람들로 다시 원을 이루며 이 과정을 계속합니다.

큐(Queue)를 활용하면 원형 구조를 매우 간단하고 우아하게 구현할 수 있습니다:
1. 1번부터 N번까지 사람을 순서대로 큐에 넣습니다.
2. 매 단계마다 앞의 (K-1)명의 사람을 큐의 앞에서 꺼내어(q.poll()) 다시 큐의 뒤로 넣습니다(q.offer()).
3. K번째에 위치하게 된 맨 앞의 사람을 큐에서 완전히 꺼내어(q.poll()) 제거하고 순번에 기록합니다.
4. 큐가 빌 때까지 반복합니다.

[동작 과정 Trace 예시]
N = 7, K = 3일 때:
- 초기 큐: [1, 2, 3, 4, 5, 6, 7]
- 1, 2 뒤로 이동 -> [3, 4, 5, 6, 7, 1, 2] -> 3 제거 (제거 순서: 3)
- 4, 5 뒤로 이동 -> [6, 7, 1, 2, 4, 5] -> 6 제거 (제거 순서: 3, 6)
- 7, 1 뒤로 이동 -> [2, 4, 5, 7, 1] -> 2 제거 (제거 순서: 3, 6, 2)
- 4, 5 뒤로 이동 -> [7, 1, 4, 5] -> 7 제거 (제거 순서: 3, 6, 2, 7)
- 1, 4 뒤로 이동 -> [5, 1, 4] -> 5 제거 (제거 순서: 3, 6, 2, 7, 5)
- 1, 4 뒤로 이동 -> [1, 4, 1] ... -> 1 제거, 마지막 4 제거
최종 제거 순열: 3 6 2 7 5 1 4

[문제 설명]

N과 K가 주어졌을 때 사람들이 제거되는 순서(요세푸스 순열)를 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. N은 1 이상 1,000 이하의 자연수이다.
2. K는 1 이상 N 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N과 K가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 제거되는 순서대로 사람의 번호를 공백으로 구분하여 한 줄에 출력한다.
