[S/W 문제해결 심화] 슬라이딩윈도우 덱 최솟값 (D4) - 백준 11003 기반

[복합 제약 조건 설명 - 모노톤 덱(Monotone Deque)을 이용한 O(N) 구간 최솟값]
N개의 정수 수열 A_1, A_2, ..., A_N과 윈도우 크기 L이 주어집니다.
각 위치 i (1 <= i <= N)에 대해, 구간 [i - L + 1, i]에서의 최솟값 D_i를 구해야 합니다. (단, i - L + 1 < 1인 경우 1번부터 i번까지의 최솟값)

[복합 해결 조건]
1. N이 최대 100,000에 달하므로, 윈도우마다 선형 탐색 O(N * L)이나 우선순위 큐 O(N log L)를 사용하면 시간 초과가 발생할 위험이 있습니다.
2. 따라서 '모노톤 덱(Monotone Deque)'을 사용하여 완벽한 O(N) 선형 시간에 해결해야 합니다:
   - 덱에는 (인덱스, 값) 쌍을 유지하며 항상 '값의 오름차순'을 유지합니다.
   - 새 원소 A[i]가 들어올 때, 덱 뒤(Rear)에 있는 원소의 값이 A[i]보다 크다면 그 원소는 앞으로 최솟값이 될 가능성이 없으므로 모두 popLast합니다.
   - 덱 앞(Front)에 있는 원소 중 인덱스가 (i - L + 1)보다 작아 현재 윈도우 범위를 벗어난 원소는 popFirst합니다.
   - A[i]를 덱 뒤에 삽입합니다.
   - 덱의 맨 앞(Front)에 있는 값이 바로 현재 윈도우의 최솟값입니다!

[제약 사항 (Java 전용)]
1. 수열의 크기 N은 1 이상 100,000 이하의 자연수이다.
2. 윈도우 크기 L은 1 이상 N 이하의 자연수이다.
3. 각 원소 A_i는 -100,000 이상 100,000 이하의 정수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 L이 공백으로 구분되어 주어진다.
둘째 줄에 N개의 정수가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, D_1부터 D_N까지의 최솟값을 공백으로 구분하여 한 줄에 출력한다.
