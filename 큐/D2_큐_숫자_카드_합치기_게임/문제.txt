[S/W 문제해결 기초] 숫자 카드 합치기 게임 (D2)

[자료구조 개념 및 동작 원리 설명 - 큐 기반 라운드 시뮬레이션]
큐(Queue)는 앞쪽(Front)에서 원소를 제거하고, 뒤쪽(Rear)으로 새 원소를 삽입하는 규칙을 가진 선형 자료구조입니다.
게임이나 라운드 기반 시뮬레이션에서 순환적인 순서 관리를 위해 큐가 폭넓게 활용됩니다.

이 게임에서는 N장의 숫자가 적힌 카드가 큐에 순서대로 놓여 있습니다.
카드가 2장 이상 남아있는 동안 매 라운드마다 다음과 같은 연산을 반복합니다:
1. 큐의 맨 앞 카드 2장을 차례대로 꺼냅니다 (Card A, Card B).
2. 두 카드의 차이의 절댓값 |Card A - Card B|를 계산합니다.
3. 차이가 0보다 크면, 그 차이 값을 큐의 맨 뒤(Rear)에 다시 삽입합니다.
(차이가 0이면 카드가 서로 상쇄되어 큐에 삽입되지 않고 소멸합니다)
4. 큐에 카드가 1장 이하로 남을 때까지 위 과정을 반복합니다.

[동작 과정 Trace 예시]
초기 카드: [10, 6, 2]
- Round 1: '10'과 '6'을 꺼냄. 차이 |10 - 6| = 4 > 0 이므로 큐의 뒤에 4 삽입 -> 큐: [2, 4]
- Round 2: '2'와 '4'를 꺼냄. 차이 |2 - 4| = 2 > 0 이므로 큐의 뒤에 2 삽입 -> 큐: [2]
남은 카드가 1장이므로 게임 종료! 최종 남은 카드는 2입니다.
이것을 구현하여 큐의 FIFO 연산과 게임 라운드 시뮬레이션의 동작을 완벽히 마스터하십시오.

[문제 설명]

주어진 N장의 초기 카드 수열에 대해 게임을 진행하고, 최종적으로 남은 1장의 카드 숫자를 출력하십시오.
만약 모든 카드가 소멸하여 카드가 0장이 남게 되면 0을 출력합니다.

[제약 사항 (Java 전용)]

1. 카드의 장수 N은 2 이상 1,000 이하의 자연수이다.
2. 각 카드에 적힌 정수는 1 이상 1,000 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 카드의 수 N이 주어진다.
둘째 줄에 N장의 카드에 적힌 정수가 공백으로 구분되어 순서대로 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 최종 남은 카드 숫자를 정수로 출력한다 (남은 카드가 없으면 0 출력).
