[문제 설명]
분할 정복(Divide and Conquer)의 가장 대표적인 재귀 패턴은 배열을 반씩 쪼개어 기저 사례(Base Case)에 도달할 때까지 파고든 뒤, 양쪽의 결과를 결합(Combine)하여 상위로 거슬러 올라가는 것입니다.

배열의 크기가 2의 거듭제곱인 N = 2^k (N = 2, 4, 8, 16, 32, 64)로 주어질 때, 구간 [left, right]에 대한 재귀 함수 solve(left, right)는 다음과 같이 동작합니다:

1. [기저 조건 (Base Case)]:
   left == right 인 경우 (원소가 1개인 경우)
   - 더 이상 분할할 수 없으므로, 해당 원소 arr[left]를 즉시 반환합니다.
2. [분할 및 정복 (Divide & Conquer)]:
   mid = (left + right) / 2 로 구간을 반으로 나눕니다.
   - 좌측 절반의 합: sumL = solve(left, mid)
   - 우측 절반의 합: sumR = solve(mid + 1, right)
3. [결합 (Combine)]:
   - 두 구간의 합을 더한 값 (sumL + sumR)을 반환합니다.

이 과정에서 호출되는 총 재귀 함수의 호출 횟수(Call Count)와 배열의 전체 원소 합(Total Sum)을 구하여 출력하십시오.
(원소의 수가 N개인 완전 이진 분할 트리에서는 총 2*N - 1 번의 함수 호출이 발생합니다.)

[동작 원리 및 Trace 예시]
arr = [5, 2, 9, 4] (N = 4) 일 때:
1. solve(0, 3) 호출 (1번째 호출)
   - mid = 1
   - 좌측 solve(0, 1) 호출 (2번째 호출)
     - mid = 0
     - 좌측 solve(0, 0) 호출 (3번째 호출, Base Case) -> 5 반환
     - 우측 solve(1, 1) 호출 (4번째 호출, Base Case) -> 2 반환
     - 결합: 5 + 2 = 7 반환
   - 우측 solve(2, 3) 호출 (5번째 호출)
     - mid = 2
     - 좌측 solve(2, 2) 호출 (6번째 호출, Base Case) -> 9 반환
     - 우측 solve(3, 3) 호출 (7번째 호출, Base Case) -> 4 반환
     - 결합: 9 + 4 = 13 반환
   - 결합: 7 + 13 = 20 반환
최종 원소 합: 20, 총 재귀 호출 수: 7
출력: 20 7

[제약 사항]
1. N은 2, 4, 8, 16, 32, 64 중 하나입니다 (2의 거듭제곱).
2. 배열의 각 원소는 -1,000 이상 1,000 이하의 정수입니다.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어집니다.
각 테스트 케이스의 첫 번째 줄에는 N이 주어집니다.
두 번째 줄에는 N개의 정수가 공백으로 구분되어 주어집니다.

[출력 형식]
각 테스트 케이스마다 '#tc'를 출력하고 한 칸 띄운 후, 배열의 총합과 총 재귀 호출 횟수를 공백으로 구분하여 출력합니다.
