[S/W 문제해결 심화] 행렬 피보나치 거듭제곱 (D4)

[문제 설명]

피보나치 수열의 N번째 항 F_N을 구하는 문제입니다. N이 10^18까지 주어지므로 동적 계획법 O(N)으로도 해결할 수 없습니다. 상태 전이 행렬 [[1, 1], [1, 0]]의 N제곱을 분할 정복(Matrix Power)으로 O(log N) 시간에 계산하여 F_N mod 1,000,000,007을 구하십시오.

[알고리즘 개념 및 문제 해결 핵심 아이디어]

• 핵심 알고리즘: 2x2 전이 행렬 분할 정복 거듭제곱을 통한 피보나치 수열 O(log N) 계산
• 접근 전략: 문제에서 요구하는 핵심 제약과 시간 복잡도를 분석하여, 비효율적인 완전 탐색 대신 최적화된 자료구조와 알고리즘 기법을 적용합니다.

[제약 사항 (Java 전용)]

1. 구하고자 하는 항 N은 1 이상 1,000,000,000,000,000,000(10^18) 이하의 자연수이다.
2. 결과값은 1,000,000,007로 나눈 나머지를 출력한다.
3. F_0 = 0, F_1 = 1, F_2 = 1, ... 로 정의된다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스마다 한 줄에 자연수 N이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, F_N mod 1,000,000,007의 값을 출력한다.
