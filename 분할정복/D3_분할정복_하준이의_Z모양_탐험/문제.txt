[S/W 문제해결 응용] 하준이의 Z모양 탐험 (D3)

[문제 스토리]

하준이는 2^N x 2^N 크기의 2차원 가상 미지의 대륙을 탐험하는 로봇 게임을 개발하고 있습니다.
이 로봇은 맵을 탐색할 때 독특한 'Z 모양' 순서로 사분면을 재귀적으로 방문합니다.
크기가 2 x 2인 기본 구역에서는:
(0, 0) -> (0, 1) -> (1, 0) -> (1, 1) 순서로 방문합니다. (왼쪽 위 -> 오른쪽 위 -> 왼쪽 아래 -> 오른쪽 아래)
크기가 2^N x 2^N인 구역은 다시 4개의 2^(N-1) x 2^(N-1) 사분면으로 쪼개어, 똑같이 Z 모양 순서대로 탐험을 진행합니다.

하준이는 로봇이 목적지 좌표 (r, c)에 도착했을 때까지 방문한 칸의 누적 개수(0-based 순번)가 얼마인지 알고 싶어 합니다.
N이 주어졌을 때 목적지 좌표 (r, c)를 몇 번째로 방문하는지 분할 정복으로 계산하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. N은 1 이상 30 이하의 자연수이다. (격자 크기는 2^N x 2^N)
2. r과 c는 0 이상 2^N - 1 이하의 정수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N, r, c가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 좌표 (r, c)의 0-based 방문 순번을 출력한다.
