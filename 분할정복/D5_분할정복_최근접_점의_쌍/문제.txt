[S/W 역량테스트 B형] 최근접 점의 쌍 (D5)

[문제 설명 - Cormen 알고리즘 33.4 Closest Pair of Points]
2차원 평면 위에 N개의 서로 다른 점들이 주어집니다.
이 N개의 점들 중 '가장 가까운 두 점 사이의 유클리드 거리의 제곱(Squared Euclidean Distance)'을 구하는 프로그램을 작성하십시오.
두 점 (x1, y1)과 (x2, y2) 사이의 거리의 제곱은 (x1 - x2)^2 + (y1 - y2)^2 입니다.

[B형 고난도 알고리즘 설계 요구사항]
1. 모든 점 쌍을 단순 비교하면 O(N^2)의 시간이 소요되어 N = 100,000일 때 100억 번의 연산으로 시간 초과가 발생합니다.
2. 따라서 CLRS Chapter 33.4에 제시된 O(N log N) 분할 정복(Divide-and-Conquer) 기법을 반드시 적용해야 합니다:
- x좌표 기준으로 점들을 정렬한 후, 중앙 분할선 x = mid_x를 기준으로 좌측과 우측으로 재귀 분할합니다.
- 좌측 영역의 최소 거리 d1과 우측 영역의 최소 거리 d2 중 최솟값 d = min(d1, d2)를 구합니다.
- 중앙 분할선 x = mid_x로부터 x좌표 거리가 sqrt(d) 미만인 점들만을 중간 밴드(Strip) 후보로 추출합니다.
- 중간 밴드의 점들을 y좌표 기준으로 정렬하고, 기하학적 성질에 의해 각 점에 대해 y좌표 차이가 sqrt(d) 미만인 최대 7~8개의 인접 점들만 검사하여 d를 갱신합니다.
3. 부동소수점 오차를 방지하기 위해 거리의 제곱(long 타입)만으로 연산해야 합니다.

[제약 사항 (Java 전용)]

1. 점의 개수 N은 2 이상 100,000 이하의 자연수이다.
2. 각 점의 좌표 x, y는 -100,000 이상 100,000 이하의 정수이다.
3. 둘 이상의 점이 동일한 좌표를 갖는 경우는 주어지지 않는다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 점의 개수 N이 주어진다.
이어지는 N개의 줄에는 각 점의 x좌표와 y좌표가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 가장 가까운 두 점 사이의 거리의 제곱을 출력한다.
