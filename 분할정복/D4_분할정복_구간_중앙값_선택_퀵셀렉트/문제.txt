[문제 설명]
크기가 N인 정수 배열에서 K번째(1-based)로 작은 원소를 찾는 문제입니다.
전체 배열을 정렬하면 $O(N \log N)$이 걸리지만, 퀵소트(Quick Sort)의 분할 정복 기법을 변형한 퀵 셀렉트(Quick Select) 알고리즘을 사용하면 평균 $O(N)$ 시간 복잡도에 K번째 원소를 찾을 수 있습니다.
분할 정복 원리:
1. 피벗(Pivot)을 무작위 또는 중앙 원소로 선택합니다.
2. 피벗을 기준으로 배열을 피벗보다 작은 구역, 같은 구역, 큰 구역으로 분할(Divide)합니다.
3. K가 피벗보다 작은 구역의 크기 이내라면, 왼쪽 구역만 재귀 탐색합니다.
4. K가 피벗과 같은 구역에 속한다면, 피벗 값이 바로 K번째 수이므로 즉시 반환(Conquer)합니다.
5. K가 피벗보다 큰 구역에 속한다면, 앞선 구역 크기만큼 K를 차감하고 오른쪽 구역만 재귀 탐색합니다.

이와 같이 한쪽 절반만 선택하여 분할 정복함으로써 평균 $N + N/2 + N/4 + ... = O(N)$에 해결됩니다.

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N(1 <= N <= 100,000)과 K(1 <= K <= N)가 공백으로 주어진다.
두 번째 줄에 N개의 정수가 공백으로 구분되어 주어진다. (원소의 절댓값 <= 1,000,000,000)

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, K번째로 작은 원소를 정수로 출력한다.
