[S/W 문제해결 심화] 구간 중앙값 선택 퀵셀렉트 (D4)

[문제 설명]

정렬되지 않은 N개의 데이터에서 K번째로 작은 원소를 정렬 없이 평균 O(N) 시간에 찾아내는 퀵셀렉트(Quickselect) 알고리즘입니다. 피벗(Pivot)을 기준으로 파티셔닝을 수행한 후, K의 위치가 속한 분할 영역만을 재귀적으로 탐색하여 불필요한 영역의 정렬을 생략합니다.

[알고리즘 개념 및 문제 해결 핵심 아이디어]

• 핵심 알고리즘: 분할 정복 기반 평균 O(N) 선택 알고리즘 (Quickselect / Hoare's Selection)
• 접근 전략: 문제에서 요구하는 핵심 제약과 시간 복잡도를 분석하여, 비효율적인 완전 탐색 대신 최적화된 자료구조와 알고리즘 기법을 적용합니다.

[제약 사항 (Java 전용)]

1. 원소의 개수 N은 1 이상 5,000,000 이하의 자연수이다.
2. 찾고자 하는 순번 K는 1 이상 N 이하의 자연수이다.
3. 배열의 원소는 -1,000,000,000 이상 1,000,000,000 이하의 정수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내 (O(N log N) 전체 정렬 시 시간 초과 유발 가능)
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 K가 공백으로 구분되어 주어진다.
둘째 줄에 N개의 정수가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, K번째로 작은 수를 출력한다.
