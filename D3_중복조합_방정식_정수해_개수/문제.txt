[S/W 문제해결 응용] 방정식 정수해 개수 (D3)
[알고리즘 개념] 중복조합과 치환
방정식 x_1 + x_2 + ... + x_N = K 를 만족하는 정수해의 개수를 구합니다.
단, 각 변수 x_i는 최소 L 이상이어야 합니다 (x_i >= L).
조건을 만족하는 정수해 순서쌍 (x_1, x_2, ..., x_N)의 개수를 구하시오.
만약 해가 존재하지 않는다면 0을 출력합니다.

[제약 사항 (Java 전용)]
1. T = 10 (샘플 2)
2. 2 <= N <= 8, 1 <= K <= 20, 0 <= L <= 5
3. 시간 제한: 2.0초, 메모리 제한: 256MB

[입력]
T
N K L

[출력]
#tc 정수해개수
