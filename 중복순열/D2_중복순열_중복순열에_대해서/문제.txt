[S/W 문제해결 기초] 중복순열에 대해서 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 중복순열(Permutation with Repetition)]
중복순열(Permutation with repetition)이란 서로 다른 N개의 원소 중에서 '중복을 허용하여' R개를 택해 순서를 고려하여 나열하는 것을 말합니다.
기호로는 nΠr로 표기하며, 매 자리마다 N개의 원소를 모두 선택할 수 있으므로 경우의 수는 다음과 같습니다:
nΠr = n^r

일반 순열과 달리 한 번 선택한 원소를 다시 선택할 수 있으므로, 방문 여부를 체크하는 불리언 배열(visited)이 필요하지 않습니다:
1. 현재 위치(depth)가 R에 도달하면 중복순열 하나가 완성된 것이므로 결과를 출력합니다.
2. 1부터 N까지의 모든 숫자를 순회하면서, visited 검사 없이 현재 depth에 숫자를 담고 다음 단계(depth + 1)로 재귀 호출합니다.
3. 이를 통해 트리 형태로 모든 분기를 탐색하여 총 N^R개의 순열을 사전순으로 생성할 수 있습니다.

[동작 과정 Trace 예시]
N=3, R=2인 경우, 1부터 3까지의 숫자로 만들 수 있는 중복순열 탐색 단계:
- depth 0: 1 선택 -> depth 1 이동
- depth 1: 1 선택 -> [1, 1] 완성
- depth 1: 2 선택 -> [1, 2] 완성
- depth 1: 3 선택 -> [1, 3] 완성
- depth 0: 2 선택 -> depth 1 이동
- depth 1: 1 선택 -> [2, 1] 완성
- depth 1: 2 선택 -> [2, 2] 완성
- depth 1: 3 선택 -> [2, 3] 완성
- depth 0: 3 선택 -> [3, 1], [3, 2], [3, 3] 완성
총 3^2 = 9가지 중복순열이 사전순으로 생성됩니다. 이것을 구현하여 중복순열의 원리를 완벽히 체득하십시오.

[문제 설명]

1부터 N까지의 자연수 중에서 중복을 허용하여 R개를 고른 모든 중복순열을 사전 순으로 출력하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. N과 R은 자연수이며, 1 <= R <= N <= 7 이고 N^R <= 50,000 이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N과 R이 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 첫 줄에 '#tc'를 출력하고, 다음 줄부터 생성된 중복순열을 한 줄에 하나씩 공백으로 구분하여 사전 순으로 출력한다.
