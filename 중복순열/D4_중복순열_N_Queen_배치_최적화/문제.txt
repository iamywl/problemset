[S/W 문제해결 응용] N Queen 배치 최적화 (D4)

[복합 제약조건 및 알고리즘 최적화]
N x N 크기의 체스판 위에 N개의 퀸(Queen)을 서로 공격할 수 없게 배치하는 N-Queen 문제입니다.
퀸은 가로, 세로, 대각선(우상향, 우하향) 8방향으로 거리 제한 없이 이동할 수 있습니다.
따라서 한 행에는 정확히 하나의 퀸만 배치될 수 있으며, 각 행마다 퀸이 위치할 열의 인덱스(0 ~ N-1)를 결정하는 중복순열 탐색 문제입니다.

N이 최대 14에 달할 때, N^N 중복순열은 14^{14} 약 1.1 x 10^{16}에 달하여 시간 초과가 발생합니다.
따라서 다음과 같은 복합 제약조건 최적화를 적용해야 합니다:
1. 열 점유 여부 (`col[c]`), 우하향 대각선 (`diag1[r - c + N]`), 우상향 대각선 (`diag2[r + c]`)을 불리언 배열 또는 비트마스크로 관리하여 충돌 여부를 O(1)에 판별합니다.
2. 유망하지 않은 열 배치는 즉시 가지치기(Pruning)하여 전체 경우의 수를 2초 이내로 단축시킵니다.

[문제 설명]

체스판의 크기 N이 주어질 때 N개의 퀸을 서로 공격할 수 없게 배치하는 총 경우의 수를 구하십시오.

[제약 사항 (Java 전용)]

1. N은 1 이상 13 이하의 자연수이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 자연수 N이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 가능한 퀸 배치의 총 경우의 수를 정수로 출력한다.
