[S/W 문제해결 심화] 과일 시너지 극대화 (D4)

[알고리즘 개념 및 원리 학습 - 비트마스크와 부분집합(Bitmask)]

정수의 각 비트(0 또는 1)를 집합의 원소 포함 여부로 매핑하는 비트마스크 기법은 N개의 원소로 구성된 모든 부분집합을 0부터 (2^N - 1)까지의 정수로 간결하고 빠르게 순회할 수 있게 해줍니다.

[문제 설명]

호텔 셰프가 N가지 과일(0번부터 N-1번)을 조합하여 새로운 시그니처 샐러드를 개발하려고 합니다.
각 과일 i는 단독으로 포함되었을 때 고유한 기본 만족도 P_i를 제공합니다.
또한 두 과일 i와 j가 동시에 샐러드에 포함되면, 상호작용으로 인해 시너지 점수 S[i][j]가 추가로 발생합니다 (S[i][j] = S[j][i], 음수일 수도 있음).
샐러드의 풍성함을 위해 최소 2개 이상의 과일을 선택해야 합니다.
선택된 과일들의 기본 만족도 총합과, 선택된 모든 과일 쌍 사이의 시너지 점수 총합을 더한 '샐러드 종합 점수'의 최댓값을 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. 테스트 케이스 개수 T = 10 (샘플 2)
2. 과일의 종류 수 N은 3 이상 14 이하의 자연수이다.
3. 각 과일의 기본 만족도 P_i는 -100 이상 100 이하의 정수이다.
4. 시너지 점수 S[i][j]는 -100 이상 100 이하의 정수이다 (S[i][i] = 0).
5. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
6. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N이 주어진다.
둘째 줄에 N개 과일의 기본 점수 P_0, P_1, ..., P_{N-1}이 공백으로 구분되어 주어진다.
다음 N개의 줄에 걸쳐 N x N 크기의 시너지 행렬 S[i][j]가 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 샐러드 종합 점수의 최댓값을 출력한다.
