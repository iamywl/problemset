[S/W 문제해결 응용] 비트마스크 동적계획법 집합 분할 (D4)

[복합 제약조건 및 알고리즘 최적화]
N개의 작업이 있으며, 각 작업의 처리 시간 T_i가 주어집니다.
최대 처리 용량이 C인 서버 한 대에 동시에 할당할 수 있는 작업들의 처리 시간 총합은 C 이하여야 합니다.
모든 N개의 작업을 처리하기 위해 필요한 최소 서버 대수를 구해야 합니다.

작업의 수 N이 최대 16개일 때, 상태를 방문한 작업들의 부분집합 비트마스크(mask: 0 ~ (1<<N)-1)로 나타냅니다.
상태 전이에서 mask의 모든 부분집합 submask를 순회하는 O(3^N) 또는 O(N * 2^N) 비트마스크 DP 최적화를 적용해야 합니다:
`dp[mask]`: mask에 포함된 작업들을 처리하는 데 필요한 최소 서버 수와 마지막 서버의 남은 잔여 용량 쌍(pair)을 기록하여 O(N * 2^N) 시간에 해결하는 복합 제약조건 최적화를 달성하십시오.

[문제 설명]

주어진 N개의 작업 시간과 서버 용량 C에 대해 모든 작업을 완료하기 위해 필요한 최소 서버 대수를 구하십시오.

[제약 사항 (Java 전용)]

1. 작업의 수 N은 1 이상 15 이하의 자연수이다.
2. 서버의 용량 C는 1 이상 1,000,000 이하의 자연수이다.
3. 각 작업의 처리 시간 T_i는 1 이상 C 이하의 자연수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 C가 공백으로 구분되어 주어진다.
둘째 줄에 N개의 작업 처리 시간이 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 필요한 최소 서버 대수를 정수로 출력한다.
