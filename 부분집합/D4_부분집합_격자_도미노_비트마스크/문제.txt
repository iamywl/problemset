[S/W 문제해결 심화] 격자 도미노 비트마스크 (D4)

[알고리즘 개념] 프로파일 DP (Profile Bitmask DP)

2 x N 크기의 직사각형 벽면을 2 x 1 크기의 도미노 블록들로 빈틈없이 채우려고 합니다.
단, 벽면 중 특정 K개의 1 x 1 칸은 이미 파손되어 블록을 놓을 수 없습니다.
남은 정상적인 빈칸들을 2 x 1 도미노 블록들로 겹치지 않고 남김없이 완벽히 채울 수 있는 서로 다른 방법의 수를 구하시오.
(파손된 칸을 제외한 정상 칸의 수가 홀수이면 도미노로 채울 수 없으므로 0입니다)

[제약 사항 (Java 전용)]

1. T = 10 (샘플 2)
2. 1 <= N <= 14, 0 <= K <= 4
3. 시간 제한: 2.0초, 메모리 제한: 256MB

[입력]

T
N K
다음 K줄에 걸쳐 파손된 칸의 좌표 r c (0 <= r <= 1, 0 <= c < N)

[출력]

#tc 방법수
