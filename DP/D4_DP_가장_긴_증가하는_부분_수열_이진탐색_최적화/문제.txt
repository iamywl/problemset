[S/W 문제해결 응용] 가장 긴 증가하는 부분 수열 이진탐색 최적화 (D4)

[복합 제약조건 및 알고리즘 최적화]
수열 A가 주어졌을 때, 가장 긴 증가하는 부분 수열(Longest Increasing Subsequence, LIS)의 길이를 구하는 문제입니다.
예를 들어 수열 A = [10, 20, 10, 30, 20, 50] 라면, LIS는 [10, 20, 30, 50] 로 길이는 4입니다.

수열의 크기 N이 최대 100,000에 달하므로 다음과 같은 복합 제약조건 최적화가 필수적입니다:
1. 기존의 O(N^2) 2중 반복문 DP는 100,000^2 = 10^{10} 연산으로 시간 초과 판정을 받습니다.
2. 따라서 LIS의 길이를 유지하는 '최소 끝값 배열(tails 또는 lisTable)'을 관리하며,
각 원소 x에 대해 이진 탐색(Lower Bound)을 수행하여 대체하거나 뒤에 추가하는 O(N log N) 최적화를 달성해야 합니다.

[문제 설명]

주어진 수열 A의 LIS의 길이를 구하십시오.

[제약 사항 (Java 전용)]

1. 수열의 크기 N은 1 이상 100,000 이하의 자연수이다.
2. 각 원소는 -1,000,000,000 이상 1,000,000,000 이하의 정수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 수열의 크기 N이 주어진다.
둘째 줄에 수열 A의 원소 N개가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, LIS의 길이를 정수로 출력한다.
