[S/W 역량테스트 B형] 외판원 순회 비트마스크 (D5)

[문제 설명 - Traveling Salesperson Problem (TSP)]
1번부터 N번까지 번호가 매겨진 N개의 도시가 있고, 도시들 사이에는 길이 있습니다. (길이 없을 수도 있습니다.)
외판원은 어느 한 도시에서 출발하여 N개의 모든 도시를 정확히 한 번씩만 거친 후, 다시 처음 출발했던 도시로 돌아오는 '최소 비용의 순회 경로'를 계획하고자 합니다.
각 도시 i에서 j로 가는 비용 W[i][j]가 2차원 행렬로 주어집니다. (W[i][j] = 0은 i에서 j로 직접 가는 길이 없음을 뜻합니다.)

[B형 고난도 알고리즘 설계 요구사항]
1. N개의 도시를 순회하는 모든 경로를 단순 백트래킹(N!)으로 탐색하면 N=16일 때 약 20조 번의 연산으로 시간 초과가 발생합니다.
2. 따라서 '비트마스킹(Bitmasking)과 동적 계획법(DP)'을 결합하여 상태 공간을 압축해야 합니다:
   - `dp[mask][u]`: 현재까지 방문한 도시들의 비트마스크 집합이 `mask`이고, 현재 위치한 도시가 `u`일 때, 나머지 모든 미방문 도시들을 방문하고 출발 도시(0번)로 복귀하는 최소 추가 비용.
   - 점화식: dp[mask][u] = min_{v} (dp[mask | (1 << v)][v] + W[u][v]) (단, v는 미방문이고 W[u][v] > 0)
   - 기저 조건: mask == (1 << N) - 1 일 때, W[u][0] > 0 이면 W[u][0], 아니면 INF 반환.
3. 순회 경로이므로 어느 도시에서 시작하든 사이클의 총비용은 동일합니다. 따라서 시작점을 0번 도시로 고정(mask = 1, u = 0)하여 탐색합니다.
4. 시간 복잡도 O(N^2 * 2^N) 안에 16개 도시의 최적 순회 비용을 완벽히 계산해야 합니다.

[제약 사항 (Java 전용)]
1. 도시의 수 N은 2 이상 16 이하의 자연수이다.
2. 각 비용 W[i][j]는 0 이상 1,000,000 이하의 정수이다. (대각선 W[i][i]는 항상 0)
3. 항상 순회 가능한 경로가 적어도 하나 존재한다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 도시의 수 N이 주어진다.
이어지는 N개의 줄에는 각 도시 간의 이동 비용 행렬 W가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 외판원의 최소 순회 비용을 출력한다.
