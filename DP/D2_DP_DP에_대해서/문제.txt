[S/W 문제해결 기초] DP에 대해서 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 동적 계획법(Dynamic Programming)]
동적 계획법(Dynamic Programming, DP)은 복잡한 문제를 여러 개의 작은 하위 문제(Subproblem)로 나누어 해결한 뒤,
그 하위 문제들의 해를 배열이나 테이블(DP Table)에 저장(Memoization / Tabulation)하여 중복 계산을 방지하는 알고리즘 설계 기법입니다.
단순 재귀 호출로 풀면 지수 시간(O(2^N))이 걸리는 문제를 다항 시간(O(N) 또는 O(N^2))으로 획기적으로 단축시킵니다.

DP가 성립하기 위한 2대 필수 조건:
1. 중복되는 부분 문제(Overlapping Subproblems): 동일한 작은 문제들이 반복해서 호출된다.
2. 최적 부분 구조(Optimal Substructure): 큰 문제의 최적해가 작은 문제들의 최적해로부터 구해진다.

가장 대표적인 예시는 계단 오르기(피보나치 수열) 문제입니다:
계단을 한 번에 1칸 또는 2칸씩 오를 수 있을 때, N번째 계단에 도달하는 방법의 수 dp[N]은:
- 바로 전 칸(N-1)에서 1칸 올라오는 경우: dp[N-1]
- 두 칸 전(N-2)에서 2칸 올라오는 경우: dp[N-2]
따라서 점화식은 다음과 같이 정의됩니다:
dp[N] = dp[N-1] + dp[N-2] (단, dp[1] = 1, dp[2] = 2)

[동작 과정 Trace 예시]
N=5 계단을 오르는 방법의 수를 바텀업(Bottom-Up)으로 채우는 과정:
- dp[1] = 1 (1)
- dp[2] = 2 (1+1, 2)
- dp[3] = dp[2] + dp[1] = 2 + 1 = 3 (1+1+1, 1+2, 2+1)
- dp[4] = dp[3] + dp[2] = 3 + 2 = 5
- dp[5] = dp[4] + dp[3] = 5 + 3 = 8
총 8가지 방법이 존재합니다. 이것을 구현하여 DP 테이블 구축과 점화식의 원리를 완벽히 체득하십시오.

[문제 설명]

계단의 수 N이 주어질 때, 1칸 또는 2칸씩 올라가서 N번째 계단에 도달할 수 있는 모든 방법의 수를 1,000,000,007로 나눈 나머지를 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. N은 1 이상 100,000 이하의 자연수이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 계단의 수 N이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 방법의 수 mod 1,000,000,007의 값을 정수로 출력한다.
