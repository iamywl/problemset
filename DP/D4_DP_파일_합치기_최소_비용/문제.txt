[S/W 문제해결 심화] 파일 합치기 최소 비용 (D4)

[문제 설명]

소설의 여러 장(Chapter)이 각각 독립된 파일로 나누어져 있습니다. 두 개의 연속된 파일을 합쳐 하나의 임시 파일로 만들고, 이 임시 파일들을 다시 합치는 과정을 반복하여 최종 하나의 완성본 파일로 묶으려 합니다.
두 파일을 합칠 때 드는 비용은 두 파일 크기의 합입니다.
K개의 장을 연속으로 하나로 합치는 데 드는 총비용의 최솟값을 구하십시오.

[알고리즘 개념 및 문제 해결 핵심 아이디어]

• 핵심 알고리즘: 구간 동적 계획법 (Interval DP O(K^3))
• 점화식: dp[i][j] = min_{k=i..j-1} (dp[i][k] + dp[k+1][j]) + sum(cost[i..j])
• 구간의 길이 len을 2부터 K까지 증가시키며 하위 구간의 최적해를 조합합니다.

[제약 사항 (Java 전용)]

1. 소설의 장 수 K는 1 이상 300 이하의 자연수이다.
2. 각 장의 파일 크기는 1 이상 10,000 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스 첫 줄에 장의 수 K가 주어지고, 둘째 줄에 K개의 파일 크기가 공백으로 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 파일을 하나로 합치는 데 드는 최소 비용을 출력한다.
