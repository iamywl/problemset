[S/W 문제해결 심화] 최장 공통 부분수열 LCS (D4)

[복합 제약 조건 설명 - CLRS 15.4 Longest Common Subsequence]
두 개의 알파벳 대문자 문자열 A와 B가 주어집니다.
두 문자열 모두의 부분 수열이 되는 문자열 중 가장 길이가 긴 수열을 최장 공통 부분수열(Longest Common Subsequence, LCS)이라고 합니다.
(예: 'ACAYKP'와 'CAPCAK'의 LCS는 'ACAK'이며 길이는 4입니다.)

[복합 해결 조건]
1. 2차원 DP 테이블 `LCS[i][j]`를 구성하여 O(|A| * |B|)에 최장 길이를 계산해야 합니다:
- A[i-1] == B[j-1]: LCS[i][j] = LCS[i-1][j-1] + 1
- A[i-1] != B[j-1]: LCS[i][j] = max(LCS[i-1][j], LCS[i][j-1])
2. 단순히 길이만 출력하는 것이 아니라, 완성된 DP 테이블로부터 우하단(i=|A|, j=|B|)에서 시작하여 역추적(Backtracking)을 수행하여 실제 LCS 문자열을 정확히 복원해야 합니다.
3. 만약 공통 부분 수열이 전혀 없다면 길이 0과 함께 빈 문자열 대신 0을 출력해야 합니다.

[제약 사항 (Java 전용)]

1. 문자열 A와 B의 길이는 1 이상 1,000 이하의 자연수이다.
2. 문자열은 알파벳 대문자로만 구성된다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 문자열 A가 주어진다.
둘째 줄에 문자열 B가 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 첫 번째로 LCS의 길이, 두 번째로 복원된 LCS 문자열을 공백으로 구분하여 출력한다. (길이가 0이면 '0 0' 출력)
