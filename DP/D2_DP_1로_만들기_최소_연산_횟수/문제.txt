[S/W 문제해결 기초] 1로 만들기 최소 연산 횟수 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - DP 기반 최소 연산 횟수 최적화]
정수 N에 사용할 수 있는 연산은 다음과 같이 세 가지가 있습니다:
1. X가 3으로 나누어 떨어지면, 3으로 나눈다.
2. X가 2로 나누어 떨어지면, 2로 나눈다.
3. 1을 뺀다.

정수 N이 주어졌을 때, 위 세 가지 연산을 적절히 사용하여 1을 만드는 최소 연산 횟수를 구하는 문제입니다.
그리디 방식으로 '항상 3으로 나누는 것'이 최적이 되지 않는 반례(예: N=10 -> 10-1=9 -> 9/3=3 -> 3/3=1 (3번), 만약 10/2=5 -> 5-1=4 -> 4/2=2 -> 2/2=1 (4번))가 존재하므로,
모든 하위 상태의 최솟값을 기록하는 동적 계획법(DP)을 사용해야 합니다.

점화식:
dp[i] = dp[i-1] + 1
if (i % 2 == 0) dp[i] = min(dp[i], dp[i/2] + 1)
if (i % 3 == 0) dp[i] = min(dp[i], dp[i/3] + 1)

[동작 과정 Trace 예시]
N=10일 때 DP 테이블 채우기:
- dp[1] = 0
- dp[2] = min(dp[1]+1, dp[1]+1) = 1
- dp[3] = min(dp[2]+1, dp[1]+1) = 1
- dp[4] = min(dp[3]+1, dp[2]+1) = 2
- ...
- dp[9] = min(dp[8]+1, dp[3]+1) = 2 (9/3=3 -> 3/3=1)
- dp[10] = min(dp[9]+1, dp[5]+1) = min(3, 4) = 3
최소 연산 횟수는 3입니다. 이것을 구현하여 다중 분기 점화식의 원리를 마스터하십시오.

[문제 설명]

정수 N이 주어질 때 1로 만드는 데 필요한 최소 연산 횟수를 구하십시오.

[제약 사항 (Java 전용)]

1. N은 1 이상 1,000,000 이하의 자연수이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 정수 N이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 최소 연산 횟수를 정수로 출력한다.
