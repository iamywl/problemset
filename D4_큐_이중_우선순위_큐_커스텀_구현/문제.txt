[S/W 문제해결 응용] 이중 우선순위 큐 커스텀 구현 (D4)

[복합 제약조건 및 알고리즘 최적화]
이중 우선순위 큐(Double-ended Priority Queue)는 데이터 삽입과 함께 최댓값 삭제 및 최솟값 삭제를 모두 지원하는 고난도 자료구조입니다.
명령어의 종류는 다음과 같습니다:
1. `I X`: 정수 X를 큐에 삽입합니다.
2. `D 1`: 큐에서 최댓값을 하나 삭제합니다. 만약 큐가 비어있다면 무시합니다.
3. `D -1`: 큐에서 최솟값을 하나 삭제합니다. 만약 큐가 비어있다면 무시합니다.

명령어의 개수 N이 최대 100,000개 주어지므로, 일반 배열이나 단순 정렬로는 $O(N^2)$ 시간이 걸려 시간 초과 판정을 받습니다.
최대 힙(Max Heap)과 최소 힙(Min Heap)을 동시에 운용하면서, 각 원소의 유효성을 고유 ID 또는 불리언 방문 배열로 관리하는 동기화 지연 삭제(Lazy Deletion) 기법을 구현해야 합니다.
이를 통해 모든 연산을 $O(N \log N)$ 시간 내에 정확히 처리하는 커스텀 동기화 큐 최적화를 달성하십시오.

[문제 설명]
주어진 N개의 연산을 모두 수행한 후, 큐가 비어있으면 "EMPTY"를 출력하고, 비어있지 않다면 최댓값과 최솟값을 공백으로 구분하여 출력하십시오.

[제약 사항 (Java 전용)]
1. 연산의 개수 N은 1 이상 100,000 이하의 자연수이다.
2. 정수 X는 -1,000,000 이상 1,000,000 이하의 정수이다.
3. 최댓값(또는 최솟값)이 여러 개일 경우 하나만 삭제한다.
4. 시간 제한: 10개 테스트케이스 기준 2.5초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 연산의 개수 N이 주어진다.
이어지는 N개의 줄에 걸쳐 명령어가 한 줄에 하나씩 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 큐가 비어있으면 "EMPTY", 비어있지 않으면 최댓값과 최솟값을 공백으로 구분하여 한 줄에 출력한다.
