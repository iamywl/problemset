[S/W 문제해결 심화] 이진탐색트리 범위합 (D4)

[복합 제약 조건 설명 - CLRS Ch 12 Binary Search Trees]
이진 탐색 트리(Binary Search Tree, BST)는 효율적인 탐색, 삽입, 삭제를 지원하는 핵심 트리 자료구조입니다.
BST의 모든 노드 x는 다음의 중요한 성질(BST Property)을 만족합니다:
- x의 왼쪽 서브트리에 있는 모든 노드 y의 키 값은 x의 키 값보다 작다. (y.key < x.key)
- x의 오른쪽 서브트리에 있는 모든 노드 y의 키 값은 x의 키 값보다 크다. (y.key > x.key)

[복합 해결 조건]
1. BST 동적 구축 (TREE-INSERT):
   - 빈 BST에 N개의 정수가 주어지는 순서대로 하나씩 삽입됩니다.
   - 첫 번째 정수가 루트(Root) 노드가 되며, 이후 정수들은 BST 속성에 따라 위치를 찾아 삽입됩니다.
   - 중복 키 무시: 만약 삽입하려는 키가 이미 트리에 존재한다면 새로 삽입하지 않고 건너뜁니다.
2. 범위 합 질의(Range Sum Query) 및 BST 가지치기(Pruning):
   - 트리가 완성된 후, 구간 [L, R] (L <= key <= R)에 속하는 모든 노드 값의 총합을 계산해야 합니다.
   - 단순 전체 순회가 아닌 BST의 정렬 속성을 활용하여 불필요한 서브트리 탐색을 배제(Pruning)해야 합니다:
     * 현재 노드의 키 < L : 현재 노드 및 왼쪽 서브트리의 모든 노드는 L보다 작으므로, 오른쪽 서브트리만 탐색합니다.
     * 현재 노드의 키 > R : 현재 노드 및 오른쪽 서브트리의 모든 노드는 R보다 크므로, 왼쪽 서브트리만 탐색합니다.
     * L <= 현재 노드의 키 <= R : 현재 노드의 키를 합에 더하고, 왼쪽 서브트리와 오른쪽 서브트리를 모두 탐색합니다.
3. 64비트 정수 연산:
   - 노드의 키 값이 최대 1,000,000,000에 달하므로, 범위 합이 32비트 정수 범위를 초과할 수 있습니다. 반드시 64비트 정수형(Java의 long)으로 계산해야 합니다.

[문제 설명]
N개의 정수와 범위 [L, R]이 주어질 때, 주어진 정수들을 순서대로 BST에 삽입한 후 범위 [L, R]에 속하는 노드 값들의 총합을 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. 노드의 개수 N은 1 이상 10,000 이하의 자연수이다.
2. 각 노드의 키 값 및 L, R은 1 이상 1,000,000,000 이하의 자연수이다. (L <= R)
3. 입력으로 주어지는 정수에는 중복된 값이 포함될 수 있으며, 이미 트리에 존재하는 값은 새로 삽입하지 않는다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 노드의 개수 N과 구간의 시작 L, 끝 R이 공백으로 구분되어 주어진다.
둘째 줄에 BST에 삽입될 N개의 정수가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 구간 [L, R]에 속하는 노드 키들의 합을 출력한다. (속하는 노드가 없으면 0 출력)
