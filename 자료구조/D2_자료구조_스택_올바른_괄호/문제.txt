[S/W 문제해결 기초] 올바른 괄호 (D2)

[알고리즘 개념 및 원리 학습 - 스택(Stack, CLRS Ch 10.1)]

스택(Stack)은 '가장 마지막에 들어간 데이터가 가장 먼저 나오는' 후입선출(LIFO: Last-In, First-Out) 원칙을 따르는 대표적인 선형 자료구조입니다.
한쪽 끝(Top)에서만 데이터의 삽입(Push)과 삭제(Pop)가 일어납니다.

[동작 원리 및 괄호 검사 적용]
여는 괄호와 닫는 괄호의 짝을 맞추는 문제는 스택의 대표적인 응용 사례입니다.
수식이나 코드에서 가장 안쪽(가장 최근에 열린) 괄호가 가장 먼저 닫혀야 하므로, LIFO 구조를 가진 스택이 최적의 해결책이 됩니다.

1. 문자열을 왼쪽부터 오른쪽으로 한 글자씩 확인합니다.
2. 여는 괄호('(', '{', '[')를 만나면 스택에 PUSH합니다.
3. 닫는 괄호(')', '}', ']')를 만나면:
- 만약 스택이 비어 있다면, 짝이 맞지 않는 닫는 괄호가 먼저 나온 것이므로 '유효하지 않음(0)'입니다.
- 스택의 맨 위(Top)에 있는 여는 괄호를 POP하여 현재 닫는 괄호와 짝이 일치하는지 비교합니다:
* ')'는 '('와 매칭
* '}'는 '{'와 매칭
* ']'는 '['와 매칭
- 만약 짝이 일치하지 않으면 '유효하지 않음(0)'입니다.
4. 문자열의 모든 문자를 확인한 후:
- 스택이 비어 있다면 모든 괄호의 짝이 올바르게 닫힌 것이므로 '올바른 괄호(1)'입니다.
- 스택에 아직 닫히지 않은 여는 괄호가 남아 있다면 '유효하지 않음(0)'입니다.

[동작 예시]
예시 1) "{[()]}"
- '{' push -> stack: ['{']
- '[' push -> stack: ['{', '[']
- '(' push -> stack: ['{', '[', '(']
- ')' pop '(' -> 매칭 일치 -> stack: ['{', '[']
- ']' pop '[' -> 매칭 일치 -> stack: ['{']
- '}' pop '{' -> 매칭 일치 -> stack: []
- 문자열 순회 종료 후 스택이 비어 있으므로 1 반환.

예시 2) "([)]"
- '(' push -> stack: ['(']
- '[' push -> stack: ['(', '[']
- ')' pop '[' -> 짝 불일치! 즉시 0 반환.

[문제 설명]

소괄호 '()', 중괄호 '{}', 대괄호 '[]'의 세 가지 종류의 괄호로만 이루어진 문자열이 주어집니다.
이 문자열이 올바른 괄호 문자열인지 판별하여, 올바르면 1, 올바르지 않으면 0을 출력하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]

1. 문자열의 길이 N은 1 이상 10,000 이하의 자연수이다.
2. 문자열은 '(', ')', '{', '}', '[', ']' 의 6가지 문자로만 구성된다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스마다 한 줄에 괄호 문자열이 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 올바른 괄호 문자열이면 1, 아니면 0을 출력한다.
