[S/W 문제해결 기본] 바이러스 확산 시간 (D2)

N×N 크기의 연구소에 바이러스가 유출되었다.
연구소의 각 칸은 빈 칸(0), 벽(1), 바이러스가 있는 칸(2) 중 하나이다.
바이러스는 매 초마다 인접한 상, 하, 좌, 우의 모든 빈 칸으로 동시에 증식한다. 벽으로는 퍼질 수 없다.
연구소의 모든 빈 칸에 바이러스가 퍼지는 데 걸리는 최소 시간(초)을 구하라.
만약 벽에 둘러싸여 바이러스가 도달할 수 없는 빈 칸이 존재한다면 -1을 출력하라.
(처음부터 빈 칸이 없는 경우에는 0을 출력한다.)

[제약 사항 (Java 전용)]
1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. 연구소 크기 N은 3 이상 15 이하의 정수이다. (3 <= N <= 15)

[입력]
첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에는 연구소 크기 N이 주어진다.
다음 N개의 줄에 걸쳐 N개의 정수가 공백으로 구분되어 주어진다. (0: 빈칸, 1: 벽, 2: 바이러스)

[출력]
각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 모든 빈 칸에 바이러스가 퍼지는 최소 시간(초)을 출력한다. 도달 불가 시 -1.
