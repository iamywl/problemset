[S/W 문제해결 기초] 음이아닌 정수해 순서쌍 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 부정방정식의 정수해와 중복조합]
방정식 x_1 + x_2 + ... + x_N = S 에 대하여,
각 변수 x_i가 '음이 아닌 정수(0, 1, 2, ...)'일 때 만족하는 순서쌍 (x_1, x_2, ..., x_N)의 개수를 구하는 문제입니다.

이 문제는 S개의 똑같은 구슬을 서로 다른 N개의 상자(변수)에 나누어 담는 것과 완전히 동일하므로,
순서쌍의 총 개수는 정확히 n H S = (n + S - 1) C S 입니다.
만약 양의 정수해(x_i >= 1)라면 각 변수에 미리 1씩 배정한 뒤 n H (S - n)으로 계산할 수 있습니다.
이처럼 대수학의 부정방정식 해를 조합론적으로 해석하여 O(1)에 경우의 수를 도출합니다.

[동작 과정 Trace 예시]
N=3, S=4인 경우:
x_1 + x_2 + x_3 = 4 (x_i >= 0)
순서쌍 개수 = 3H4 = (3+4-1)C4 = 6C4 = 15가지!
이것을 구현하여 정수해 개수 계산의 원리를 마스터하십시오.

[문제 설명]
변수의 개수 N과 합 S가 주어질 때 음이 아닌 정수해 순서쌍의 개수를 1,000,000,007로 나눈 나머지를 구하십시오.

[제약 사항 (Java 전용)]
1. N과 S는 1 이상 1,000 이하의 자연수이다.
2. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
3. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄에 N과 S가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 순서쌍 개수 mod 1,000,000,007의 값을 정수로 출력한다.
