[S/W 역량테스트 Professional / B형] N-Queen 배치 (D5)

N×N 크기의 체스판 위에 N개의 퀸(Queen)을 서로 공격할 수 없도록 놓으려고 한다.
퀸은 같은 행, 같은 열, 그리고 대각선(좌상-우하, 우상-좌하) 방향의 모든 칸에 있는 말을 공격할 수 있다.
체스판의 크기 N이 주어졌을 때, 퀸 N개를 서로 공격할 수 없게 배치하는 가능한 모든 경우의 수를 구하는 프로그램을 작성하라.

[제약 사항 (Java 전용)]

1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. N은 1 이상 12 이하의 정수이다.

[입력]

첫 줄에 테스트 케이스 개수 T가 주어진다.
다음 줄부터 T개의 줄에 걸쳐 각 테스트 케이스마다 정수 N이 하나씩 주어진다.

[출력]

각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 가능한 배치의 총 경우의 수를 출력한다.
