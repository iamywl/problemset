[S/W 문제해결 기초] 바이러스 전파 연결컴포넌트 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - DFS 기반 연결 컴포넌트 크기 계산]
어느 날 1번 컴퓨터가 웜 바이러스에 감염되었습니다.
컴퓨터들이 네트워크 상에서 서로 연결되어 있다면, 한 컴퓨터가 바이러스에 걸렸을 때 그 컴퓨터와 연결된 모든 컴퓨터들로 바이러스가 전파됩니다.
1번 컴퓨터를 통해 바이러스에 걸리게 되는 컴퓨터의 수를 구하는 문제는,
그래프에서 1번 정점이 속한 연결 컴포넌트(Connected Component)의 정점 개수(1번 컴퓨터 본인 제외)를 세는 것과 완벽히 동일합니다.

DFS를 사용하여 1번 정점에서 출발하여 도달 가능한 모든 정점을 방문하고,
새롭게 방문할 때마다 카운트를 1씩 증가시키는 방식으로 간단히 해결할 수 있습니다.

[동작 과정 Trace 예시]
컴퓨터 7대 (네트워크 연결: 1-2, 2-3, 1-5, 5-2, 5-6, 4-7):
1. 1번 방문 (시작)
2. 1과 연결된 2번 방문 (감염 컴퓨터 +1)
3. 2와 연결된 3번 방문 (감염 컴퓨터 +1)
4. 1과 연결된 5번 방문 (감염 컴퓨터 +1)
5. 5와 연결된 6번 방문 (감염 컴퓨터 +1)
4번과 7번 컴퓨터는 1번과 분리되어 있으므로 감염되지 않습니다.
총 감염된 컴퓨터는 2, 3, 5, 6 총 4대입니다. 이것을 구현하여 연결 컴포넌트 탐색의 원리를 익히십시오.

[문제 설명]

컴퓨터의 수 N과 네트워크 연결 수 M이 주어질 때, 1번 컴퓨터를 통해 바이러스에 걸리게 되는 컴퓨터의 수를 구하십시오.

[제약 사항 (Java 전용)]

1. 컴퓨터의 수 N은 1 이상 100 이하의 자연수이다.
2. 네트워크 연결의 수 M은 1 이상 1,000 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 컴퓨터의 수 N이 주어지고, 둘째 줄에 네트워크 연결의 수 M이 주어진다.
이어지는 M개의 줄에 네트워크 상에서 직접 연결되어 있는 두 컴퓨터 번호가 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 1번 컴퓨터를 통해 감염되는 컴퓨터의 수를 정수로 출력한다.
