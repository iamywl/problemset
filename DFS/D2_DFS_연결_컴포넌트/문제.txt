[S/W 문제해결 기본] 연결 컴포넌트 (D2)

[문제 설명]
격자 그래프 연결 요소(Connected Component) 탐색 원리 및 개념 설명:
격자의 모든 좌표를 순회하며 아직 방문하지 않은 육지(1)를 발견할 때마다 DFS 재귀 호출을 시작하여 하나의 독립된 섬을 완전히 탐색하는 기본 원리입니다.

N×M 크기의 2차원 격자 지도가 있다.
지도에서 1은 땅을 나타내고, 0은 바다를 나타낸다.
상, 하, 좌, 우로 인접해 있는 땅들은 서로 연결되어 하나의 섬(연결 컴포넌트)을 형성한다.
지도에 존재하는 섬의 총 개수를 구하는 프로그램을 작성하라.

[제약 사항 (Java 전용)]

1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. N과 M은 2 이상 15 이하의 정수이다.

[입력]

첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 M이 주어진다.
다음 N개의 줄에 걸쳐 각 줄마다 길이 M인 0과 1로 구성된 문자열이 주어진다.

[출력]

각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 섬의 총 개수를 출력한다.
