[문제 설명]
길이가 N인 수열 A에서 $i < j$이면서 $A[i] > A[j]$인 쌍 $(i, j)$를 '역순쌍(Inversion)'이라고 합니다.
단순 이중 반복문으로 역순쌍을 셀 경우 $O(N^2)$ 시간이 걸려 $N=100,000$일 때 시간 초과가 발생합니다.
하지만 병합 정렬(Merge Sort)의 분할 정복 과정을 응용하면 $O(N \log N)$ 시간에 역순쌍의 총 개수를 셀 수 있습니다.
분할 정복 원리:
1. 배열을 왼쪽 절반과 오른쪽 절반으로 나눕니다.
2. 왼쪽 배열의 내부 역순쌍과 오른쪽 배열의 내부 역순쌍을 재귀적으로 계산합니다.
3. 두 정렬된 배열을 하나로 병합(Combine)할 때, 오른쪽 배열의 원소 $A[R]$이 왼쪽 배열의 원소 $A[L]$보다 작아서 먼저 병합 배열에 들어간다면,
   현재 왼쪽 배열에 남아있는 모든 원소(mid - L + 1개)는 $A[R]$보다 크므로 역순쌍을 형성합니다.

배열 A가 주어졌을 때, 역순쌍의 총 개수를 구하라. (개수가 크므로 64비트 정수 사용)

[입력 형식]
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 줄에 수열의 크기 N(1 <= N <= 100,000)이 주어진다.
두 번째 줄에 N개의 정수가 공백으로 구분되어 주어진다. (원소의 절댓값 <= 1,000,000,000)

[출력 형식]
각 테스트 케이스마다 '#T'를 출력하고, 역순쌍의 총 개수를 정수로 출력한다.
