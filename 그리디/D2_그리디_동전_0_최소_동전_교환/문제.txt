[S/W 문제해결 기초] 동전 0 최소 동전 교환 (D2)

[자료구조 및 알고리즘 개념 및 동작 원리 설명 - 일반화된 배수 동전 그리디]
준규가 가지고 있는 동전은 총 N종류이고, 각 동전의 가치는 A_1, A_2, ..., A_N입니다.
이 문제에서 핵심 조건은 "각 동전의 가치 A_i는 항상 직전 동전 A_{i-1}의 배수"라는 점입니다 (A_1 = 1).
이 배수 조건이 성립하기 때문에, 큰 가치의 동전을 사용하는 것이 항상 작은 동전 여러 개를 사용하는 것보다 유리하다는 탐욕적 선택 속성(Greedy Choice Property)이 완벽히 증명됩니다.

[동작 과정 Trace 예시]
동전 종류 [1, 5, 10, 50, 100, 500, 1000, 5000], 목표 금액 K=4200원인 경우:
1. 가장 큰 단위 5000원은 4200원보다 크므로 건너뜀
2. 1000원 -> 4개 사용 (4000원, 잔액 200원)
3. 500원 -> 건너뜀
4. 100원 -> 2개 사용 (200원, 잔액 0원)
총 사용 동전 개수: 4 + 2 = 6개.
이것을 구현하여 배수 관계에서의 그리디 최적성을 확인하십시오.

[문제 설명]
N종류의 동전과 목표 금액 K가 주어질 때, 그 가치의 합을 K로 만드는 데 필요한 동전 개수의 최솟값을 구하십시오.

[제약 사항 (Java 전용)]
1. N은 1 이상 10 이하의 자연수이다.
2. K는 1 이상 100,000,000 이하의 자연수이다.
3. 각 동전의 가치 A_i는 오름차순으로 주어지며, A_1 = 1이고 i >= 2인 경우 A_i는 A_{i-1}의 배수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N과 K가 공백으로 구분되어 주어진다.
이어지는 N개의 줄에 동전의 가치 A_i가 오름차순으로 한 줄에 하나씩 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 필요한 최소 동전 개수를 정수로 출력한다.
