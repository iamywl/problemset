[S/W 문제해결 응용] 강의실 배정 우선순위큐 최소 강의실 (D4)

[복합 제약조건 및 알고리즘 최적화]
선생님 김종혜는 N개의 강의를 진행해야 합니다. 각 강의는 시작 시간 S_i와 종료 시간 T_i를 가집니다.
최소한의 강의실을 사용하여 모든 수업을 가능하게 해야 합니다.
단, 한 강의실에서 수업이 끝난 직후에 다음 수업을 시작할 수 있습니다 (즉, T_i <= S_j 일 때 같은 강의실 사용 가능).

강의의 개수 N이 최대 200,000에 달하므로 다음과 같은 복합 제약조건 최적화를 적용해야 합니다:
1. 모든 강의를 '시작 시간 S_i' 기준 오름차순으로 정렬합니다.
2. 우선순위 큐(Min Heap)에 현재 사용 중인 강의실들의 '종료 시간'을 저장합니다.
3. 새로운 강의 (S, T)를 확인할 때:
- 만약 pq.peek() <= S 라면(가장 일찍 끝나는 강의실의 종료 시간 이후에 새 강의가 시작된다면), 기존 강의실을 재사용할 수 있으므로 pq.poll() 합니다.
- 그렇지 않다면 기존 강의실을 재사용할 수 없으므로 새로운 강의실을 하나 더 개설해야 합니다.
- 이후 새 강의의 종료 시간 T를 pq에 삽입합니다.
4. 모든 강의를 처리한 후 우선순위 큐의 크기가 필요한 최소 강의실 개수가 되며, 시간복잡도는 O(N log N)으로 최적화됩니다.

[문제 설명]

주어진 N개의 강의 일정에 대해 필요한 최소 강의실 개수를 구하십시오.

[제약 사항 (Java 전용)]

1. 강의의 개수 N은 1 이상 100,000 이하의 자연수이다.
2. 시작 시간 S_i와 종료 시간 T_i는 0 이상 1,000,000,000 이하의 정수이며, S_i < T_i이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]

첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N이 주어진다.
이어지는 N개의 줄에 걸쳐 각 강의의 시작 시간 S_i와 종료 시간 T_i가 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 필요한 최소 강의실 개수를 정수로 출력한다.
