[S/W 문제해결 응용] 지아의 은행 창구 시뮬레이션 (D3)

[문제 스토리]
지점장 지아는 고객 만족도를 높이기 위해 은행 1인 전담 창구의 고객 대기 시간을 정밀 시뮬레이션하고 있습니다.
오늘 방문할 N명의 고객 정보가 번호표 순서(도착 시간 오름차순)로 주어집니다.
각 고객 i는 도착 시간 A_i와 업무 처리 소요 시간 S_i를 가집니다:
1. 은행 창구는 시각 0부터 업무를 시작합니다.
2. 고객이 도착했을 때 창구가 비어있다면 즉시 업무를 시작합니다. (대기 시간 = 0)
3. 만약 이전 고객의 업무가 진행 중이라면, 해당 고객은 대기 큐에서 기다립니다.
   이전 고객의 업무가 종료되는 시각에 다음 고객의 업무가 즉시 시작됩니다.
   (대기 시간 = 업무 시작 시각 - 도착 시간 A_i)
4. 모든 고객은 큐에 도착한 순서대로 차례대로 응대받습니다.

지아를 도와 N명 고객들의 '총 대기 시간의 합'을 구하는 프로그램을 작성하십시오.

[제약 사항 (Java 전용)]
1. 고객의 수 N은 1 이상 1,000 이하의 자연수이다.
2. 도착 시각 A_i는 0 이상 100,000 이하의 정수이며, A_1 <= A_2 <= ... <= A_N이다.
3. 업무 소요 시간 S_i는 1 이상 1,000 이하의 자연수이다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 고객 수 N이 주어진다.
이어지는 N개의 줄에 각 고객의 도착 시각 A_i와 업무 소요 시간 S_i가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 모든 고객의 총 대기 시간의 합을 출력한다.
