[S/W 문제해결 응용] 안전 영역 카운트 (D3)

어떤 지역의 높이 정보를 파악하여, 많은 비가 내렸을 때 물에 잠기지 않는 안전한 영역이 최대 몇 개가 만들어지는지 조사하려고 한다.
지역은 N×N 크기의 2차원 배열로 표현되며 각 칸의 값은 해당 지점의 높이를 나타낸다.
비가 내리면 높이가 h 이하인 모든 지점은 물에 잠긴다.
물에 잠기지 않는 안전 영역이란 상, 하, 좌, 우로 인접한 칸들이 연결되어 있는 덩어리를 의미한다.
비의 높이 h가 정해지지 않았을 때(h >= 0), 안전 영역의 최대 개수를 구하는 프로그램을 작성하라.
(아무 지역도 물에 잠기지 않는 경우 h=0일 때 영역의 개수는 1이다.)

[제약 사항 (Java 전용)]
1. 언어 제한: Java (Java 8 이상)
2. 클래스명: 반드시 Solution
3. 시간 제한: 10개 테스트 케이스 기준 2.0초 이내
4. 메모리 제한: 힙 메모리 256MB 이내
5. 2차원 배열의 한 변의 크기 N은 3 이상 15 이하이다. 높이는 1 이상 100 이하의 자연수이다.

[입력]
첫 줄에 테스트 케이스 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N이 주어지고, 다음 N개의 줄에 걸쳐 N개씩 높이 정보가 주어진다.

[출력]
각 테스트 케이스마다 '#' 부호와 함께 테스트 케이스 번호를 출력하고, 공백 후 물에 잠기지 않는 안전 영역의 최대 개수를 출력한다.
