# 🧩 Cormen (CLRS) & SSAFY 알고리즘 문제 세트 & AI 채점 에이전트

*Introduction to Algorithms (Cormen et al., CLRS)* 및 SSAFY 알고리즘 정규 커리큘럼(완탐·순열·조합·부분집합, 분할정복, 그리디, DP, 그래프, 서로소집합, 최단경로, 기초 자료구조, 고급 알고리즘)을 망라한 **총 132개**의 SWEA 스타일 Java 알고리즘 문제 세트와, 문제를 통합 관리·채점·검증하는 AI 에이전트 시스템입니다.

---

## 📌 주요 특징 및 규격

1. **Java 전용 제약조건 준수**:
   - 모든 문제는 **Java (Java 8 이상)** 기준
   - 클래스명 `public class Solution` (SWEA 표준 규격)
   - 10개 테스트케이스 기준 2.0초 이내, 힙 메모리 256MB 이내
   - 고속 입출력(`BufferedReader`, `StringTokenizer`, `StringBuilder`) 최적화 적용

2. **표준 6종 파일 규격 완비 (전체 132문제 100% 완비)**:
   - `문제.txt`: SWEA 표준 문제 명세서, 알고리즘 개념/원리(D2), 실생활 시나리오(D3), 복합 제약조건(D4/D5), 입출력 포맷
   - `sample_input.txt` & `sample_output.txt`: 샘플 테스트케이스 (정확히 2개)
   - `input.txt` & `output.txt`: 백그라운드 평가용 테스트케이스 (정확히 10개)
   - `Solution.java`: 컴파일 및 12개 테스트케이스 100% 통과(PASS) 검증 완료된 Java 솔루션

3. **엄격한 난이도 체계**:
   - **D2 (개념 및 기초 - 37문제)**: 단순 알고리즘/자료구조 적용 문제. 문제 본문에 해당 알고리즘의 개념, 동작 원리, 단계별 실행 예시(Trace)가 상세히 포함됨.
   - **D3 (응용 및 실생활 스토리텔링 - 45문제)**: 사용자 지정 한국 아이 대표 이름 20인(남자: 이준, 도윤, 하준, 시우, 서준, 은우, 유준, 선우, 로운, 도하 / 여자: 이서, 서아, 아윤, 지아, 하윤, 서윤, 시아, 아린, 나은, 유주)을 활용한 생생한 실생활 스토리텔링 응용 문제.
   - **D4 (심화 및 복합 제약 - 42문제)**: 2~3개 이상의 까다로운 복합 제약조건이 유기적으로 결합된 고난도 문제.
   - **D5 (삼성 SW 역량테스트 Professional / B형 - 8문제)**: 대규모 데이터, 비트마스킹 DP, 롤백(Undo) 유니온파인드, K번째 최단경로, No-STL 커스텀 자료구조 등 고도의 최적화 알고리즘 문제.

4. **병렬 에이전트(Parallel Agent) 지원 및 지속적 통합(CI)**:
   - 대규모 문제 세트 생성, 일괄 채점/검증 시 다중 Worker Subagent를 동시 증설하여 분할 병렬 처리 지원
   - 각 문제 단위로 생성이 완료되고 100% 테스트케이스 검증을 통과할 때마다 즉시 개별 `git commit` 및 `git push origin main` 자동 수행
