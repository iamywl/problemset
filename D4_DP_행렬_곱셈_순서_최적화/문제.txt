[S/W 문제해결 심화] 행렬 곱셈 순서 최적화 (D4)

[복합 제약 조건 설명 - CLRS 15.2 Matrix-chain Multiplication]
N개의 연속된 행렬 A_1, A_2, ..., A_N이 주어집니다.
행렬 A_i의 크기는 r_i x c_i이며, 인접한 두 행렬의 곱셈이 정의되므로 c_i = r_{i+1}을 항상 만족합니다.
행렬 곱셈은 결합 법칙(Associative Law)이 성립하므로, 괄호를 어떻게 묶느냐에 따라 필요한 스칼라 곱셈(원소 곱셈) 연산 횟수가 극적으로 달라집니다.
(예: 10x100, 100x5, 5x50 크기의 3개 행렬 곱셈 시 ((A1 A2) A3)는 7,500번이지만, (A1 (A2 A3))는 75,000번으로 10배 차이가 납니다.)

[구간 DP(Interval DP) 복합 해결 조건]
1. 부분 구간 [i, j]의 최소 곱셈 연산 횟수를 `m[i][j]`라고 정의합니다.
2. 구간의 길이 len을 2부터 N까지 늘려가며 다음 점화식을 계산해야 합니다:
   m[i][j] = min_{i <= k < j} (m[i][k] + m[k+1][j] + p_{i-1} * p_k * p_j)
   (여기서 행렬 A_t의 차원은 p_{t-1} x p_t)
3. 시간 복잡도 O(N^3)의 구간 DP를 정확하고 빠르게 수행해야 합니다.
4. 연산 횟수가 2^31-1을 넘을 수 있으므로 long 타입을 사용하여 최소 비용을 계산해야 합니다.

[제약 사항 (Java 전용)]
1. 행렬의 개수 N은 1 이상 200 이하의 자연수이다.
2. 행렬의 각 차원 크기는 1 이상 500 이하의 자연수이다.
3. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
4. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 행렬의 개수 N이 주어진다.
이어지는 N개의 줄에는 각 행렬의 행 r_i와 열 c_i가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, N개의 행렬을 모두 곱하는 데 필요한 최소 스칼라 곱셈 횟수를 출력한다.
