[S/W 문제해결 기본] 유클리드 호제법과 최대공약수 (D2)

[알고리즘 개념 및 원리 학습 - 유클리드 호제법 (Euclidean Algorithm, CLRS 31.2)]
유클리드 호제법(Euclidean Algorithm)은 기원전 300년경 유클리드의 '기하학 원론'에 수록된 가장 오래되고 우아한 수론(Number Theory) 알고리즘 중 하나로, 두 양의 정수의 최대공약수(GCD: Greatest Common Divisor)를 신속하게 구합니다.

1. 최대공약수(GCD)와 호제법의 원리:
- 두 양의 정수 a, b (a >= b)에 대하여, a를 b로 나눈 나머지를 r이라고 할 때 (즉, a = q*b + r, 0 <= r < b), a와 b의 공약수 집합은 b와 r의 공약수 집합과 정확히 일치합니다.
- 따라서 gcd(a, b) = gcd(b, a % b)의 재귀적 관계가 성립합니다.
- 나머지가 0이 되었을 때 나누는 수 b가 바로 두 수의 최대공약수가 됩니다. (b == 0 이면 a가 GCD)
- 시간 복잡도는 O(log(min(a, b)))로, 두 연속한 피보나치 수일 때가 최악의 수행 시간(라메의 정리, Lamé's Theorem)을 갖지만 매우 빠르게 수렴합니다.

2. 최소공배수(LCM: Least Common Multiple):
- 두 정수 a, b의 최대공약수를 g라 하면, a = g * x, b = g * y (x, y는 서로소)입니다.
- 두 수의 최소공배수는 g * x * y = (a * b) / g 로 계산할 수 있습니다.
- 계산 시 (a * b)에서 정수 오버플로우가 발생하지 않도록 (a / g) * b 형태로 먼저 나눈 후 곱하는 기법이 권장됩니다.

3. N개 수의 GCD와 LCM으로의 확장:
- N개의 수 A_1, A_2, ..., A_N에 대해:
  GCD(A_1, A_2, ..., A_N) = gcd(GCD(A_1, ..., A_{N-1}), A_N)
  LCM(A_1, A_2, ..., A_N) = lcm(LCM(A_1, ..., A_{N-1}), A_N)
  순차적으로 이전 결과와 다음 수의 연산을 누적 수행하여 간단히 계산할 수 있습니다.

[문제 설명]
SSAFY 알고리즘 캠프에 참가한 학생들은 N개의 양의 정수를 분석하는 프로그램을 작성하고 있습니다.
주어진 N개의 양의 정수들에 대해 전체 수들의 최대공약수(GCD)와 최소공배수(LCM)를 차례대로 구하여 출력하십시오.

[제약 사항 (Java 전용)]
1. 수의 개수 N은 2 이상 10 이하의 자연수이다. (2 <= N <= 10)
2. 각 정수 A_i는 1 이상 1,000,000 이하의 자연수이다. (1 <= A_i <= 1,000,000)
3. 모든 테스트케이스에서 N개 정수의 최소공배수(LCM)는 64비트 정수형(Java의 long 타입, 약 9.22 * 10^18)을 초과하지 않음이 보장된다.
4. 시간 제한: 10개 테스트케이스 기준 2.0초 이내
5. 메모리 제한: 힙(Heap) 메모리 256MB 이내

[입력]
첫 줄에 총 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스의 첫 줄에 N이 주어진다.
둘째 줄에 N개의 자연수가 공백으로 구분되어 주어진다.

[출력]
각 테스트 케이스마다 '#tc'와 공백을 출력한 후, 전체 N개 수의 최대공약수와 최소공배수를 공백으로 구분하여 한 줄에 출력한다.
